# 見る方向を変えるテク

> 📅 **投稿日**: 2022-02-11 03:04:03

見る方向を \\(x\\) 軸と \\(y\\) 軸で入れ替えると、効率的に解ける問題を集めてみました。
&lt;h2&gt;Floor Sum&lt;/h2&gt;
\\(ax+by \\leq N, a,b,N \\in \\mathbb&#123;N&#125;, x,y \\geq 0\\) を満たす格子点の数を求めてくださいという問題を考えます。\\(x\\) 軸に沿って格子点を大雑把に求めた後、\\(y\\) 軸に沿って格子点を求め、また \\(x\\) 軸に沿って...というようにすると効率的に求まります。
&lt;img class="aligncenter size-large wp-image-11373" src="https://37zigen.com/wp-content/uploads/2022/02/76c691c22c7ef40a64aa64b04f05e90c-1024x860.png" alt="" width="512"&gt;
&lt;h2&gt;Grundy数（AGC002E）&lt;/h2&gt;
それぞれ \\(a_1, \\ldots, a_N\\) 個のキャンディからなる山が&nbsp;&lt;var&gt;N&lt;/var&gt;&nbsp;個あります。交互に次の操作を行い、最後のキャンディーを食べたほうが負けです。どちらが勝つでしょうか。
&lt;ul&gt;
 	&lt;li&gt;キャンディが最も多く残っている山をひとつ選び、その山のキャンディをすべて食べる。&lt;/li&gt;
 	&lt;li&gt;キャンディが残っているすべての山から、1 個ずつキャンディを食べる。&lt;/li&gt;
&lt;/ul&gt;
これは、各列にキャンディーの山の個数分だけ丸を並べた図形で考えると、行と列の削除に対応しています。これが効率的な解法に至る重要な考察になっています。
&lt;img class="aligncenter size-large wp-image-11371" src="https://37zigen.com/wp-content/uploads/2022/02/0d40a5e4a645fc6b96e767d64ac0878e-1024x352.png" alt="" width="512"&gt;
&lt;h2&gt;分割数&lt;/h2&gt;
自然数 \\(n\\) を自然数の非減少数列 \\(x_i\\) を用いて \\(n= \\sum x_i\\) と表すことを整分割といい、その分け方の個数を分割数といいます。例えば、\\begin&#123;align&#125; 5=&amp;1+1+1+1+1 \\\\ =&amp; 2+1+1+1 \\\\ =&amp; 3+1+1 \\\\ =&amp; 4 + 1 \\\\ =&amp; 2+2+1 \\\\ =&amp; 3 + 2 \\\\ =&amp;5\\end&#123;align&#125; なので、\\(5\\) の分割数は \\(7\\) です。分割数の性質は、フェーラズ図形という整分割の可視化により導かれることがあります。分割後のそれぞれの数の分だけドットを上の行から並べた図形です。例えば、\\(12=5+4+2+1\\) のときは下のようになります。&lt;img class="aligncenter size-large wp-image-11374" src="https://37zigen.com/wp-content/uploads/2022/02/82cd89bf6e3e7beeac7a6a7e3c296e8a-1024x867.png" alt="" width="216"&gt;一方、列方向から見ても \\(12\\) になっており、\\(12=4+3+2+2+1\\) です（共役）。このことから、最大値が \\(k\\) の \\(n\\) の分割の個数と、\\(k\\) 個への \\(n\\) の分割の個数は等しいことが分かります。このほかにも、
&lt;ul&gt;
 	&lt;li&gt;オイラーの五角数定理・ヤコビの三重積&lt;/li&gt;
 	&lt;li&gt;\\(m,l\\) を奇数とする。各数が \\(m\\) 以下の偶数で、項数が \\(l\\) 個以下の分割の総数と、各数が \\(m\\) 以下の奇数、項数が \\(l\\) 個以下の分割の総数が等しい。&lt;/li&gt;
 	&lt;li&gt;共役が自分自身と等しい \\(n\\) の分割の総数と相異なる奇数への \\(n\\) の分割の総数が等しい。&lt;/li&gt;
&lt;/ul&gt;
のような事実をフェラーズ図形で示せます。

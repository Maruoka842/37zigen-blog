# 素数の個数

> 📅 **投稿日**: 2022-06-26 01:10:25

&lt;p&gt;[toc]&lt;/p&gt;
&lt;h2&gt;Lucy's DP&lt;/h2&gt;
&lt;p&gt;包除原理より \\(n\\) 以下の数のうち、\\(p_1, p_2, \\ldots, p_j\\) と互いに素なものの個数 \\(\\pi_j(n)\\) は&lt;br&gt;\\begin&#123;align&#125;&lt;br&gt;\\pi_j(n)=\\sum \\mu(d) \\lfloor n/d \\rfloor \\\\&lt;br&gt;\\end&#123;align&#125;と書ける。ただし、\\(\\mu\\) は \\(p_1, p_2, \\ldots, p_j\\) を素因数に持つ数からなる整除束の部分束のメビウス関数とする。&lt;/p&gt;
&lt;p&gt;\\(n\\) を固定する。\\(\\lfloor n / i\\rfloor\\) を基底とする整数係数の加群 \\(V\\) を考えて \\(\\boldsymbol&#123;v&#125; = \\sum a_i \\lfloor n / i\\rfloor\\) に対する作用素 \\(D_m\\) を \\(D_m \\boldsymbol&#123;v&#125; = \\sum a_i \\lfloor n / (im)\\rfloor\\) と定義する。\\(\\mathbb&#123;N&#125;\\) と \\(V\\) の元を区別して、\\(\\sum a_i \\lfloor n / i\\rfloor\\) は \\(\\sum a_i\\boldsymbol&#123;e&#125;_&#123;i&#125;\\) のように書くべきかもしれないが、分かりやすいので混同する。&lt;br&gt;\\(i\\) 番目の素数 \\(p_i\\) を用いて \\(f_i = 1-D_&#123;p_i&#125;\\) とすると $$\\pi_j(n) = \\left(\\prod_&#123;i=1&#125;^j f_i \\right) \\left\\lfloor \\frac&#123;n&#125;&#123;1&#125; \\right\\rfloor $$ になる（左辺と右辺で型が違いますが、自然に解釈してください）。合成数 \\(m\\) の素因数には \\(\\sqrt&#123;m&#125;\\) 以下のものが必ず存在するから、\\(p_i^2 \\leq n\\) となる最大の \\(i\\) を \\(k\\) と置くと$$\\pi(n) = k+\\pi_k(n)$$である。&lt;/p&gt;
&lt;p&gt;基底が小さい場合に帰着したいので \\(i\\) の降順に \\(f_i\\) を作用させて&lt;br&gt;$$\\pi_k(n) = f_1\\left(f_2\\left(\\cdots \\left(f_&#123;k-1&#125;\\left(f_k\\left\\lfloor \\frac&#123;n&#125;&#123;1&#125; \\right\\rfloor\\right)\\right)\\right)\\right) $$の順に計算する。\\(\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125; \\right\\rfloor\\) の形の基底は \\(O(\\sqrt n)\\) 個しか存在しない。また、\\(\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125;\\right\\rfloor &lt; p_m^2\\) ならば \\(f_m\\) は恒等作用素として扱ってよい。つまり、dp の更新は in-place に行い \\(\\sqrt &#123;\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125;\\right\\rfloor&#125; &lt; p_m\\) となる基底には何もしない。&lt;/p&gt;
&lt;ul&gt;
&lt;li&gt;\\(d \\leq \\sqrt&#123;n&#125;\\) となる基底 \\(\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125;\\right\\rfloor\\) に対して、恒等でない作用が \\(O(\\sqrt&#123;n/d&#125;)\\) 回起きる。作用の回数の和は \\(O\\left(\\int_&#123;x=1&#125;^&#123;\\sqrt&#123;n&#125;&#125; \\sqrt&#123;n/x&#125;dx \\right) = O(n^&#123;3/4&#125;)\\)。&lt;/li&gt;
&lt;li&gt;\\(d \\geq \\sqrt&#123;n&#125;\\) となる基底 \\(\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125;\\right\\rfloor\\) に対して、恒等でない作用が \\(O(\\sqrt&#123;n/d&#125;) = O(n^&#123;1/4&#125;)\\) 回起きる。このような基底は \\(O(\\sqrt&#123;n&#125;)\\) 個しかないので、作用の回数の和は \\(O(n^&#123;3/4&#125;)\\)。&lt;/li&gt;
&lt;/ul&gt;
&lt;h2&gt;Meissel-Lehmer algorithm&lt;/h2&gt;
&lt;p&gt;基本方針は \\(f_k, f_&#123;k-1&#125;, \\ldots, \\) を順に作用させて、\\(\\pi_k(n)\\) を \\(\\pi_i(j)\\) \\((1 \\leq j \\leq n^&#123;2/3&#125;)\\) と \\(\\pi_0(j)\\) \\((1 \\leq j \\leq n)\\) の線形結合で表すことである。&lt;br&gt;\\begin&#123;align&#125;&lt;br&gt;\\pi(n) &amp;= k+f_1f_2\\cdots f_&#123;k-1&#125;\\left(f_k\\left\\lfloor \\frac&#123;n&#125;&#123;1&#125; \\right\\rfloor\\right) \\\\&lt;br&gt;&amp;= k+f_1f_2\\cdots f_&#123;k-1&#125;\\left(\\left\\lfloor \\frac&#123;n&#125;&#123;1&#125; \\right\\rfloor - \\left\\lfloor \\frac&#123;n&#125;&#123;p_k&#125; \\right\\rfloor\\right) \\\\&lt;br&gt;&amp;= k+f_1f_2\\cdots f_&#123;k-1&#125;\\left\\lfloor \\frac&#123;n&#125;&#123;1&#125; \\right\\rfloor - \\pi\\left(\\left\\lfloor \\frac&#123;n&#125;&#123;p_k&#125; \\right\\rfloor\\right)\\\\&lt;br&gt;&amp;\\vdots\\\\&lt;br&gt;&amp;= k+f_1f_2\\cdots f_&#123;l&#125;\\left\\lfloor \\frac&#123;n&#125;&#123;1&#125; \\right\\rfloor - \\sum_&#123;i=l+1&#125;^k \\pi\\left(\\left\\lfloor \\frac&#123;n&#125;&#123;p_i&#125; \\right\\rfloor\\right)\\\\&lt;br&gt;\\end&#123;align&#125;を得る。ただし、\\(p_i^2 \\leq n\\) となる最大の \\(i\\) を \\(k\\)、\\(p_i^3 \\leq n\\) となる最大の \\(i\\) を \\(l\\) と置く。&lt;br&gt;\\(\\sum_&#123;i=l+1&#125;^k \\pi\\left(\\left\\lfloor \\frac&#123;n&#125;&#123;p_i&#125; \\right\\rfloor\\right)\\) は \\(n^&#123;2/3&#125;\\) 以下の数に対してエラトステネスの篩を適用すれば計算できる。\\(\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125; \\right\\rfloor \\leq n^&#123;2/3&#125;\\) となる基底に対しては、それ以上作用素を掛けずそのままにして、計算を進めると、$$f_1f_2\\cdots f_&#123;l&#125;\\left\\lfloor \\frac&#123;n&#125;&#123;1&#125; \\right\\rfloor = \\sum_i \\sum_&#123;\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125; \\right\\rfloor \\leq n^&#123;2/3&#125;&#125; a_&#123;i, d&#125; f_1f_2 \\cdots f_i \\left\\lfloor \\frac&#123;n&#125;&#123;d&#125;\\right\\rfloor + \\sum_&#123;d &lt; n^&#123;1/3&#125;&#125; b_d \\left\\lfloor \\frac&#123;n&#125;&#123;d&#125;\\right\\rfloor $$と展開できる。\\(\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125; \\right\\rfloor &gt; n^&#123;2/3&#125;\\) となる基底は \\(O(n^&#123;1/3&#125;)\\) 個しかないので、\\(O(n^&#123;2/3&#125;)\\)で展開できる。\\(f_1f_2 \\cdots f_i \\left\\lfloor \\frac&#123;n&#125;&#123;d&#125;\\right\\rfloor\\)は\\(\\left\\lfloor \\frac&#123;n&#125;&#123;d&#125;\\right\\rfloor\\)以下の数のうち、\\(p_1, p_2, \\ldots, p_i\\) で割り切れないものの個数だから、累積和を高速に得られるデータ構造（BITなど）でエラトステネスの篩を管理すれば、\\(l = O(n^&#123;1/3&#125; / \\log(n))\\) より \\(O(n^&#123;2/3&#125;\\log(n))\\) で列挙できる。&lt;a href="https://37zigen.com/sieve-eratosthenes/"&gt;エラトステネスの篩&lt;/a&gt;を \\(O(n^&#123;1/3&#125;)\\) 個ずつに区切って、それぞれ別々に更新すれば、空間計算量 \\(O(n^&#123;1/3&#125;)\\) にできる。\\(a(k,\\lfloor n/i \\rfloor)=f_1f_2\\cdots f_k \\lfloor n / i \\rfloor\\) と置くと \\(a(k,\\lfloor n/i \\rfloor)=a(k-1,\\lfloor n/i \\rfloor)-a(k-1,\\lfloor n/(ki) \\rfloor)\\) となりDPすると計算量はそのままで、素数の列挙が\\(\\lfloor n/i \\rfloor\\) for i =1,..,nについて同時に行える。&lt;/p&gt;
&lt;h2&gt;一般化&lt;/h2&gt;
&lt;p&gt;完全乗法的関数 \\(g\\) に対して、\\(G(n) = \\sum_&#123;1 \\leq i \\leq n&#125; g(i), G'(n) = \\sum_&#123;1 \\leq i \\leq n\\\\ p \\text&#123; is prime&#125;&#125; g(i)\\) と置く。\\(f_i = 1-g(p_i)\\left\\lfloor \\frac&#123;\\cdot&#125;&#123;p_i&#125;\\right\\rfloor\\)と置くと$$G'(n)=\\sum_&#123;i=1&#125;^k g(p_i)+ f_1f_2\\cdots f_k G(n)$$が成り立つ。\\(g(p_i)=1\\) と置くと \\(G'(n)=\\pi(n)\\) である。&lt;/p&gt;


&lt;p&gt;\\(G(\\lfloor n/1\\rfloor), G(\\lfloor n/2\\rfloor), \\ldots, G(\\lfloor n/n\\rfloor)\\) が \\(O(1)\\) で求まるならば、Meissel-Lehmer algorithm により \\(O(n^&#123;2/3&#125;\\log(n))\\) で \\(G'(n)\\) が求まる。アルゴリズムを少し変更すると \\(G'(\\lfloor n/1\\rfloor), G'(\\lfloor n/2\\rfloor), \\ldots, G'(\\lfloor n/n\\rfloor)\\) が同様の計算量で列挙できる。\\(1 \\leq n/j \\leq n^&#123;2/3&#125;\\) に対して、$\\pi_i(\\lfloor n/j \\rfloor)$ の取得および列挙は BIT によって \\(O(\\log(n))\\) でできる。\\(i\\) の降順に必要になるので、破壊的に変更して構わない。\\(n^&#123;2/3&#125; \\leq n/j \\leq n\\) に対する \\(\\pi_i(\\lfloor n/j \\rfloor)\\) の列挙は、次の様にする。\\(1 \\leq i \\leq \\pi(n^&#123;1/3&#125;), 1\\leq j \\leq n^&#123;1/3&#125;\\) なので、全て保持しても \\(O(n^&#123;3/2&#125; / \\log(n))\\) で済む。上記の説明では、\\(\\lfloor n/i\\rfloor\\) の線形結合を保持したが、今回は \\(\\boldsymbol&#123;v&#125;_&#123;\\lfloor n/d \\rfloor&#125;^&#123;(i)&#125;=f_if_&#123;i+1&#125;f_&#123;i+2&#125; \\cdots f_l \\lfloor n/d\\rfloor\\) を（ベクトルではなく値として）各 \\(d\\) について列挙する。\\(\\boldsymbol&#123;v&#125;_&#123;\\lfloor n/d \\rfloor&#125;^&#123;(i-1)&#125; = f_&#123;i-1&#125;\\boldsymbol&#123;v&#125;_&#123;\\lfloor n/d \\rfloor&#125;^&#123;(i)&#125; = \\boldsymbol&#123;v&#125;_&#123;\\lfloor n/d \\rfloor&#125;^&#123;(i)&#125; - f(p_&#123;i-1&#125;)\\boldsymbol&#123;v&#125;_&#123;\\lfloor n/(p_&#123;i-1&#125;d) \\rfloor&#125;^&#123;(i)&#125;\\) となる。ゼータ変換に対して同様のアルゴリズムを適用することで (G') から (G) を求めることもできる。すなわち、\\(f_i^&#123;-1&#125;=1+g(p_i) \\left\\lfloor \\frac&#123;\\cdot&#125;&#123;p_i&#125; \\right\\rfloor\\) とすると \\(G(n) = f_1^&#123;-1&#125;f_2^&#123;-1&#125;..f_k^&#123;-1&#125;(G'(n)-\\sum_&#123;i=1&#125;^k g(p_i))\\) となる。&lt;/p&gt;

# Grundy数

> 📅 **投稿日**: 2022-02-02 01:20:45


&lt;p&gt;&lt;div class="statement"&gt;
&lt;p&gt;それぞれ \\(a, b, c\\) 個の石からなる山が三つあります。各操作では、2つの山から同数の好きな個数の石を \\(x\\) 個取り、もう一つの山に \\(x\\) 個の石を加えます。操作できなくなった方が負けです。&lt;/p&gt;
&lt;/div&gt;&lt;/p&gt;



&lt;p&gt;&lt;p&gt;グランディー数は \\(\\frac&#123;1&#125;&#123;2&#125;(a+b+c-a \\oplus b \\oplus c)\\) となります。&lt;a href="http://https://wandbox.org/permlink/Ft1PyvdYqlQZxfUg" data-type="URL"&gt;code&lt;/a&gt;, &lt;a href="https://link.springer.com/content/pdf/10.1007/s00182-013-0380-z.pdf"&gt;証明&lt;/a&gt;&lt;/p&gt;

&lt;div class="statement"&gt;
&lt;p&gt;それぞれ \\(a_1, a_2, \\ldots, a_N\\) 個の石からなる山があります。各操作では、1つの山から好きな個数の石を取り除くか、合計で \\(1\\) 個以上 \\(h\\) 個未満の石を複数の山から取り除くことができます。操作できなくなった方が負けです。&lt;/p&gt;
&lt;/div&gt;
グランディー数は \\(h \\left(\\frac&#123;a_1&#125;&#123;h&#125; \\oplus \\frac&#123;a_2&#125;&#123;h&#125; \\oplus \\dots \\frac&#123;a_N&#125;&#123;h&#125; \\right) + \\left(\\left(\\sum a_i\\right) \\mod h\\right)\\) となります。

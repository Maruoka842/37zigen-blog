# カット・サイクル空間の基底

> 📅 **投稿日**: 2020-10-20 14:14:43

グラフ \\(G\\) の辺集合 \\(E(G)\\) の部分集合 \\(F\\) は各辺 \\(e \\in E(G)\\) が辺集合 \\(F\\) に"含まれるか否か"をベクトルの要素"1/0"に対応させることで \\(\\mathbb&#123;Z&#125;/2\\mathbb&#123;Z&#125;\\) ベクトルと一対一対応する。このとき、ベクトルの和は辺集合の対称差と対応づく（下図、要は辺ごとのXOR）。辺集合がなすこのベクトル空間を辺空間と呼ぶ。&lt;img class="aligncenter size-full wp-image-2266" src="https://37zigen.com/wp-content/uploads/2020/10/edgespace-1.png" alt="" width="3244" height="1084"&gt;

この記事では辺空間 \\(\\mathcal&#123;E&#125;(G)\\) の部分空間であるサイクル空間、カット空間の基底について解説する。

サイクル空間 \\(\\mathcal&#123;C&#125;(G)\\) とはサイクルの辺集合全体が生成する \\(\\mathcal&#123;E&#125;(G)\\) の部分空間、またカット空間 \\(\\mathcal&#123;B&#125;(G)\\) とはカットの辺集合全体が生成する \\(\\mathcal&#123;E&#125;(G)\\) の部分空間である。

サイクル空間の元は、サイクルの Disjoint Union になる（非連結になり得ることに注意）。このことは、二つの閉路の XOR が閉路の Disjoint Union になることを思い浮かべれば分かる。また、カット空間の元は（幾つか例外を除き）カットになる。このことは、後述する\\(E(v)\\) の形の基底で理解できるはずである。

サイクルの Disjoint Union とカットが部分空間として閉じているという点が非常に重要である。サイクル・カット空間の基底を見つけることができれば、サイクルの Disjoint Union やカットの数え上げが容易であることを示唆している。

簡単のために、この記事では辺集合 \\(F \\in \\mathcal&#123;E&#125;(G)\\) と \\(G\\) の部分グラフ \\((V,F)\\) を区別せずに使う。
&lt;h2&gt;基本閉路・基本カット&lt;/h2&gt;
以下に述べるように、サイクル・カット空間の基底は全域木を用いて簡単に列挙することができる。&lt;img class="aligncenter size-full wp-image-2283" src="https://37zigen.com/wp-content/uploads/2020/10/fundamental-cut-cycl-4.png" alt="" width="2784" height="1372"&gt;適当な全域木 \\(T \\) を取る。\\(T\\) に含まれない \\(G\\) の辺 \\(e \\in E(G) \\setminus E(T)\\) を \\(T\\) に加えた時にできる唯一の閉路 \\(C_e\\) を \\(T\\) に関する \\(e\\) の基本閉路と定義する。また、\\(f \\in E(T)\\) を除いた \\(T-f\\) の 2 つの連結成分を横切るカット \\(D_f\\) を \\(T\\) に関する \\(f\\) の基本カットと定義する。このとき次の事実が成り立つ。
&lt;div class="statement"&gt;\\(n\\) 頂点 \\(m\\) 辺の連結グラフ \\(G\\) があり、\\(T\\) を \\(G\\) の全域木とする。このとき \\(T\\) に関する基本閉路と基本カットはそれぞれサイクル空間 \\(\\mathcal&#123;C&#125;(G)\\) とカット空間 \\(\\mathcal&#123;B&#125;(G)\\) の基底をなす。&lt;/div&gt;
&lt;div class="proof"&gt;

証明：\\(e \
otin T\\) は基本閉路のうち \\(C_e\\) のみに含まれる辺であるから、基本閉路は一次独立。同様に \\(f \\in T\\) は基本カットのうち \\(D_f\\) にのみ含まれる辺であるから基本カットも一次独立。

あとは基本閉路と基本カットがそれぞれサイクル空間とカット空間の全ての元を生成することを示せば良い。サイクル空間の元 \\(C+\\sum_&#123;e \\in C \\setminus T&#125; C_e\\) は \\(T\\) の辺のみで構成されるが、そのような回路は存在しない（辺空間での足し算であることに注意）。従って \\(C+\\sum_&#123;e \\in C \\setminus T&#125; C_e=\\emptyset\\) つまり \\(C=\\sum_&#123;e \\in C \\setminus T&#125; C_e\\) となる。サイクル空間の任意の元 \\(C\\) が基本閉路で生成できた。同様にカット空間の元 \\(D+\\sum_&#123;f \\in C \\cap T&#125; D_f\\) は \\(T\\) の辺を含まないが、そのようなカットは存在しない。従って、\\(D=\\sum_&#123;f \\in D \\cap T&#125; D_f\\) である。カット空間の任意の元 \\(D\\) が基本カットで生成できた。

&lt;/div&gt;
ここから基本閉路・基本カットの数を数えることで \\(\\mathrm&#123;dim&#125;\\ \\mathcal&#123;C&#125;(G)=m-(n-1), \\mathrm&#123;dim&#125;\\ \\mathcal&#123;B&#125;(G)=n-1\\) が成り立つ。

ところで頂点 \\(v\\) に接続する辺集合 \\(E(v)\\) はカットであるが、実はこの形のカット全体はカット空間全体を生成する。一つカットを除いて、\\(n-1\\) 元にすれば、基底になる。この基底は頂点のXORでカット空間の足し算が捉えられることを表している。基底を求めるだけなら基本カットよりもこちらのほうが求めやすいと思う。Project Selection だと、こちらの方が考えやすい場合がある。
&lt;div class="statement"&gt;カット \\(E(v)\\) 全体はカット空間 \\(\\mathcal&#123;C&#125;(G)\\) 全体を生成する&lt;/div&gt;
&lt;div class="proof"&gt;証明：\\(E(A,B)=\\sum_&#123;v \\in A&#125; E(v)\\) であるから成立（足し算は 辺空間で行っていることに注意）。&lt;/div&gt;

ネタバレを避けるために出典は黒塗りにしている。
&lt;div class="statement"&gt;問題1：カット \\(E(v)\\) 全体の生成する部分空間に \\(E(G)\\) が元として含まれるのはどんな場合か。（出典：&lt;span style="background-color: black; color: #000000;"&gt;ARC105F改&lt;/span&gt;）&lt;/div&gt;

\\(E(v)\\) は誘導奇サイクルを生成できないから、\\(G\\) は二部グラフである。逆に部集合 \\(A,B\\) の二部グラフは \\(E(G)=\\sum_&#123;v \\in A&#125; E(v)\\) を満たす。よって \\(G\\) が二部グラフであればよい。

&lt;/div&gt;
&lt;div class="statement"&gt;問題2：\\(n\\) 頂点 \\(m\\) 辺の単純無向グラフには回路がいくつ含まれるか。&lt;/div&gt;

\\(\\mathrm&#123;dim&#125;\\ \\mathcal&#123;C&#125;(G)=m-n+1\\) より \\(2^&#123;m-n+1&#125;-1\\) 個（-1は空グラフを除いた）。

&lt;/div&gt;
&lt;div class="statement"&gt;問題3：\\(n\\) 頂点 \\(n+15\\) 辺以下の単純無向グラフがある。部分グラフとして含まれるサイクルの数を答えるアルゴリズムを構成せよ。また、空でない辺極小なカットの数の場合も考えよ（出典：&lt;span style="background-color: black; color: #000000;"&gt;ICPC2017Asia問題K&lt;/span&gt;）&lt;/div&gt;
&lt;div onclick="obj=document.getElementById('open3').style; obj.display=(obj.display=='none')?'block':'none';"&gt;
&lt;a style="cursor: pointer;"&gt;▼ 解説&lt;/a&gt;

&lt;/div&gt;
&lt;div id="open3" style="display: none; clear: both;"&gt;

サイクル空間の次元は 16 以下。従ってサイクルの個数は \\(2^&#123;16&#125;=65536\\) 個以下。答えは変わらないので次数 \\(2\\) 以下の頂点は縮約しておく。このとき頂点数が 32 以下になるので、基本閉路の線形結合を全て試せばよい。

同様に、空でない辺極小なカットは、基本カットの線形結合を全て試せばよい。空でない辺極小なカットはボンド（bond）という。

&lt;/div&gt;
&lt;div class="statement"&gt;問題4：\\(n\\) 頂点 \\(m\\) 辺の連結グラフが与えられる。各辺に 0, 1 の重みを割り当てる。このとき、「任意の回路の重みが偶数」かつ「全ての辺の重みの和が偶数」であるような重みの割り当て方法がいくつあるか求めよ（\\(O(m)\\) で解ける）。（出典：&lt;span style="background-color: black; color: #000000;"&gt;HackerRank "Devu and Cycles of a Graph"&lt;/span&gt;）&lt;/div&gt;
&lt;div onclick="obj=document.getElementById('open4').style; obj.display=(obj.display=='none')?'block':'none';"&gt;
&lt;a style="cursor: pointer;"&gt;▼ 解説&lt;/a&gt;

&lt;/div&gt;
&lt;div id="open4" style="display: none; clear: both;"&gt;

サイクル空間の基底である、全域木 \\(T\\) に関する基本閉路について「重みが偶数」が満たされれば、任意の回路について重みが偶数になる。ところで辺 \\(e \
otin T\\) は \\(C_e\\) のみに含まれるからこれら \\(n-m+1\\) 個の条件は独立である。また、辺 \\(e \
otin T\\) は \\(C_e\\) のみに含まれることより \\(\\sum_&#123;e \
otin T&#125; C_e=\\sum_&#123;e\\in G&#125; e\\) であるときのみ「基本閉路の重みの和が偶数」と「任意の回路について重みが偶数」が従属である。これは累積和を使えば \\(O(m)\\) で判定できる。独立であれば \\(2^&#123;n-2&#125;\\) 通り、そうでなければ \\(2^&#123;n-1&#125;\\) 通り。

サイクル空間とカット空間が互いに直交補空間であることを用いるともっと綺麗に解くことができる（ここでは解説しない）。

&lt;/div&gt;
&lt;div class="statement"&gt;問題5：\\(n\\) 頂点 \\(m\\) 辺の連結グラフが与えられる。各辺 \\(e\\) には64bit整数の重み \\(w_e\\) が割り当てられている。\\(s=0\\) とする。全ての 2 頂点の組 \\(u, v\\) それぞれについて、\\(u, v\\) を端点とする歩道の取りうる重みの XOR を \\(s\\) に加える。s を求めるアルゴリズムを構成せよ。（出典：&lt;span style="background-color: black; color: #000000;"&gt;CodeForces724G&lt;/span&gt;）&lt;/div&gt;

&lt;h3&gt;次数分布が等しい向き付け&lt;/h3&gt;
無向グラフ \\(G\\) を向き付けた二つのグラフ \\(G_1, G_2\\) について、各頂点の入次数・出次数が \\(G_1, G_2\\) 間で等しいとする。\\(G_1, G_2\\) で同じ方向に向き付けられている辺を \\(G_1\\) から削除したグラフを \\(G'\\) とする。\\(G'\\) の辺の向きを逆にしても各頂点の入次数・出次数が変わらない。従って、\\(G'\\) が辺素な有向サイクルの和で書けることと、\\(G_1, G_2\\) の各頂点の入次数・出次数が等しいことが同値（&lt;a href="https://x.com/kaichou243/status/1895881490552275445"&gt;会長さん&lt;/a&gt;、&lt;a href="https://atcoder.jp/contests/arc193/tasks/arc193_b"&gt;ARC193B&lt;/a&gt;）
&lt;h3&gt;接続行列&lt;/h3&gt;
&lt;div class="statement"&gt;
有向グラフ \\(G=(V,E)\\) と辺重み \\(c : E \\to \\mathbb&#123;F&#125;_2\\) が与えられる。任意の \\(ij \\in E\\) について \\(x_i + x_j + y_i = c_&#123;ij&#125;\\) を満たすような \\(x, y : V \\to \\mathbb&#123;F&#125;_2\\) を求めよ（&lt;a href="https://atcoder.jp/contests/arc188/tasks/arc188_c?lang=ja"&gt;ARC188C&lt;/a&gt;）。&lt;/div&gt;
\\(v \\in V\\) を一つ取り、\\(vw \\in E\\) かつ \\(c_&#123;vw&#125; = 0\\) となる \\(w\\) 全体を \\(W\\) と置く。 すると

\\(x_v + x_w + y_v = 0\\) for \\(w \\in W\\) という連立方程式は \\(x_i = x_j\\) for \\(i,j \\in W\\) とある一つの \\(w \\in W\\) を固定して、\\(x_v + x_w + y_v = 0\\) という式で書ける。\\(c_&#123;vw&#125; = 1\\) の場合も同様にする。\\(x_i=x_j\\) または \\(x_i \
eq x_j\\) という形の連立方程式が立ち、これはdfsなどで簡単に解が（存在するなら）求まる。あとは \\(x_v + x_w + y_v = 0\\) を満たすように \\(y\\) を決めればよい。

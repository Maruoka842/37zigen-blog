# \\(L_1\\)距離と\\(L_\\infty\\)距離

> 📅 **投稿日**: 2022-08-03 08:29:07

\\(L_1\\) 距離空間は

\\begin&#123;align&#125;
&amp;|dx| + |dy| \\\\
=&amp;\\max(dx, -dx) + \\max(dy, -dy) \\\\
=&amp;\\max(dx+dy,dx-dy,-dx+dy,-dx-dy) \\\\
=&amp;\\max(|dx+dy|,|dx-dy|) \\\\
=&amp;\\max(|dx'|,|dy'|) \\\\
\\end&#123;align&#125;

によって \\(L_\\infty\\) 距離空間になる。ただし、\\(x' = x + y, y' = x - y\\) と置いた。これは座標を45度回転していることに対応する。逆に辿れば \\(L_\\infty\\) 距離空間は \\(L_1\\) 距離空間に変換できる。

\\(L_1\\) で解ける問題
&lt;ul&gt;
 	&lt;li&gt;点の集合 S が与えられる。\\(v \\in S\\) がクエリで指定されるので、\\(\\sum_&#123;u \\in S&#125; \\mathrm&#123;dist&#125;(u, v)\\) を求めよ（yuki1864）。&lt;/li&gt;
&lt;/ul&gt;
\\(L_\\infty\\) で解ける問題
&lt;ul&gt;
 	&lt;li&gt;点の集合 S が与えられる。\\(d \\in \\mathbb&#123;R&#125;\\) がクエリで指定されるので、\\(\\mathrm&#123;dist&#125;(u, v) \\leq d\\) を満たす点の個数を求めよ（ABC233Ex）。&lt;/li&gt;
 	&lt;li&gt;点の集合 S が与えられる。互いに距離が等しい3頂点がいくつがあるか求めよ（天下一2018E）。&lt;/li&gt;
&lt;/ul&gt;

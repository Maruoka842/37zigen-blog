# Strassenの素因数分解 \\(\\tilde{O}(n^{1/4})\\)

> 📅 **投稿日**: 2021-04-13 12:45:33

&lt;p&gt;正整数 \\(n\\) の素因数分解を deterministic に \\(\\tilde&#123;O&#125;(n^&#123;1/4&#125;)\\) で求める Strassen のアルゴリズムが面白かったので紹介します。&lt;/p&gt;
&lt;h2&gt;アルゴリズム&lt;/h2&gt;
&lt;p&gt;\\(n\\) bitサイズ（桁数）の整数同士の掛け算に必要なステップ数を \\(\\mathrm&#123;M_&#123;int&#125;&#125;(n)\\) と置きます。\\(\\mathrm&#123;M_&#123;int&#125;&#125;(n)=O(n\\log(n))\\) のアルゴリズムがあるようなのですが、私は詳細を把握していないので語れないです、すみません。どの乗算アルゴリズムを使うかはほとんど関係ないので、\\(\\mathrm&#123;M_&#123;int&#125;&#125;\\) で内部を覆い隠して議論を進めます。\\(\\mathrm&#123;M_&#123;int&#125;&#125;(n)=\\tilde&#123;O&#125;(n)\\) であれば、素因数分解を \\(\\tilde&#123;O&#125;(n^&#123;1/4&#125;)\\) ステップでするには十分です。&lt;/p&gt;
&lt;p&gt;\\(n\\) の素因数のうち、\\(n^&#123;1/4&#125;\\) 以下のものは愚直に発見します。これは \\(O(n^&#123;1/4&#125;\\mathrm&#123;M_&#123;int&#125;&#125;(\\log(n)))\\) でできるので、\\(n\\) は \\(n^&#123;1/4&#125;\\) 超の素因数から成り立つと仮定して一般性を失いません。すると、\\(n\\) は高々３つの素数の積で書けます。また、\\(n^&#123;1/2&#125;\\) 超の素因数は高々１つしか存在しません。つまり \\(\\lceil n^&#123;1/4&#125; \\rceil\\) から \\(\\lfloor n^&#123;1/2&#125; \\rfloor\\) に含まれる素因数を１つ発見するアルゴリズムを構築すればよいです。&lt;/p&gt;
&lt;p&gt;この段落ではアイディアを説明しますが、そのままでは破綻する部分があるので探しながら読んでみてください。Baby-step Giant-step を用います。\\(M:=\\lfloor n^&#123;1/4&#125; \\rfloor\\) に対して、$$f(x) := (x+1)(x+1)(x+2) \\cdots (x+M)$$ と置きます。\\(\\lfloor n^&#123;1/2&#125; \\rfloor\\) 以下の正整数の積は$$n!=f(0)f(M)f(2M) \\cdots f(M(M-1)) \\prod_&#123;i=M(M-1)+1&#125;^&#123;\\lfloor n^&#123;1/2&#125; \\rfloor&#125; i!$$のように表せます。\\(f(0),f(M),f(2M), \\ldots ,f(M^2)\\) を&lt;a href="https://37zigen.com/multipoint-evaluation/"&gt;多点評価&lt;/a&gt;にて求めたとしましょう。各 \\(i=0,1,\\ldots,M\\) に対して \\(\\gcd(n,f(iM))\\) は \\(n\\) の素因数のうち \\(iM+1,iM+2,\\ldots,(i+1)M\\) に共通するものからなります。\\(\\gcd(n,f(iM)) \
eq 1\\) ならばその区間に因数が含まれていると分かります。従って、\\(i=0,1,2,\\ldots,M^2\\) について順に GCD を計算し、初めて \\(\\gcd(n,f(iM)) \
eq 1\\) となった区間 \\((iM,(i+1)M]\\) について愚直に素因数を探せばよいです。\\(n\\) の素因数は高々３個なので、高々２回このアルゴリズムを適用すれば \\(n\\) の素因数分解が終了します。&lt;/p&gt;
&lt;p&gt;以上のアルゴリズムでは \\(f(x)\\) の係数が大きくなりすぎます。この問題は、\\(\\gcd(n,f(iM))\\) は \\(\\bmod n\\) を取っても変化しないことに着目して、\\(\\mathbb&#123;Z&#125;/n\\mathbb&#123;Z&#125;\\) 係数で \\(f(x)\\) を計算することにより解決します。\\(\\mathbb&#123;Z&#125;/n\\mathbb&#123;Z&#125;\\) 係数 \\(d\\) 次多項式 \\(f,g\\) の掛け算は、繰り上がりが起きないよう十分 base を大きくとった整数同士の掛け算とみなすことができます。つまり、\\(n^2d\\) 次進法で \\(i\\) 桁目がそれぞれ \\([x^&#123;i-1&#125;]f,[x^&#123;i-1&#125;]g\\) の整数の掛け算として計算してもよく、\\(O(\\mathrm&#123;M_&#123;int&#125;&#125;(d\\log(n^2d))\\) で求まります。従って \\(f(x)\\) は分割統治法により \\(O(\\mathrm&#123;M_&#123;int&#125;&#125;(n^&#123;1/4&#125;\\log(n))\\log(n))\\) で計算できます。&lt;/p&gt;
&lt;p&gt;ラグランジュ補間を用いた&lt;a href="https://37zigen.com/multipoint-evaluation/"&gt;多点評価&lt;/a&gt;では mod g(x) が何度も登場しますが、\\(\\mathbb&#123;Z&#125;/n\\mathbb&#123;Z&#125;\\) には非可逆な元が存在するので mod g(x) が計算可能かは注意が必要です。mod g(x) は g(x) の最上位の項の係数が可逆ならば計算可能です。ラグランジュ補間を利用した多点評価は g(x) の最上位の係数が 1 の場合しか現れないので、mod g(x) を計算できます。従って、多点評価は可能です。&lt;/p&gt;
&lt;p&gt;GCD は掛け算より \\(O(\\log n)\\) だけ重いので、順に \\(\\gcd(n,f(iM))\\) を計算せず、分割統治によって求めます。まず葉に \\(f(iM)\\) が、葉以外の頂点に子に書かれた数の積が書かれた２分木を構築します（下図）。&lt;img class="aligncenter size-large wp-image-8917" src="https://37zigen.com/wp-content/uploads/2021/04/gcd_tree-1024x375.png" alt="" width="300"&gt;&lt;/p&gt;
&lt;p&gt;この根から、GCD が 1 にならない頂点を辿って葉に向かって \\(\\gcd(f(iM),n) \
eq 1\\) なる \\(i\\) が（存在するなら）得られます。木の高さは \\(O(\\log(n))\\) なので、全体で \\(O(\\mathrm&#123;M_&#123;int&#125;&#125;(n^&#123;1/4&#125;\\log(n))\\log(n))\\) になります。&lt;/p&gt;

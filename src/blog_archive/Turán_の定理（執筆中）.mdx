# Turán の定理（執筆中）

> 📅 **投稿日**: 2020-10-10 08:10:40

&lt;div class="statement"&gt;
Turán の定理：
頂点数 \\(n\\) のグラフのうち、\\(r\\) 頂点完全グラフ \\(K^r\\) を部分グラフに含まない辺数最大のグラフ \\(G\\) は Turán グラフ \\(T^&#123;r-1&#125;(n)\\) である。また、辺数が同じで形状が異なるグラフはない。&lt;/div&gt;
&lt;div class="proof"&gt;
&lt;b&gt;証明&lt;/b&gt;：
G が完全多部グラフであることを示す。完全多部グラフでないと仮定する。

各頂点を一つの部集合に割り当てれば、n 頂点のグラフは n 部集合に分けられる。隣接していない部集合を合体しても部集合のままであるから、隣接していない部集合がなくなるまで合体を繰り返す。完全多部グラフでないから、図のように、\\(xy_1, xy_2  \
otin E, y_1y_2 \\in E\\) となる頂点 \\(x,y_1,y_2\\) が取れる。

(i) \\( d(x) &lt; d(y_1) \\) のとき
頂点 \\(x\\) を消去して頂点 \\(y_1\\) を複製する。

(ii) \\( d(x) &lt; d(y_2) \\) のとき
頂点 \\(x\\) を消去して頂点 \\(y_2\\) を複製する。

(iii) \\( d(x) &lt; d(y_1) \\) かつ \\( d(x) &lt; d(y_2) \\) のとき
頂点 \\(y_1,y_2\\) を消去して頂点 \\(x\\) を 2 回複製する。

いずれの場合も頂点数を不変に保ったまま、辺数を増やせたので矛盾。従って G は完全多部グラフ。完全多部グラフのうち、辺数が最も多くなるのは Turan グラフのときである（後で書く）。

# 指数型母関数の解釈（錬成中）

&lt;p&gt;書くべきこと：&lt;br&gt;・重要な関数&lt;/p&gt;



&lt;p&gt;exp(x), x, 1/(1-x), log(1/(1-x))&lt;br&gt;&lt;br&gt;・掛け算&lt;br&gt;・合成&lt;br&gt;・微分 &lt;/p&gt;

&lt;p&gt;$$A(n) := \\sum_&#123;n=0&#125;^\\infty \\#\\mathcal&#123;A&#125;_n \\frac&#123;x^n&#125;&#123;n!&#125;$$&lt;/p&gt;

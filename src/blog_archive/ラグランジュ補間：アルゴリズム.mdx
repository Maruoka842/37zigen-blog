# ラグランジュ補間：アルゴリズム

> 📅 **投稿日**: 2021-03-24 00:41:13

ラグランジュ補完で、多項式補完を \\(O(n \\log(n)^2)\\) で求めるアルゴリズムを紹介します（\\(n\\) は次数）。

ラグランジュ補完とは、多項式補完の公式の一つです：
&lt;div class="statement"&gt;ラグランジュ補完：
\\(n\\) 個の相異なる点 \\(x_1, x_2, \\ldots, x_n\\) が与えられます。\\(n-1\\) 次多項式はそれぞれの点で \\(f(x_i) = y_i\\) です。このとき、\\(f\\) は中国剰余定理より一意に定まり、
$$f(x)=\\sum_&#123;i=1&#125;^n y_i\\frac&#123;\\prod_&#123;j \
eq i&#125;(x-x_i)&#125;&#123;\\prod_&#123;j \
eq i&#125;(x_i-x_j)&#125;$$と書けます。この式をラグランジュ補完といいます。&lt;/div&gt;
ラグランジュ補完は愚直だと \\(O(n^2)\\) で求まります。

各 \\(i=1,2,\\ldots,n\\) に対して、\\(\\prod_&#123;j \
eq i&#125;(x_i-x_j)\\) は \\(O(n)\\) で求まります。\\(g(x):=\\prod_&#123;i=1&#125;^n (x-x_i)\\) を求めておけば、各 \\(i=1,2,\\ldots,n\\) に対して、\\(\\prod_&#123;j \
eq i&#125;(x-x_i) = \\frac&#123;g(x)&#125;&#123;x-x_i&#125; \\) は \\(O(n)\\) で求まります。両方合わせて、全体で \\(O(n^2)\\) です。
[toc]
&lt;h2&gt;アルゴリズム&lt;/h2&gt;
\\(g(x):=\\prod_&#123;i=1&#125;^n (x-x_i)\\) と置くと、ラグランジュ補完は$$f(x) = g(x)\\sum_&#123;i=1&#125;^n \\frac&#123;y_i&#125;&#123;g'(x_i)(x-x_i)&#125;$$と書けます。\\(g'(x_1), g'(x_2), \\ldots, g'(x_n)\\) は &lt;a href="https://37zigen.com/multipoint-evaluation/"&gt;multipoint evaluation&lt;/a&gt; により \\(O(n\\log(n)^2)\\) で計算できます。

\\(a_i := y_i / g'(x_i)\\) と置きます。サイズ半分の二つの同じ問題に分けられます：$$\\sum_&#123;i=1&#125;^n a_i/(x-x_i) = \\sum_&#123;i=1&#125;^&#123;\\lfloor n/2 \\rfloor&#125; a_i/(x-x_i)  +  \\sum_&#123;i=\\lfloor n/2 \\rfloor + 1&#125;^&#123;n&#125; a_i/(x-x_i)$$それぞれ、分母分子は高々次数 \\(n/2\\) の多項式なので、2つの部分問題の結果を通分するのは \\(O(n\\log(n))\\) でできます。\\(\\sum_&#123;i=1&#125;^n a_i/(x-x_i)\\) を通分するのに必要な計算量を \\(T(n)\\) とすると漸化式 \\(T(n) = 2T(n/2) + O(n\\log(n))\\) が成り立ちます。漸化式を解いて、\\(T(n) = O(n\\log(n)^2)\\) です。

全体で \\(O(n\\log(n)^2)\\) です。

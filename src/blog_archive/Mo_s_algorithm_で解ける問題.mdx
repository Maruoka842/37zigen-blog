# Mo's algorithm で解ける問題

> 📅 **投稿日**: 2022-03-19 05:32:31

Mo's algorithm は、\\(f(l, r)\\) から \\(f(l+dx, r+dy)\\) が \\(d=|dx|+|dy|\\) として、\\(O(d+N/\\sqrt&#123;Q&#125;)\\) に求まるとき \\(f(l, r)\\) (\\(0 \\leq l, r \\leq N\\)) を求めよというクエリがオフラインで \\(O(N\\sqrt&#123;Q&#125;+Q\\log(Q))\\) で処理できる。

2次元平面の与えられた点を全て通る walk について、マンハッタン距離での最短化の近似アルゴリズムと考えることができる。\\((iN/\\sqrt&#123;Q&#125;, jN/\\sqrt&#123;Q&#125;)\\) (\\(i,j \\in [\\sqrt Q]\\)) を訪れろというインスタンスは \\(O(N\\sqrt&#123;Q&#125;)\\) かかるため最悪計算量の観点では最適である。画像のような与えられた点を葉に持つ木を取り、その上をオイラーツアーすればよい。&lt;img class="aligncenter  wp-image-17203" src="https://37zigen.com/wp-content/uploads/2022/03/mo-algorithm.png" alt="" width="271" height="222" /&gt;\\((-1, 0), (0, -1)\\) 方向への移動は、履歴を roll back することで \\((1, 0), (0, 1)\\) 方向への移動と同じ計算量で（原理的には）必ずできる。従って、Moが適用できるか考察する際には、\\((1, 0), (0, 1)\\) 方向への移動だけ考えればよい。木の構造を左右反転すれば、\\((-1, 0), (0, 1)\\) 方向への移動だけにする子もできる。点の移動順をヒルベルト曲線上で訪れる順にしても同じ計算量が達成できる。これは cache oblivious と発想が近い。
&lt;h3&gt;処理できるクエリの例&lt;/h3&gt;
&lt;ul&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\)の最頻値&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\)の k 番目に小さい値&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\)で同じ数をペアにしたとき、何個のペアができるか。(ABC242G)&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\)には何種類の数があるか。(ABC174F)&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\)の総積の約数の個数(dwacon2017e)&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\)の和がKになる部分列の個数（&lt;a href="https://codeforces.com/contest/877/problem/F?locale=en"&gt;CF442F&lt;/a&gt;）&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\)に含まれる、同じ要素が複数回現れない連続部分列の個数（&lt;a href="https://www.hackerrank.com/contests/101hack52/challenges/car-show"&gt;Hackensack 101 Hack 52 C&lt;/a&gt;）&lt;/li&gt;
 	&lt;li&gt;fをO(1)次方程式とする。\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\) に出現する各値の登場回数 x について、f(x) の和を求めよ。&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\) に現れる値 \\(v\\) とその出現回数 \\(c\\) の積 \\(vc\\) の最大値を \\(O(Q N^&#123;1/2&#125;)\\) で求めよ（JOI歴史の研究）。&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\) について、各値 \\(v\\) に出現回数 \\(c\\) との積 \\(vc\\) を割り当てる。この値の最大値と最小値の差 \\(x\\) が最小になるように \\(k\\) 項選ぶ。\\(x\\) の値を求めよ。(&lt;a href="https://codeforces.com/contest/1476/problem/G"&gt;CF1476&lt;/a&gt;)&lt;/li&gt;
 	&lt;li&gt;\\(\\sum_&#123;k=l_i&#125;^&#123;r_i&#125;&#123;n_i \\choose k&#125;\\) を求めよ。&lt;/li&gt;
 	&lt;li&gt;n 頂点の木が与えられる。各頂点 i には色 \\(v_i\\in [n]\\) が割り当てられている。\\(w_i\\)を根とする部分木に含まれる色の種類数を求めよ。&lt;/li&gt;
 	&lt;li&gt;n 頂点の木が与えられる。各頂点 i には色 \\(v_i\\in [n]\\) が割り当てられている。\\(u_i\\)-\\(w_i\\)パスに含まれる色の種類数を求めよ。&lt;/li&gt;
 	&lt;li&gt;\\(a_&#123;l&#125;,\\ldots,a_&#123;r&#125;\\) の転倒数を\\(O(QN^&#123;1/2&#125;)\\)で求めよ。&lt;/li&gt;
&lt;/ul&gt;

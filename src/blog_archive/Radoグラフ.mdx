# Radoグラフ

> 📅 **投稿日**: 2020-10-25 18:13:57

次の条件を満たす可算グラフ \\(R\\) を Rado グラフという。
条件★：
\\(U,W\\) が \\(R\\) の交わらない有限集合ならば、全ての \\(U\\) の頂点に隣接し、全ての \\(W\\) の頂点に隣接しない頂点 \\(v \\in R-U-W\\) が存在する。
&lt;div class="statement"&gt;任意の頂点集合の分割 \\(V(G)=P \\coprod Q\\) に対して、\\(P,Q\\) の誘導する部分グラフ \\(G[P],G[Q]\\) のどちらかが \\(G\\) と同型になるグラフは \\(K^&#123;\\aleph&#125;\\)、\\(\\overline&#123;K^&#123;\\aleph&#125;&#125;\\) を除いて Rado グラフしかない。&lt;/div&gt;
&lt;div class="proof"&gt;&lt;b&gt;証明：&lt;/b&gt;まず Rado グラフがどのように頂点を分割しても一方には Rado グラフができることを示す。\\(V = V_1 \\coprod V_2\\) のうち、\\(G[V_1],G[V_2]\\) の両方が Rado グラフでない、つまりそれぞれ、\\(U_1,W_1\\)、\\(U_2,W_2\\) について条件★を満たさないとする。すると、グラフ R は条件★を\\(U_1 \\cup U_2, W_1 \\cup W_2\\) について満たさないから矛盾。

自分以外の全ての頂点と隣接する頂点を集めた頂点集合 \\(V_1\\) が空集合でないとする。残りの頂点集合を \\(V_2\\) とする。\\(G \
ot\\cong G[V_2]\\) より \\(G \\cong G[V_1]\\) である。よってこのとき \\(G \\cong K^&#123;\\aleph&#125;\\) である。

孤立頂点を集めた頂点集合 \\(V_1\\) が空集合でないとする。残りの頂点集合を \\(V_2\\) とする。\\(G \
ot\\cong G[V_2]\\) より \\(G \\cong G[V_1]\\) である。よってこのとき \\(G \\cong \\overline&#123;K^&#123;\\aleph&#125;&#125;\\) である。

以上から \\(G \
ot\\cong K^&#123;\\aleph&#125;,G \
ot\\cong \\overline&#123;K^&#123;\\aleph&#125;&#125;\\) ならば「自分以外の頂点全てと隣接する頂点」「自分以外の頂点全てと隣接しない頂点」は存在しないと仮定してもよい。

★を満たさない \\(\\mid U \\cup W \\mid\\) 最小の \\(U,W\\) を取ってくる。

\\(U \
eq \\emptyset\\) だとする。\\(u \\in U\\) を一つ固定する。\\(u\\) および \\(u\\) と非隣接な \\(V-U-W\\) の頂点の集合を \\(V_1\\) 、残りを \\(V_2\\) とする。\\(G \
ot\\cong G[V_1]\\) より \\(G \\cong G[V_2]\\) である。\\(\\mid U \\cup W \\mid\\) の最小性から \\(G[V_2]\\) において \\(U-\\&#123;u\\&#125;, W\\) について★を満たす頂点 \\(v\\) が存在。ところで \\(V_2\\) は \\(u\\) と隣接する頂点の集合だから、\\(G\\) において \\(U,W,v\\) は★を満たし矛盾。\\(G\\) は Rado グラフである。

\\(U = \\emptyset\\) だとする。\\(w \\in W\\) を一つ固定する。\\(w\\) および w と隣接する \\(V-U-W\\) の頂点の集合を \\(V_1\\)、残りを \\(V_2\\) とする。\\(G \
ot\\cong G[V_1]\\) より \\(G \\cong G[V_2]\\) である。\\(\\mid U \\cup W \\mid\\) の最小性から \\(G[V_2]\\) において \\(U, W-\\&#123;w\\&#125;\\) について★を満たす頂点 \\(v\\) が存在。ところで \\(V_2\\) は \\(u\\) と非隣接な頂点の集合だから、\\(G\\) において \\(U,W,v\\) は★を満たし矛盾。\\(G\\) は Rado グラフである。

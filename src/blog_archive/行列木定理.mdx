# 行列木定理

> 📅 **投稿日**: 2022-09-22 02:10:53

無向グラフ \\(G\\) とその向き付け \\(\\mathfrak&#123;o&#125;\\) に対して、接続行列 \\(M(G)\\) を
\\begin&#123;eqnarray&#125;
M_&#123;i, j&#125; =
\\begin&#123;cases&#125;
1 &amp; (辺 e_j は向き付け \\mathfrak&#123;o&#125; の下、頂点 v_i を始点に持つ) \\\\
-1 &amp; (辺 e_j は向き付け \\mathfrak&#123;o&#125; の下、頂点 v_i を終点に持つ) \\\\
0 &amp; (\\text&#123;otherwise&#125;)
\\end&#123;cases&#125;
\\end&#123;eqnarray&#125;
として定義する。このとき、\\(L(G) = MM^T\\) は\\begin&#123;eqnarray&#125;
L_&#123;i, j&#125; =
\\begin&#123;cases&#125;
-m_&#123;i,j&#125; &amp; (i \
eq j で、頂点 i,j 間に m_&#123;i,j&#125; 本の辺がある) \\\\
d(i) &amp; (i = j で頂点iに接続する辺の個数が d(i) である) \\\\
\\end&#123;cases&#125;
\\end&#123;eqnarray&#125;となる。\\(L\\) をラプラシアン行列と呼ぶ。
&lt;div class="statement"&gt;行列木定理：\\(G\\) を自己ループのない無向グラフ、\\(G\\) の全域木の個数を \\(\\kappa(G)\\) とする。とする。\\(L_&#123;v&#125;\\) を \\(L\\) から \\(v\\) で番号づけられた行と列を除いた小行列とすると、$$\\det(L_&#123;v&#125;) = \\kappa(G)$$ が成り立つ。この値は \\(v\\) や \\(\\mathfrak&#123;o&#125;\\) の選び方に依らない。&lt;/div&gt;
&lt;div class="proof"&gt;証明：\\(M\\) は任意の小行列の行列式が \\(0, \\pm 1\\) になる。この性質を完全ユニモジュラという。特に、頂点集合 \\(U\\)、辺集合 \\(F\\) で添え字付けられた行・列からなる小行列 \\(A\\) が \\(\\det(A) = \\pm 1\\) となるための必要十分条件（あとで示す）は
&lt;ul&gt;
 	&lt;li&gt;\\(F\\) からなる無向基礎グラフは \\(V(G) \\setminus U\\) の頂点を根とする森になる。&lt;/li&gt;
 	&lt;li&gt;\\(U\\) は \\(F\\) の辺で被覆されている。&lt;/li&gt;
&lt;/ul&gt;
である。この事実を認めると、\\(L_v\\) において \\(F\\) は \\(v\\) を根とする森、つまり、木になる。従って、コーシー・ビネの定理より、
\\begin&#123;align&#125;
\\det(L_v) &amp;= \\det(M_vM_v^T) \\\\
&amp;= \\sum_S \\det(&#123;M_v&#125;^S)^2 \\\\
&amp;= \\kappa(G) \\\\
\\end&#123;align&#125;となる。ただし、\\(M_v\\) は頂点 \\(v\\) で番号づけられた行・列を \\(M\\) から取り除いた小行列、\\(M_v^S\\) は \\(M_v\\) から辺集合 \\(S\\) で番号づけられた列を取り出した小行列である。

&lt;/div&gt;
証明することなく使った次の事実を示す。
&lt;div class="statement"&gt;無向基礎グラフを向きづけた接続行列 \\(M\\) は任意の小行列の行列式が \\(0, \\pm 1\\) になる。特に、頂点集合 \\(U\\)、辺集合 \\(F\\) で添え字付けられた行・列からなる小行列 \\(A\\) が \\(\\det(A) = \\pm 1\\) となるための必要十分条は
&lt;ul&gt;
 	&lt;li&gt;\\(F\\) からなる無向基礎グラフが \\(V(G) \\setminus U\\) の頂点を根とする森になる。&lt;/li&gt;
 	&lt;li&gt;\\(U\\) は \\(F\\) の辺で被覆されている。&lt;/li&gt;
&lt;/ul&gt;
である。

&lt;/div&gt;
&lt;div class="proof"&gt;証明：行列式が非零になるには、各頂点に辺を一つずつ割り当てなければならない。閉路以外の頂点に割り当てる辺は、葉から貪欲に一意に定まる。頂点が順に \\(v_0, v_1, \\ldots\\) である閉路は、頂点 \\(v_i\\) に辺 \\(\\&#123;v_i, v_&#123;i+1&#125;\\&#125;\\) を割り当てる方法と、辺 \\(\\&#123;v_i, v_&#123;i-1&#125;\\&#125;\\) を割り当てる方法の二通りがある。いくつかある閉路のうち、頂点ラベルが辞書順最小の閉路の辺の向きを反転する操作 \\(\\phi\\) を考える（閉路の辺を巡回置換する）。偶閉路の場合、置換の偶奇が反転し、辺の向き(±1)の積は不変。奇閉路の場合、置換の偶奇は不変だが、辺の向き(±1)の積は反転する。従って、\\(\\phi\\) は、閉路がある場合、行列式の符号を反転させる。\\(\\phi\\) は二回行うと元に戻るので、閉路のあるグラフはペアをなし、行列式が打ち消される。従って、森だけが残る。あるいは、\\(A\\) の核はサイクル空間になっていて、その像の次元が \\(|E|-|V|+(連結成分の数) &gt; 0\\) になっていることから、行列式が 0 になることが分かる。&lt;/div&gt;

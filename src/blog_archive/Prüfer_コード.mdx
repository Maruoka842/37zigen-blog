# Prüfer コード

> 📅 **投稿日**: 2020-10-27 02:22:43

Prüfer コード（Prüfer 列）とは、ラベル付き木を全単射に変換した一種の数列である。ラベル付き木を数えやすい対象に変換でき、木の数え上げに威力を発揮する。[toc]
&lt;h2&gt;Prüfer コードの定義&lt;/h2&gt;
頂点集合 \\(V=\\&#123;1,2,\\ldots,n\\&#125;\\) からなり、頂点 \\(n\\) を根とするラベル付き木 \\(T\\) を考える。木 \\(T\\) に対する Prüfer code を以下のよう生成される頂点列 \\(\\mathcal&#123;P&#125;(T)=(y_1,y_2,\\ldots,y_&#123;n-2&#125;)\\) として定義する。
&lt;ul&gt;
 	&lt;li&gt;以下の操作を \\(k=1,2,\\ldots,n-1\\) について順に行う。
&lt;ol&gt;
 	&lt;li&gt;\\(T\\) のラベル最小の葉を \\(x_k\\), その親を \\(y_k\\) とする。&lt;/li&gt;
 	&lt;li&gt;\\(T \\leftarrow T_k-x_k\\)&lt;/li&gt;
&lt;/ol&gt;
&lt;/li&gt;
&lt;/ul&gt;
※ \\(y_&#123;n-1&#125;=n\\) は Prüfer コードには含まない。

&lt;h2&gt;Prüfer コードの全単射性&lt;/h2&gt;
\\(n\\) 頂点ラベル付き木全体から \\(V^&#123;n-2&#125;\\) への写像 \\(\\mathcal&#123;P&#125;\\) が全単射であることを示したい。異なる木は異なる Prüfer コードを生成するから \\(\\mathcal&#123;P&#125;\\) は単射である。全射であるには、木をなすように \\((y_i)\\) から \\((x_i)\\) が一意に復元できればよい。\\(x_1,x_2,\\ldots,x_k\\) まで復元できたとする。木 \\(T_&#123;k+1&#125;\\) について、\\(x_1,x_2,\\ldots,x_k\\) はすでに削除された頂点、\\(y_&#123;k+1&#125;,y_&#123;k+2&#125;,\\dots,y_&#123;n-1&#125;\\) は葉となりえない頂点、その他の頂点は葉である。従って、\\(S=\\&#123;x_1,x_2,\\ldots,x_k\\&#125;\\cup\\&#123;y_&#123;k+1&#125;,y_&#123;k+2&#125;,\\ldots,y_&#123;n-1&#125;\\&#125;\\) に含まれないラベル最小の頂点が \\(x_&#123;k+1&#125;\\) として定まる。\\(|S| &lt; n\\) であるからこのような頂点は必ず取れる。以上より \\((y_i)\\) から \\((x_i)\\) が一意に復元できたから、\\(\\mathcal&#123;P&#125;\\) は全単射であることが示された。

Prüfer コードの応用例として最も有名なのは次の定理だろう。
&lt;div class="statement"&gt;Cayley の定理：\\(n\\) 頂点ラベル付き木は \\(n^&#123;n-2&#125;\\) 個ある。&lt;/div&gt;
\\(\\mathcal&#123;P&#125;\\) は \\(n\\) 頂点ラベル付き木全体から \\(V^&#123;n-2&#125;\\) への全単射であるから、この定理が成り立つ。

次のような数え上げの問題も Prüfer コードによって処理できる。
&lt;div class="statement"&gt;問題１：\\(n\\) 頂点ラベル付き木であって、各頂点 \\(i\\) の次数が \\(d_i\\) \\((1\\leq i \\leq n)\\) である木はいくつあるか。&lt;/div&gt;
次数 \\(d\\) の頂点はちょうど \\(d-1\\) 回 Prüfer コードに出現するから、\\(&#123;n-2 \\choose d_1-1,d_2-1, \\ldots ,d_n-1&#125;\\) 通り存在する。
&lt;h2&gt;葉を同時に取り除く亜種&lt;/h2&gt;
次のような流儀もあり、全単射になる（&lt;a href="https://www.sciencedirect.com/science/article/pii/S1071579705000183"&gt;M.C. Crabb. Counting nilpotent endomorphisms. Finite Fields and Their Applications, 12 (2006), 151-154.&lt;/a&gt;）。
&lt;ul&gt;
 	&lt;li&gt;以下の操作を \\(k=1\\) から始めて、\\(k = n\\) となるまで行う。
&lt;ol&gt;
 	&lt;li&gt;\\(T\\) に \\(l\\) 個の葉 \\(x_k, x_&#123;k + 1&#125;, \\ldots, x_&#123;k+l&#125;\\) （昇順）があるとする。各葉の親を \\(y_k, y_&#123;k+1&#125;, \\ldots, y_&#123;k + l&#125;\\) とする。&lt;/li&gt;
 	&lt;li&gt;\\(T \\leftarrow T_k-x_k-x_&#123;k+1&#125;-\\cdots-x_&#123;k+l&#125;, k \\leftarrow k + l\\)&lt;/li&gt;
&lt;/ol&gt;
&lt;/li&gt;
&lt;/ul&gt;
\\(V=\\mathbb&#123;F&#125;_q^n\\) とする。\\(f : [n-1] \\to V^&#123;n-1&#125;\\) の個数と 冪零線形写像 \\(V \\to V\\) に全単射があり、その個数は \\(q^&#123;n(n-1)&#125;\\) 個である。冪零線形写像 fgが与えられたとする。\\(V_i=g^i(V)\\) と置く。\\(r\\) を \\(V_r = O\\) となる最小の正整数とする。\\(V_0\\) における \\(V_1\\) の直行補空間の基底であって、辞書順最小のもの \\((x_1, x_2, \\ldots, x_k) \\in V^k\\) が一意に定まる。これは、列基本変形をすればよい。\\(f(i) = g(x_i)\\) として、再帰的に処理する。&lt;h2 style="text-align: center;"&gt;問題演習&lt;/h2&gt;
&lt;div class=" statement"&gt;問題２：葉が \\(m\\) 個ある \\(n\\) 頂点ラベル付き根付き木はいくつあるか（根は頂点 \\(n\\) とする）。&lt;/div&gt;
解答：\\(m\\) 個の葉が Prüfer コードに出現しないから \\(&#123;n-1 \\choose m&#125;\\sum_&#123;i=0&#125;^&#123;n-1-m&#125;&#123;n-1-m \\choose i&#125;(-1)^i(n-m-i)^&#123;n-2&#125;\\) 個。
&lt;div class=" statement"&gt;問題３：根の次数が \\(m\\) であるラベル付き木はいくつあるか（根は頂点 \\(n\\) とする）。&lt;/div&gt;
解答：根 \\(n\\) が \\(m-1\\) 回 Prüfer コードに出現するから \\(&#123;n-2 \\choose m-1&#125;(n-1)^&#123;n-m-1&#125;\\) 個。
&lt;div class="statement"&gt;問題４： 頂点にラベルが付いた \\(n\\) 頂点 \\(m\\) 辺の森が与えられる。\\(n-1-m\\) 辺追加してできる木は何通りあるか。（出典：&lt;a href="https://twitter.com/KOKTOSbot/status/1269711089542983680"&gt;碧@KOKTOSbot&lt;/a&gt;）&lt;/div&gt;
解答：森の各連結成分 \\(G_i\\) を縮約して 1 頂点にしたグラフを \\(G'\\) とする。\\(G'\\) の各頂点にはラベル \\(1,2,...,n-m\\) を付ける。Prüfer コード \\(P(T)=(y_1,...,y_&#123;n-m-2&#125;)\\) は \\(V(G')^&#123;n-m-2&#125;\\) への全単射で、次数 \\(d(v)\\) の頂点 \\(v\\) は \\(y_1,...,y_&#123;n-m-2&#125;\\) に \\(d(v)-1\\) 回出現する。また、縮約を解いた際、\\(G'\\) の頂点 \\(i\\) に接続する辺は、 \\(G\\) において \\(|G_i|\\) 通りの端点の接続方法がある。したがって \\((\\prod|G_i|)(\\sum|G_i|)^&#123;n-m-2&#125;=n^&#123;n-m-2&#125;\\prod|G_i|\\) が答え。
&lt;div class="statement"&gt;問題： \\([n]\\) 上のグラフであって、頂点 \\(1, 2, \\ldots, k\\) を根とする \\(k\\) 個の根付き木であるものの個数&lt;/div&gt;
\\(kn^&#123;n-k-1&#125;\\)通り。Pruferコードの構成で、頂点が \\(1,2,\\ldots,k\\) のみになるまで頂点の除去を行うとき、最後に取り除かれた頂点の親が \\(1,2,\\ldots,k\\) の \\(k\\) 通りあることに注意。\\(f=x\\exp(x)\\)として\\([x^n/n!] f^k = [x^&#123;n-1&#125;/(n-1)!]k\\left(\\frac&#123;x&#125;&#123;f^&#123;\\langle -1 \\rangle&#125;&#125;\\right)^&#123;n-k&#125;\\) を用いてもよい。

また、次のような示し方もある。\\(p_k\\) を \\(k\\) 個の連結成分からなる根付き森の個数とする。\\(np_k=k&#123;n \\choose k&#125; n^&#123;n-k&#125;\\) を示せばよい。
&lt;ul&gt;
 	&lt;li&gt;左辺：根付き森の頂点 \\(v\\) を自由に選ぶ。\\(v\\) が含まれる連結成分の根を \\(r\\) とする。\\(v\\) を根とする部分木を切り離す。\\(vP r^&#123;\\circ&#125;\\) パスをサイクル分解の標準形と思う。&lt;/li&gt;
 	&lt;li&gt;右辺：k 個の根付き木と、いくつかの functional graph があり、どれか一つの根 v にマークを付ける場合の数。functional graph のサイクルをサイクル分解の標準形で並べてから、末尾に \\(v\\) を繋げる。&lt;/li&gt;
&lt;/ul&gt;
&lt;div class="statement"&gt;任意のcircuitの長さが素数の単純グラフの個数は？&lt;a href="https://atcoder.jp/contests/abc387/tasks/abc387_g"&gt;ABC387G&lt;/a&gt;&lt;/div&gt;
&lt;div class="statement"&gt;頂点ラベル付き木のEGFを頂点ラベル付き根付き木のEGFで表せ&lt;/div&gt;
頂点ラベル付きの木の EGF g は、頂点ラベル付き根付き木のEGF f を用いて \\(g = f-\\frac&#123;1&#125;&#123;2&#125;f^2\\) と表せる（&lt;a href="https://arxiv.org/abs/math/0311259"&gt;David Callan&lt;/a&gt;）。


証明（解析的）：\\(f = x \\exp(f), f = xg'\\) である。
\\(f=x \\frac&#123;dg&#125;&#123;dx&#125;\\) に \\(x = f \\exp(-f)\\) を代入して
\\(\\exp(f) = \\frac&#123;dg&#125;&#123;dx&#125;\\)。
\\begin&#123;align&#125;
\\frac&#123;dg&#125;&#123;dx&#125; &= \\frac&#123;dg&#125;&#123;df&#125;\\frac&#123;df&#125;&#123;dx&#125; \\\\
&= \\frac&#123;dg&#125;&#123;df&#125;\\left(\\frac&#123;dx&#125;&#123;df&#125;\\right)^&#123;-1&#125; \\\\
&= \\frac&#123;dg&#125;&#123;df&#125; \\frac&#123;\\exp(f)&#125;&#123;1-f&#125; \\\\
\\end&#123;align&#125;
を代入して \\(\\frac&#123;dg&#125;&#123;dx&#125; = 1-f\\) となり、これを解いて \\(g = f-\\frac&#123;1&#125;&#123;2&#125;f^2\\)。

証明（全単射）：\\(g + \\frac&#123;1&#125;&#123;2&#125;f^2 = f\\) を全単射で示す。木の中心が一つの場合をまず考える。\\(g\\) は木の中心を根とする木の個数。\\(\\frac&#123;1&#125;&#123;2&#125; g^2\\) は木の辺uvを選び、\\(u,v\\) のうち中心から遠い方を根とする木の個数。木の中心が二つの場合も同様にできる。
&lt;div class="statement"&gt;問題：根付き森 \\(F\\) に対して \\(l(F)\\) を連結成分の個数とする。\\(f(G, x) = \\sum_&#123;F&#125; x^&#123;l(F)-1&#125;\\) と置く。ただし、和は \\(G\\) の根付き全域森 \\(F\\) 全体を渡る。包除原理より
\\begin&#123;align&#125;
f(\\overline G, x) =&amp; \\sum_&#123;F&#125;\\sum_k (-1)^&#123;n-l&#125; &#123;l - 1\\choose k - 1&#125;n^&#123;l-k&#125;x^k \\\\
=&amp; (-1)^&#123;n-1&#125;f(G, -x-n)
\\end&#123;align&#125;
完全グラフや完全多部グラフの全域木の個数が簡単に計算できる（Enumerative Combinatorics 2.27）。&lt;/div&gt;
無向グラフ \\(G\\) のラプラシアンの固有多項式 \\(f\\) について、\\(g(G, x) = f(-x)/(-x)\\) と置くと
\\(g(G, x) = (-1)^&#123;n-1&#125; \\sum x^&#123;l(F)-1&#125; \\) であることが、行列木定理から分かる。ただし、和は根付き森F全体を渡り、l(F)はFの連結成分の個数。代数的な計算により補グラフ\\( \\overline G\\)のラプラシアンの固有値は、\\(G\\) の固有値 \\(0, \\lambda_1, \\lambda_2, \\ldots, \\lambda_&#123;n-1&#125;\\) に対して、\\(0, n-\\lambda_1, n-\\lambda_2, \\ldots, n-\\lambda_&#123;n-1&#125;\\) となることが分かる。従って、\\(g(\\overline G, x)=(-1)^&#123;n-1&#125;g(G, -n-x)\\) が成り立つ。これは、包除により導出できる。

\\begin&#123;align&#125;
&amp;(-1)^&#123;n-1&#125; g(G,n-x) \\\\
=&amp;  \\sum (n-x)^&#123;l(F)-1&#125; \\\\
=&amp; (-1)^&#123;n-1&#125; \\sum &#123;l(F)-1 \\choose i-1&#125;x^&#123;i-1&#125; n^&#123;l(F)-i&#125; (-1)^&#123;n-l(F)&#125;
\\end&#123;align&#125;
この式を、補グラフに含まれない辺集合E(F)に関する包除原理と見ます。Σの中身が、Fを部分グラフとして含む、i個の木からなる根付き木の個数×(±1)です。

Pruferコードで葉を順番に削除したとき、一番最後に削除する葉の親の選び方がn通り（親の連結成分に含まれるFの根を引き続き根として採用）、その他の根の選び方が \\(&#123;l(F)-1 \\choose i-1&#125;\\)通り（Fの根を再利用）、Pruferコードで削除する最後以外の葉の親の選び方が\\(n^&#123;l(F)-i-1&#125;\\)通りです。

従って、
\\(g(\\overline G, x)=(-1)^&#123;n-1&#125;g(G, -n-x)\\)
となります。
&lt;div class="statement"&gt;問題５：ラベル付き木をランダムに生成したとき、各頂点の次数の 2 乗の期待値はいくつか。&lt;/div&gt;
解答：問題１より、各頂点 \\(i\\) の次数が \\(d_i\\) であるラベル付き木の総数は \\((\\sum_&#123;i=1&#125;^n x_i)^&#123;n-2&#125;\\) の \\(\\prod_&#123;i=1&#125;^n x_i^&#123;d_i-1&#125;\\) の係数に等しい。従って、\\(\\left(\\frac&#123;d&#125;&#123;dx&#125;x\\right)^2(x+\\sum_&#123;i=2&#125;^&#123;n&#125; 1)^&#123;n-2&#125;\\) に \\(x=1\\) を代入してラベル付き木の総数 \\(n^&#123;n-2&#125;\\) で割った \\((5-\\frac&#123;6&#125;&#123;n&#125;)(1-\\frac&#123;1&#125;&#123;n&#125;)\\) が答え。
&lt;div class="statement"&gt;問題６：ラベル付き完全 \\(m\\) 部グラフ \\(K_&#123;n_1,\\ldots,n_m&#125;\\) の全域木 \\(T\\) はいくつあるか。（出典：[2]）&lt;/div&gt;
\\(m=2\\) のとき \\(n_1^&#123;n_2-1&#125;n_2^&#123;n_1-1&#125;\\)通り、\\(m=n\\) のとき \\(n^&#123;n-2&#125;\\) 通りであることは通常のPrüferコードから分かる。
解答：全域木 \\(T\\) のコード \\(\\mathcal&#123;P'&#125;(T)=(\\sigma_1,\\sigma_2,\\ldots,\\sigma_k,\\sigma_\\infty) \\in W_1^&#123;n_1-1&#125; \\times W_2^&#123;n_2-1&#125;\\times \\ldots \\times W_k^&#123;n_k-1&#125; \\times V^&#123;m-2&#125; \\) を次のように構成する。
&lt;ol type="i"&gt;
 	&lt;li&gt;\\((\\sigma_1,\\sigma_2,\\ldots,\\sigma_k,\\sigma_\\infty):=(\\emptyset,\\emptyset,\\ldots,\\emptyset,\\emptyset)\\)&lt;/li&gt;
 	&lt;li&gt;\\(T_1:=T\\)&lt;/li&gt;
 	&lt;li&gt;以下の操作を \\(k=1,2,\\ldots,n-1\\) について行う。
&lt;ol&gt;
 	&lt;li&gt;\\(T_k\\) のラベル最小の葉を \\(v\\) 、その親を \\(p\\) 、\\(v\\) の属する部集合を \\(V_a\\) とする。&lt;/li&gt;
 	&lt;li&gt;\\(T_k\\) において \\(V_a = \\&#123;v\\&#125;\\) ならば \\(\\sigma_\\infty\\) の末尾、 さもなくば \\(\\sigma_a\\) に \\(p\\) を追加する。&lt;/li&gt;
 	&lt;li&gt;\\(T_&#123;k+1&#125;:=T_k-v\\)&lt;/li&gt;
&lt;/ol&gt;
&lt;/li&gt;
&lt;/ol&gt;
Prüfer コードと同様に削除済みの頂点と葉でない頂点に着目すれば次に削除される葉が分かり、全ての全域木 \\(T\\) と \\(W_1^&#123;n_1-1&#125; \\times W_2^&#123;n_2-1&#125;\\times \\ldots \\times W_k^&#123;n_k-1&#125; \\times V^&#123;n-2&#125;\\) は全単射の関係にあることが示せる。従って、\\(n^&#123;m-2&#125;\\prod(n-n_i)^&#123;n_i-1&#125;\\) が答え。また、\\(f(G+H,x)=xf(G,x)f(H,x)\\) を用いると \\(K_1, nK_1, K^n = \\overline&#123;nK_1&#125;, K_&#123;a,b,\\ldots&#125; = \\overline &#123;K^a + K^b+\\cdots&#125;\\) の順で求まる。
&lt;div class="statement"&gt;問題７： \\(k\\) 木を次のように再帰的に定義されるグラフとする。
&lt;ol type="i"&gt;
 	&lt;li&gt;\\(k\\) 頂点完全グラフ \\(K^&#123;k&#125;\\) は \\(k\\) 木である。&lt;/li&gt;
 	&lt;li&gt;\\(k\\) 木 \\(G\\) の部分グラフ \\(H \\cong K^k\\) の各頂点と隣接する新たな頂点を \\(G\\) に加えたグラフは \\(k\\) 木である。&lt;/li&gt;
&lt;/ol&gt;
\\(n\\) 頂点ラベル付き \\(k\\) 木は何通りあるか。（出典：[3]）

&lt;/div&gt;
\\(k=1\\) のときは根付き全域木の数え上げになる。
解答：頂点 \\(v\\) とその隣接頂点の集合 \\(N(v)\\) が誘導する部分グラフが \\(K^k\\) と同型であるとき、頂点 \\(v\\) を k-leaf と呼ぶことにする。 Prüfer コードに倣って \\(k\\) 木 \\(G\\) に関する頂点の列 \\(a\\) と頂点集合の列 \\(B\\) を次のように作ろう。
&lt;ol type="i"&gt;
 	&lt;li&gt;\\(G_1:=G\\)&lt;/li&gt;
 	&lt;li&gt;以下の操作を \\(i=1,2,\\ldots,n-k\\) について行う。
&lt;ol&gt;
 	&lt;li&gt;\\(G_i\\) のラベル最小の k-leaf を \\(a_i\\), その隣接頂点の集合を \\(B_i\\) とする。&lt;/li&gt;
 	&lt;li&gt;\\(G_&#123;i+1&#125;:=G_i-a_i\\)&lt;/li&gt;
&lt;/ol&gt;
&lt;/li&gt;
&lt;/ol&gt;
\\(G\\) に対して組 \\((a, B)\\) は単射である。この構成方法は、 \\(k\\) 木の定義にある再帰的構築の逆再生である。定義に従って \\(k\\) 木を構築するとき、k-leaf になるのは (ii) で追加された頂点のみ、また k-leaf でなくなるのは、(ii) で追加された頂点の隣接頂点のみ。\\(B_i \
eq B_&#123;n-k&#125;\\) とする。\\(B_i\\) のうち、最後に追加された頂点を \\(p_i\\) とする。\\(p_i\\) が \\(d\\) 番目に追加されたとすると、\\(\\# (B_&#123;d&#125; \\cap B_i) = k-1 \\) である。\\(B_d\\) のうち、\\(B_i\\) に含まれない唯一の頂点が、\\(B_d\\) の頂点のうち、\\(q_i\\) 番目に追加されたとする。2つの数 \\((p_i, q_i) \\in (V \\setminus B_&#123;n-k&#125;) \\times [k]\\) から \\(B_i\\) を決定できる。全単射であることは、Prüfer コードと同様にすれば示せる。
以上から \\(B_&#123;n-k&#125;\\) を選ぶ \\(n \\choose k\\) 通りも併せて \\(&#123;n \\choose k&#125;(1+k(n-k))^&#123;n-k-1&#125;\\) 通りが答え。
&lt;h2&gt;サイクル分解の標準形による導出&lt;/h2&gt;
サイクル分解の標準形でも、完全多部グラフの全域木の個数が求まる（Omer, E. "A Bijection for Spanning Trees of Complete Multipartite Graphs."）。
木の2頂点 \\(a, b\\) を自由に選び、\\(a\\) から \\(b\\) へのパスをサイクル分解の標準形とみなして、サイクルを作る。ただし、頂点のラベルは、組（属する部集合、部集合内での番号）に従って順序付ける。同じ部集合 \\(W\\) に属する２頂点 \\(x, y\\) が、サイクル分解の標準形において\\((x..y)\\) の形になるのは、\\(W\\) の頂点から始まるサイクルのうち、一番最後のサイクルだけである。また、一頂点のサイクル \\((x)\\) が現れるのも、一番最後だけである。一頂点のサイクルが高々一つしかないような functional graph は \\(\\prod ((n-n_i)^&#123;n_i&#125; + n_i(n-n_i)^&#123;n_i-1&#125;) = n^&#123;m&#125;\\prod (n-n_i)^&#123;n_i-1&#125;\\) 通りある。\\(a, b\\) の選び方が \\(n^2\\) 通りあるので、\\(n^2\\) で割ると答え。

&lt;h2&gt;葉ラベル付き木の数え上げ&lt;/h2&gt;
&lt;h3&gt;カタラン数&lt;/h3&gt;
葉ラベル付きの2n+1頂点の平面全2分木（葉がn+1個）の個数はカタラン数\\(C_n\\)を用いて \\((n+1)!C_n\\) と表せる。\\(C_n=\\frac&#123;1&#125;&#123;n+1&#125;&#123;2n\\choose n&#125;\\) を代入すると、この数は、\\([2n]\\) を順序対に分割する方法の数 \\((2n)!/n!\\) と等しい。木から分割への全単射は次の通り。ラベルがついていない頂点のうち、子が全てラベル付きの頂点で、子のラベルの最大値が最小のものを取る。この頂点に対して、まだラベルとして使われていない最小の正整数をラベルとして振る。この操作を根以外の全ての頂点がラベル付きになるまで繰り返す。各内点に対して、子のラベルを一つの順序対として、\\([2n]\\) の順序対への分割を作る。
&lt;h3&gt;ナラヤナ数&lt;/h3&gt;
葉ラベル付きの2n+1頂点の平面全2分木（葉がn+1個）のうち、左子が葉であるものの個数はナラヤナ数 \\(N(n, k)\\) を用いて \\((n+1)!N(n,k) = \\frac&#123;(n+1)!&#125;&#123;n&#125;&#123;n \\choose k&#125;&#123;n \\choose k-1&#125; = \\frac&#123;1&#125;&#123;n!&#125;&#123;n + 1 \\choose k&#125; \\frac&#123;n!&#125;&#123;(n-k)!&#125;\\frac&#123;n!&#125;&#123;(k-1)!&#125;(n-1)!\\) と書ける。一方、カタラン数の節と同様の全単射を用いると、一つ目の要素が \\(n+1\\) 以下の順序対がちょうど \\(k\\) 個あるような \\([2n]\\) の順序対への分割の個数と等しい。確かめてみよ。
&lt;h2&gt;parking function&lt;/h2&gt;
数列 \\(A \\in [n]^n\\) について、昇順に並べ替えた列 $B$ が \\(B_i \\leq i\\) を満たすとき、parking functionと呼ぶ。\\(N+1\\) 個の箱が円環に並べられていて、それぞれ箱 \\(0\\), 箱 \\(1\\), ... と呼ぶ。\\(i=1,2, \\ldots, N\\) の順に \\(A_i, A_i+1, \\ldots\\) 番目の最初に空いている箱に玉 \\(i\\) を入れる（足し算は mod (N + 1)）。操作が終了したとき、箱 \\(N + 1\\) が空いていることと、\\(A\\) が parking function であることが同値。parking function は \\((N+1)^&#123;N-1&#125;\\) 個ある。これは、サイクルシフトで同値類を作るとそのうち一つのみが parking function になることから分かる。\\(N+1\\) 頂点ラベル付き木も \\((N+1)^&#123;N - 1&#125;\\) 個あるので、両者の間には全単射が構成できるはずである。
&lt;h3&gt;bfs orderによる全単射&lt;/h3&gt;
頂点 \\(0,1,\\ldots, N\\) からなり、\\(0\\) を根とする木と parking function \\(A \\in [n]^n\\) の間に全単射を作る。木は子が左から順に小さい順に並んでいるとする。(深さ, 頂点番号) の昇順を bfs order と呼ぶ。各頂点 \\(v\\) について、親が bfs order で \\(k\\) 番目ならば、\\(A_v=k\\) とすると、全単射になる。
&lt;h3&gt;displacement と inversion&lt;/h3&gt;
玉 \\(i\\) の置かれた箱の番号 \\(B_i\\) と \\(A_i\\) の差を displacement と呼ぶ。parking function A の displacement の和を \\(\\Delta(A)\\) と置くと、長さ \\(N\\) の parking function \\(A\\) 全体について和を取った \\(\\sum q^&#123;\\Delta(A)&#125;\\) は、頂点 \\(1\\) を根とする \\(N + 1\\) 頂点の木の転倒数の母関数と等しい。全単射は次の通り。。\\(B\\) の各要素 \\(B_i\\) について、\\(B_i &lt; B_j\\) を満たす最小の \\(i &lt; j\\) を取り、\\(B_j\\) を親、\\(B_i\\) を子とする。そのような \\(j\\) が存在しなければ、\\(0\\) を親とする。そのようにしてできた木に対して、bfs ordering で次のような処理をする。頂点 \\(v\\) の displacement が \\(d\\) だとする。\\(v\\) の部分木に対して、\\(v\\) を部分木内で \\(d + 1\\) 番目に大きい要素と交換した後、\\(v\\) 以外の要素を、交換前の順序を保つように入れ替える。
&lt;h3&gt;木の転倒数の母関数&lt;/h3&gt;
頂点集合 \\([n]\\) 上の連結グラフ \\(G\\) の辺の数に関する母関数 \\(C_n(t) = \\sum_G t^&#123;||G||&#125;\\) は \\(1\\) を根とする頂点集合 \\([n]\\) 上の木の転倒数に関する母関数 \\(I_n(t)\\) と
\\(t^&#123;n-1&#125;I_n(1+t) = C_n(t)\\) の関係にある（&lt;a href="https://www.sciencedirect.com/science/article/pii/0097316579901080"&gt;Gessel&lt;/a&gt;）。木の子は降順に並んでいるとする。木の転倒数をなす２頂点 \\(i &gt; j\\) に対して、\\(i\\) の親 \\(p\\) を取り、辺 \\(pj\\) を対応付ける。転倒数を対応付けられた辺たちは、追加してもDFS木を保つ。以上より \\(t^&#123;n-1&#125;I_n(1+t) = C_n(t)\\) が成り立つ。

無向連結グラフとトーナメント（\\(K^n\\)の向き付けで、\\(1\\)から任意の点に移動可）が一対一対応。トーナメントでDFS木を作り、DFS木の辺でも後退辺でもない辺を削除して向き付けを無視すると、無向連結グラフに。無向連結グラフと、有向グラフで\\(1\\)から任意の点に移動できるものが\\(1:2^&#123;&#123;n \\choose 2&#125;&#125;\\)対応。DFS木の辺でも後退辺でもない辺が、無向連結グラフに \\(&#123;n \\choose 2&#125;\\) 個増やせるため。

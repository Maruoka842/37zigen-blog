# アルゴリズム/データ構造を語る会

> 📅 **投稿日**: 2020-10-08 04:21:25

スライド・録画は&lt;a href="https://drive.google.com/drive/folders/1htiwJtiSZ_ruYJYRk54cuJlJgea_XGrH"&gt;こちら&lt;/a&gt;からどうぞ。
&lt;h3&gt;第零回&lt;/h3&gt;
&lt;ul&gt;
 	&lt;li&gt;level ancestor problem の〈O(N), O(1)〉アルゴリズム（37zigen）
&lt;ul&gt;
 	&lt;li&gt;long-path decomposition やダブリングなど色々なテクニックが詰まっています。&lt;/li&gt;
&lt;/ul&gt;
&lt;/li&gt;
 	&lt;li&gt;SMAWK Algorithm とナップザック（熨斗袋）
&lt;ul&gt;
 	&lt;li&gt;重みの種類数が小さいとき、SMAWK アルゴリズムによって高速にナップザック問題を解く Axiotis–Tzamos　のアルゴリズムを解説。&lt;/li&gt;
&lt;/ul&gt;
&lt;/li&gt;
 	&lt;li&gt;O(1) RMQ（ながたかな）
&lt;ul&gt;
 	&lt;li&gt;Range Minimum Query をクエリ当たりO(1)で解くアルゴリズムを解説。&lt;/li&gt;
&lt;/ul&gt;
&lt;/li&gt;
 	&lt;li&gt;Incidence algebra and Mobius inversion（maspy）
&lt;ul&gt;
 	&lt;li&gt;隣接代数入門。ゼータ／メビウス変換などがより高い視点から見れるようになります。&lt;/li&gt;
&lt;/ul&gt;
&lt;/li&gt;
 	&lt;li&gt;Dominator Tree（けんしん）
&lt;ul&gt;
 	&lt;li&gt;Dominator Tree の定義からそれを求めるアルゴリズムまで丁寧に解説。&lt;/li&gt;
&lt;/ul&gt;
&lt;/li&gt;
&lt;/ul&gt;
&lt;h3&gt;第一回&lt;/h3&gt;
&lt;a href="https://connpass.com/event/185742/"&gt;概要&lt;/a&gt;
&lt;ul&gt;
 	&lt;li&gt;最大独立集合（37zigen）
&lt;ul&gt;
 	&lt;li&gt;最大独立集合のアルゴリズムの設計や計算量解析のテクニックを紹介。&lt;/li&gt;
&lt;/ul&gt;
&lt;/li&gt;
 	&lt;li&gt;爆速 multipoint evaluation（tko919）
&lt;ul&gt;
 	&lt;li&gt;転置写像を経由して multipoint evaluation を高速化。&lt;/li&gt;
&lt;/ul&gt;
&lt;/li&gt;
 	&lt;li&gt;数え上げと解析学（maspy）
&lt;ul&gt;
 	&lt;li&gt;複素解析を駆使して数え上げた通り数がどのぐらいに大きさになるのか評価。発表者による&lt;a href="https://drive.google.com/drive/folders/1CI4P9TUWcK_sGLkUBsA4ORNilIcNjB-N"&gt;アブストラクト&lt;/a&gt;も。&lt;/li&gt;
&lt;/ul&gt;
&lt;/li&gt;
&lt;/ul&gt;

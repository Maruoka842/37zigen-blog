# 文字列

> 📅 **投稿日**: 2022-06-28 22:28:03

[toc]
&lt;h2&gt;記法&lt;/h2&gt;
&lt;h3&gt;自由モノイド&lt;/h3&gt;
集合 \\(\\Sigma\\) をアルファベットと呼ぶ。アルファベットの要素を文字と呼ぶ。文字の列を語と呼ぶ。有限長の語全体を \\(\\Sigma^*\\)、長さ \\(n\\) の語の集合を \\(\\Sigma^n\\) と置く。語 \\(s, t\\) の結合を \\(st\\) と書く。また、空語を \\(\\varepsilon\\) と置く。空語は結合の単位元である。空語は辞書順最小とする。結合は結合法則を満たすので、\\(\\Sigma^*\\) 上でモノイドをなす。このモノイドを自由モノイドと呼ぶ。
&lt;h3&gt;その他&lt;/h3&gt;
逆順にした語を \\(s^R\\) と置く。辞書順で \\(s\\) の方が \\(t\\) より小さいとき \\(s \\prec t\\) と書く。語 \\(s\\) の \\(i\\) 文字目を \\(s[i]\\) と表す。\\([i..j] = \\&#123;i, i+1,\\ldots,j\\&#125;\\)、\\(s[i..j]=s[i]s[i+1]..s[j]\\)と置く。語 \\(s,t\\) の連結を \\(st\\) と書く。語 \\(s\\) の長さを \\(|s|\\) と書く。空語を除いたものを \\(\\Sigma^+=\\Sigma^*-\\varepsilon\\) と置く。語 \\(w\\) が語 \\(x\\) の接頭辞であるとき、\\(w &lt;_&#123;suf&#125; x\\) と書く。また、語 \\(w\\) が語 \\(x\\) の真の接尾辞であるとき、\\(w &lt;_&#123;pref&#125; x\\) と書く。\\(t\\) が \\(s\\) の部分語のとき、\\(t \\subset s\\) と書く。語 \\(s, t\\) の最長共通接尾辞を \\(\\mathrm&#123;lcp&#125;(s, t)\\) と書く。\\(\\xi s\\) を \\(s\\) の真の suffix のうち最も長い語とする。語の集合 \\(A\\) に対して、\\(\\xi_A s\\) を、 \\(A\\) に含まれる語の suffix のうち \\(s\\) の真の suffix であって、最も長い語とする。アルファベットまたは一文字の語を \\(\\sigma\\) と書く。語 \\(s\\) を無限回接続した語を \\(s^\\omega\\) と置く。
&lt;h2&gt;語の周期&lt;/h2&gt;
\\(s[i] = s[i \\bmod d]\\) が成り立つとき、\\(s\\) の周期は \\(d\\) であるという。そのような最小の正整数を \\(w\\) の最小周期と呼び、\\( \\mathrm&#123;period&#125;(s)\\) と置く。\\(\\mathrm&#123;ord&#125;(s) = \\mathrm&#123;period&#125; / |s| \\in \\mathbb&#123;Q&#125;\\) を \\(s\\) の位数と呼ぶ。\\(s = u^&#123;\\mathrm&#123;ord&#125;(s)&#125;\\) を満たす \\(u\\) が存在する。\\(s\\) の接頭辞かつ接尾辞である真部分語 \\(u\\) を \\(s\\) の境界と呼ぶ。周期の定義を同値変形することにより、
\\begin&#123;align&#125;
&amp;s[i] = s[i \\bmod d]\\\\
\\Leftrightarrow&amp;s[i]=s[i+d] \\quad (1 \\leq i \\leq |s|-d)\\\\
\\Leftrightarrow&amp; s[1..|s|-d-1] = s[d+1..|s|] \\\\
\\end&#123;align&#125;となるので、境界を \\(b\\) とすると $$|s|-|b|$$ は周期である。別証明として、\\(s=ax=xb\\) ならば
\\begin&#123;align&#125;
a^ix &amp;= a^&#123;i-1&#125;xb \\\\
&amp;=a^&#123;i-2&#125;xb^2 \\\\
&amp;=xb^i
\\end&#123;align&#125;より \\(a^\\omega=xb^\\omega\\) から、周期 \\(|a|=|b|=|s|-|x|\\) が分かる。語 \\(s\\) の最長境界を \\(\\mathrm&#123;Border&#125;(s)\\) と置きます。境界は長い順に \\(\\mathrm&#123;Border&#125;(s), \\mathrm&#123;Border&#125;^2(s), \\ldots, \\mathrm&#123;Border&#125;^k(s) = \\varepsilon\\) と列挙できます。境界の長さを  \\(\\mathrm&#123;border&#125;(s)\\) と置きます。\\(s\\) の周期は降順に \\(|s|-\\mathrm&#123;border&#125;(s),|s|-\\mathrm&#123;border&#125;^2(s),|s|-\\mathrm&#123;border&#125;^3(s),\\ldots, |s|-\\mathrm&#123;border&#125;^k(s)=|s|\\) で全てである。\\(\\mathrm&#123;period&#125;(x) = |x| - \\mathrm&#123;border&#125;(x)\\) である。回文wについて、先頭k文字が回文であることと、周期|w|-kを持つことが同値。
&lt;h3&gt;Fine--Wilfの定理&lt;/h3&gt;
&lt;div class="statement"&gt;語 \\(s\\) が周期 \\(p\\) かつ周期 \\(q\\) かつ \\(|s| \\geq p + q-\\gcd(p, q)\\) ならば、周期 \\(\\gcd(p, q)\\) である。&lt;/div&gt;
周期 \\(p\\) より \\(p\\) 個の同値類に分かれる。これらが一つになるには、少なくとも \\(p-1\\) 個の別の独立な同値関係が必要である。周期 \\(q\\) を用いて、先頭から \\(i\\) 文字目と \\(i+q\\) 文字目が等しいという関係を \\(i = 1, \\ldots, p-1\\) について加えるには少なくとも全体の文字列の長さが \\(p + q - 1\\) 以上でなければならない。
&lt;div class="proof"&gt;証明：\\(s = u^&#123;\\gcd(p, q)&#125;\\) と書けるので、\\(u\\) の周期を考えることで、\\(p, q\\) が互いに素な場合に帰着できる。また、\\(|s|=p+q-1\\) の場合だけ示せば十分。\\(p = 0 \\lor q = 0 \\lor p = q\\) ならば明らか。\\(q &lt; p\\) とする。\\(1 \\leq i \\leq q-1\\) では \\(s[i]=s[i+p]=s[i+p-q]\\) なので、\\(a=s[1..p-1]\\) は周期 \\(p-q\\) である。\\(|a| = p-1 = (p-q) + q-1\\) だから帰納法が回る。

次のようにしてもよい。長さ \\(q-1\\) の境界を \\(q\\) だけ移動することで、\\(s[1..p-1]\\) は長さ \\(q-1\\) の境界を持つことが分かる。従って、\\(s[1..p-1]\\) は周期 \\((p-1)-(q-1)=p-q\\) を持つ。

&lt;/div&gt;
別証明として、\\(\\sum s[i]t^i\\) という形式的べき級数を考える方法もある（省略）。

例えば、\\(ab = ba\\) と表せる語 \\(s\\) は周期 \\(|a|, |b|\\) で \\(|s| \\geq |a|+|b|-\\gcd(|a|, |b|)\\) なので周期 \\(\\gcd(|a|, |b|)\\) である。\\(\\gcd(|a|, |b|)\\) は \\(|s|\\) の約数なので、\\(s\\) はある整数乗で表せる。

Fine--Wilfの定理から、\\(|s|\\) の非自明な約数を周期に持つならば、最小周期もまた非自明な約数になることが分かる。
&lt;h4&gt;周期のGCDが取れない例（フィボナッチ語）&lt;/h4&gt;
\\(f_0 = a, f_1 = b, f_i=f_&#123;i-1&#125;f_&#123;i-2&#125;\\) とする。
\\(\\phi(f_0)=f_1, \\phi(f_1)=f_2\\) を満たす準同型写像すなわち \\begin&#123;align&#125;
\\phi(a)&amp;=b \\\\
\\phi(b)&amp;=ba
\\end&#123;align&#125;は\\(\\phi(f_i)=f_&#123;i+1&#125;\\)を満たす。順に計算することで、\\(n \\geq 1\\) のとき $$f_n = f_1f_2\\cdots f_&#123;n-2&#125;$$ が成り立っていること分かる。\\(f_n\\) の後ろ２文字を削った文字列を \\(g_n\\) とすると、\\(g_n\\) は周期 \\(|f_&#123;n-1&#125;|, |f_&#123;n-2&#125;|\\) を持つ。これは
\\begin&#123;align&#125;
&amp;g_n &lt;_&#123;pref&#125; f_&#123;n-1&#125;f_&#123;n-2&#125; &lt;_&#123;pref&#125; f_&#123;n-1&#125;^2 \\\\
&amp;g_n = f_&#123;n-1&#125;g_&#123;n-2&#125; = f_&#123;n-2&#125; f_&#123;n-3&#125;g_&#123;n-2&#125; &lt;_&#123;pref&#125; f_&#123;n-2&#125;^2
\\end&#123;align&#125;から分かる。\\(g_n\\) は Wine--Wilf の定理で周期の gcd が取れないギリギリの例を与えている。
&lt;h3&gt;累乗&lt;/h3&gt;
\\(s = w^m\\) \\( (m \\in \\mathbb&#123;N&#125;, m \\geq 2)\\) と表すことができないような語を原始的と呼ぶことにする。語 \\(s\\) を \\(n\\) 回繰り返した \\(s^n\\) について考察したいとする。このとき、原始的な語 \\(w\\) を用いて \\(s = w^m\\) と一意に書けるので、\\(s^n = w^&#123;nm&#125;\\) とできる。
&lt;h3&gt;累乗で表される回文&lt;/h3&gt;
語を逆順にする関数 \\(&#123;\\cdot&#125;^R\\) は反準同型写像 \\((xy)^R=y^Rx^R\\) なので、\\((w^n)^R = (w^R)^n\\) である。つまり、\\(w^n\\) が回文ならば \\(w\\) は回文になる。
&lt;h2&gt;共役&lt;/h2&gt;
語 \\(x, y\\) について、ある語 \\(a, b\\) を用いて \\(x = ab, y=ba\\) と表せるとき、\\(x, y\\) は共役であると呼ぶ。\\(x, y\\) が共役であることと、\\(gx=yg\\) を満たす \\(g\\) が存在することは同値である。\\(\\Rightarrow\\) は \\(x=uv, y=vu\\) とすると、\\(vx=yv\\) であることから分かる。\\(\\Rightarrow\\) は \\(\\forall i\\in\\mathbb&#123;N&#125;, gx^i=y^ig\\) より \\(gx^\\omega=y^\\omega\\) だから、\\(x\\) は \\(y\\) の巡回シフトになることから分かる。これは群の \\(x = aya^&#123;-1&#125;\\) のアナロジーである。共役な語は、巡回シフトで移り合う。従って、共役な語は同値類をなす。この共役類をネックレスと呼ぶ。共役類の大きさは整数の位数と等しい。従って、原始的な語の共役類の大きさは語長と等しい。

&lt;h2&gt;KMP法&lt;/h2&gt;
接頭辞の最長境界を列挙するアルゴリズムである。\\(\\mathrm&#123;Border&#125;(s\\sigma)\\) は \\(s\\) の境界 \\(\\mathrm&#123;Border&#125;^1(s), \\mathrm&#123;Border&#125;^2(s), \\ldots, \\mathrm&#123;Border&#125;^k(s) = \\varepsilon\\) のうち、\\(s[|\\mathrm&#123;Border&#125;^i(s)|+1] = \\sigma\\) となる最長のものを（存在するなら）用いて、\\(\\mathrm&#123;Border&#125;(s\\sigma) = \\mathrm&#123;Border&#125;^i(s)\\sigma\\) と書ける。存在しなければ、\\(\\mathrm&#123;Border&#125;(s \\sigma) = \\varepsilon\\) となる。境界は接尾辞で、\\(\\mathrm&#123;Border&#125;^&#123;i&#125;(s)\\) は \\(B^&#123;i-1&#125;(s)\\) の最長境界であるから、\\(\\mathrm&#123;Border&#125;^i(s)\\) は全て計算済みである。\\(s\\sigma\\) の最長境界は \\(s\\) の最長境界に比べて高々一つしか長さが増加せず、最長境界は再帰的に取るたびに長さは単調減少するので、ならし \\(O(1)\\) で最長境界を列挙できる。
&lt;h3&gt;高速化&lt;/h3&gt;
末尾に1文字追加したときのborderをO(log |s|)で取得したい。\\(\\mathrm&#123;period&#125;(s) \\leq |s| / 2\\) ならば、\\(\\mathrm&#123;period&#125;(s)\\) の倍数でない \\(p\\) は周期は、\\(|s|/2\\) 超である。さもなくば、Fine--Wilfの定理より \\(\\gcd(\\mathrm&#123;period&#125;(s), p)\\) の周期があるが、これは最小性に反する。言い換えれば、\\(s=(uv)^ku\\) \\((k\\geq1, u \\in \\Sigma^+)\\) の境界は
\\(w=uv\\) と置くと、
$$w^&#123;k-1&#125;u, w^&#123;k-2&#125;u, w^&#123;k-3&#125;u, \\ldots$$
の形が長さ \\(|s|/2\\) 以上である間は続く。この形は全て \\(s[\\mathrm&#123;Border&#125;^i(s)+1] = u[1]\\) であるから、\\(\\sigma \
eq u[1]\\) ならば計算を飛ばすことができる。従って、ならし計算量が実時間 \\(O(\\log(|s|)\\) にできる。Manacherの場合についても、末尾に1文字追加したときのprefix=suffixとなる最長回文がO(log|s|)で得られる。それには、回文の境界がkであることと先頭k文字が回文であることが同値であることを用いる。
&lt;h2&gt;辞書順&lt;/h2&gt;
\\(S,T \\in \\Sigma^+\\) について \\( \\overline &#123;S &lt;_&#123;suf&#125; T&#125;\\) ならば
\\(S \\prec T \\Rightarrow SA \\prec TB\\) である。この事実より、\\(S, T\\) の順序から \\(SA,TB\\) の順序が定まらないのは \\(S &lt;_&#123;suf&#125; T\\) または \\(T &lt;_&#123;suf&#125; S\\) のときのみである。（yuki1018, ARC058F）lcp が求まれば、辞書順も分かる。

\\(A \\prec B \\Leftrightarrow \\mathrm&#123;lcp&#125;(A)^&#123;-1&#125;A  \\prec \\mathrm&#123;lcp&#125;(B)^&#123;-1&#125;B\\)

である。

prefix の列 \\(s_1 &lt;_&#123;pref&#125;  s_2 &lt;_&#123;pref&#125; \\cdots &lt;_&#123;pref&#125; s_n\\) と語 \\(t\\) について、\\(\\&#123;s_i\\&#125;
\\cup \\&#123;s_i t\\&#125;\\) を辞書順に並べよ。（ARC058C）
\\(s_it &lt;  s_jt\\) \\((i &lt; j)\\)
\\(\\Leftrightarrow t&lt; s_i^&#123;-1&#125;s_jt\\) \\((i &lt; j)\\)

などから \\(t\\) と \\(s_i^&#123;-1&#125;s_j\\)、\\(t[|s_i^&#123;-1&#125;s_j|+1..|t|]\\) と \\(t\\) の比較などに帰着できる。
&lt;h2&gt;回文&lt;/h2&gt;
\\(s\\) が回文 \\(\\Leftrightarrow\\) \\(s[i] = s[|s|+1-i]\\) である。\\(s\\) が回文ならば \\(s[l..r] = s[|s|+1-r..|s|+1-l]\\) である。特に、\\(s,s[l..r]\\) が回文ならば、\\(s[|s|+1-r..|s|+1-l]\\) は回文である（rng_58の解説参照）。
&lt;h3&gt;部分語に含まれる回文の種類数の上限&lt;/h3&gt;
S に部分語として含まれる回文の種類数は |S| 個以下である（ABC237H）。これはManacherのアルゴリズムから分かる。\\(S[a..|s|]\\) と \\(S[b..|s|]\\) \\((a &lt; b)\\) が回文ならば \\(s[b..|s|] = s[a..|s|-b+a] \\subset s[1..|s|-1]\\) より長さを一つ増やすごとに回文の種類数が高々一つしか増えないことからもわかる。\\(AB=B^RA^R, BA=A^RB^R\\) が成り立つ条件は？（&lt;a href="https://kumakumatime.hateblo.jp/entry/2023/02/08/213539"&gt;kumaさん&lt;/a&gt;）\\begin&#123;align&#125;
A^RABB^R&amp;=BAA^RB^R \\\\
&amp;=BABA\\\\
&amp;=BB^RA^RA
\\end&#123;align&#125;
従って、\\(A^RA,BB^R\\) は互いに可換だから、欠陥定理よりある一意な原始的な語 \\(u\\) に対して、\\(A^RA,BB^R \\in u^*\\) である。\\(A^RA,BB^R\\) は回文であるから、\\(u\\) も回文である。
&lt;h3&gt;LCS&lt;/h3&gt;
文字列SをK文字まで変更してよい。Sの部分文字列\\(a,b\\)であって、\\(a=b^R\\)となる\\(|a|\\)の最大値は？（&lt;a href="https://atcoder.jp/contests/agc021/tasks/agc021_d"&gt;AGC21D&lt;/a&gt;）\\(\\mathrm&#123;lcs&#125;(s, s^R)\\) の長さは、 \\(s\\) の部分語の回文の最大の長さに等しい。
&lt;h2&gt;語の長さの種類数&lt;/h2&gt;
語 \\(t_1, t_2, \\ldots, t_n\\) の長さの合計が \\(n\\) で抑えられるならば、長さの種類数は \\(O(\\sqrt&#123;n&#125;)\\) である。これは \\(\\sum_&#123;i=1&#125;^k i = k(k+1) /2 \\leq n\\) のとき \\(k = O(\\sqrt n)\\) であることから従う。このことから、長さ n の文字列に含まれる部分文字列の種類数は \\(O(n \\sqrt&#123;n&#125;)\\) である。また、この事実によりDPなどを高速化できることがある。例えば、Aho-Corasick 法で \\(A = \\&#123;t_1, t_2, \\ldots, t_n\\&#125;\\)、語長の和が \\(\\sum |t_i| = O( n)\\) とする。\\(\\xi'_A s\\) を \\(A\\) のうち \\(s\\) の suffix であるものとすると、\\(\\xi'_As\\) はメモ化によりならし \\(O(1)\\) で求まる。\\(|t_i|\\) の種類数が \\(O(\\sqrt&#123;n&#125;)\\) であること、\\(\\xi_A'\\)を掛けるたびに長さが狭義単調減少することから \\(O(\\sqrt&#123;n&#125;)\\) 回掛けると \\(\\varepsilon\\) になる(ECR097G)。\\(\\zeta_A s\\) をキーとしたDPができる(AOJ2257)。オンラインに文字を追加すると、$\\zeta_A $ の最長性が破壊されるため、基本的にはオフラインでしか使えない。パターンの追加・削除は、Trieのノードへの±1と見ると準同型なので、\\(\\log(n)\\) のオーバーヘッドによりオンラインにできる（&lt;a href="https://codeforces.com/contest/710/problem/F"&gt;ECF710F&lt;/a&gt;）。パターン数を2進数で表した時のビットが立っている桁ごとに Aho-Corasick を用意する。繰り上がりの回数が \\O(\\log(n))\\) で抑えられる。
&lt;ul&gt;
 	&lt;li&gt;パターン\\(P_1, P_2, \\ldots, P_n\\) が事前に与えられる。文字列 \\(S_1, S_2, \\ldots, S_m\\) が与えられるので、それぞれ、オンラインでパターンが部分文字列として何回現れるか求めよ。\\(N = \\sum |P_i|, M = \\sum |S_i|\\) として \\(O(N+M)\\)。&lt;/li&gt;
 	&lt;li&gt;文字列とパターンがオンラインで与えられる。パターンは追加と削除がある。各文字列に対して、パターンが部分文字列として何回現れるか求めよ。\\(O((N+M) \\log(n))\\)。&lt;/li&gt;
 	&lt;li&gt;パターン \\(P_1, P_2, \\ldots, P_n\\) と文字列 \\(S\\) が与えられる。パターンとマッチしないようにするには、\\(S\\) から何文字削除する必要があるか。\\(O(|S|\\sum |P_i|)\\)&lt;/li&gt;
 	&lt;li&gt;削除ではなく文字の変更だとどうなるか？&lt;/li&gt;
 	&lt;li&gt;文字列 S, パターン P_1, .., P_n, 整数列 a_1, .., a_n が与えられる。Sの部分文字列であって、P_iをa_i回含むものの、最短の長さをそれぞれ求めよ\\(O(|S|\\sqrt&#123;|S|&#125;\\log(|S|))\\)（&lt;a href="https://codeforces.com/problemset/problem/963/D"&gt;CF963D&lt;/a&gt;）&lt;/li&gt;
 	&lt;li&gt;文字列S_1, S_2, .., S_nが与えられられる。文字列Tをこれらの文字列のオーバーラップ（糊しろを持たせてつなげる）で表すには何個必要か。同じ文字列を複数回使っても良い。Aho-Corasickと貪欲法で\\(O(|T|+\\sum|S_i|)\\)（&lt;a href="https://qnighy.github.io/informatics-olympiad/joi2010-day2-dna-problem.html"&gt;joi2010day2&lt;/a&gt;）&lt;/li&gt;

&lt;h2&gt;Trie&lt;/h2&gt;
語の末尾への incremental な更新があり、オフラインで処理してよい場合、最終的な語の集合に対する Trie を構築することでほかの種類のクエリが処理できるようになることがある。例えば、\\(\\sum_i|\\mathrm&#123;lcp&#125;(S_i, S_k)|\\) を求めるクエリ（yuki2020）。
&lt;h2&gt;Aho-Corasick法&lt;/h2&gt;
次のようなことができるデータ構造。
&lt;ul&gt;
 	&lt;li&gt;\\(s \\in \\mathrm&#123;prefix&#125;(A)\\) である語 \\(s\\) に対して \\(s\\sigma\\in \\mathrm&#123;prefix&#125;(A)\\) かどうかが \\(O(\\log \\Sigma)\\) で求まる。&lt;/li&gt;
 	&lt;li&gt;\\(s \\in \\mathrm&#123;prefix&#125;(A) \\) に対して \\(\\xi_As[1..i]\\) が \\(O(1)\\) で求まる。&lt;/li&gt;
&lt;/ul&gt;

# KMP法

> 📅 **投稿日**: 2022-06-28 22:28:03

&lt;h2&gt;記法&lt;/h2&gt;
\\(s\\) を逆順にした文字列を \\(s^R\\) と置く。
辞書順で \\(s\\) の方が \\(t\\) より小さいとき \\(s \\prec t\\) と書く。
文字列 \\(s\\) の \\(i\\) 文字目を \\(s[i]\\) と表す。
\\([i..j] = \\&#123;i, i+1,\\ldots,j\\&#125;\\)、\\(s[i..j]=s[i]s[i+1]..s[j]\\)と置く。文字列 \\(s,t\\) の連結を \\(st\\) と書く。文字列 \\(s\\) の長さを \\(|s|\\) と書く。
&lt;h2&gt;KMP法&lt;/h2&gt;
\\(\\psi(s[0..i]) = \\&#123; s[0..j] : s[0..j] = s[i-j..i], j &lt; i \\&#125;\\) と置く。また \\(\\xi s[0..i]\\) を \\(\\psi(s[0..i])\\) のうち最も長い文字列とする。このとき、\\(\\xi^&#123;k&#125;s[0..i]\\) は \\(\\psi(s[0..i]) \\) のうち \\(k\\) 番目に長い文字列である。

\\begin&#123;eqnarray&#125;
  \\left\\&#123;
    \\begin&#123;array&#125;&#123;l&#125;
      \\xi^k s[0..i]=s[0..t] \\\\
      s[i+1]=s[t+1]
    \\end&#123;array&#125;
  \\right.
\\end&#123;eqnarray&#125;を満たす最小の \\(k\\) （\\(k'\\)と置く）を用いると、\\(\\xi s[0..i+1]=s[0..t+1]\\) となる。\\(\\xi\\) を掛けると長さは狭義単調減少する。また、\\(|\\xi^&#123;k'&#125;s[0..i]| + 1 = |\\xi s[0..i+1]|\\) なので、各 \\(1 \\leq i \\leq |s|\\) について \\(k'\\) を列挙する（\\(\\xi s[0..i+1]\\) を求める）ことは \\(O(|s|)\\) でできる。

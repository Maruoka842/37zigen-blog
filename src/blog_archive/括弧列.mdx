&lt;h2&gt;平衡括弧列の定義&lt;/h2&gt;
&lt;p&gt;平衡括弧列には同値な定義が様々あり、どの定義を使うかによって問題の解きやすさは劇的に変わる。平衡括弧列全体を \\(\\mathcal P\\), 長さ \\(2n\\) の平衡括弧列全体を \\(\\mathcal P_&#123;2n&#125;\\) と置く。&lt;/p&gt;
&lt;h3&gt;連結と再帰による定義&lt;/h3&gt;
&lt;p&gt;平衡括弧列とは、空文字列および、次の操作を繰り返すことで生成される文字列である。&lt;/p&gt;
&lt;ul&gt;
&lt;li&gt;二つの平衡括弧列 \\(A, B\\) を連結した文字列 \\(AB\\)&lt;/li&gt;
&lt;li&gt;平衡括弧列 \\(A\\) を用いて \\((A)\\) と書ける文字列&lt;/li&gt;
&lt;/ul&gt;
&lt;p&gt;(を x, ) を y と置くと、\\(F = 1 + xFyF = 1 + xy + xyxy + \\cdots\\) の単項式であるものと言い換えることもできる。二つ目の操作を \\()A(\\) に置き換えた時に生成される文字列を負の平衡括弧列と呼ぶことにする。また、元の定義による文字列を正の平衡括弧列と呼ぶことにする。正の平衡括弧列を逆から読むと負の平衡括弧列になる。平衡括弧列をいくつかの極小な平衡括弧列の連結で表した時、その極小な平衡括弧列たちを既約平衡括弧列と呼ぶことにする。&lt;/p&gt;
&lt;h3&gt;\\(\\pm1\\)列による定義&lt;/h3&gt;
&lt;p&gt;\\((\\), \\()\\) を \\(+1, -1\\) に置き換えた数列 \\(\\delta a\\) の累積和 \\(a_i = \\sum_&#123;k=1&#125;^i \\delta a_k\\) について&lt;br /&gt;\\begin&#123;eqnarray&#125;&lt;br /&gt;\\left\\&#123;&lt;br /&gt;\\begin&#123;array&#125;&#123;l&#125;&lt;br /&gt;a_&#123;i+1&#125; - a_i\\in \\&#123;+1,-1\\&#125; \\\\&lt;br /&gt;a_i \\geq 0 \\\\&lt;br /&gt;a_&#123;0&#125; = a_&#123;2N&#125; = 0&lt;br /&gt;\\end&#123;array&#125;&lt;br /&gt;\\right.&lt;br /&gt;\\end&#123;eqnarray&#125;が成り立つとき平衡括弧列と定義する。mod 2 で考えると、初めて \\(a_i &lt; 0\\) となるのは \\(i\\) が奇数のときだけだと分かる。従って、\\(a_&#123;2i + 1&#125; \\geq 0\\) で十分。\\(a_i \\geq 0\\) を \\(a_i \\leq 0\\) にすると負の平衡括弧列になる。累積和によって定義されていることから、\\(\\delta a\\) の一点更新は \\(a\\) の区間更新に直すことになる。例えば、i 文字目を ( から ) に変更する操作は、区間 \\([i..2N]\\) に \\(-2\\) を足す操作になる。また、i 番目の ( と j 番目の ) を swap する操作は区間 \\([i..j)\\) に \\(-2\\) を足す操作になる。&lt;br /&gt;\\(0, 2\\) 列による言い換え \\begin&#123;eqnarray&#125;&lt;br /&gt;\\left\\&#123;&lt;br /&gt;\\begin&#123;array&#125;&#123;l&#125;&lt;br /&gt;t_&#123;i+1&#125; - t_i\\in \\&#123;0,2\\&#125; \\\\&lt;br /&gt;t_&#123;2i-1&#125; \\geq 2i \\\\&lt;br /&gt;t_&#123;0&#125; = 0 \\\\&lt;br /&gt;t_&#123;2N&#125; = 2N&lt;br /&gt;\\end&#123;array&#125;&lt;br /&gt;\\right.&lt;br /&gt;\\end&#123;eqnarray&#125; が有効な場合もある。&lt;/p&gt;
&lt;h3&gt;()の削除による定義&lt;/h3&gt;
&lt;p&gt;隣接する2文字()の削除を繰り返すことで空文字列にできる文字列を平衡括弧列と定義する。空でない極小な括弧列 \\((A_1), (A_2), \\ldots, (A_n)\\) を用いて \\((A_1)(A_2)\\ldots (A_n)\\) と書ける括弧列を、根の子の部分木が \\(A_1, A_2, \\ldots, A_n\\) の表すそれである木に対応させると、子の順序を区別する n 辺の根付き木と一対一対応する。&lt;/p&gt;
&lt;ul&gt;
&lt;li&gt;LCA（yuki1778）&lt;/li&gt;
&lt;li&gt;二乗の木DP（DDCC2016C）&lt;/li&gt;
&lt;/ul&gt;
&lt;p&gt;()の削除は、葉の削除に対応する。オイラーツアーの各辺について、一回目は (, 2回目はを ) に対応させると元の括弧列が得られる。右子・左子を区別する n 頂点二分木を平衡括弧列と一対一対応させることもできる。この場合、オイラーツアーの各頂点について、一回目は (, 2回目は ) に対応させる。この木の各辺を (, ) に対応させると、n + 1 個の元の積を二項演算として処理するための括弧付けと一対一対応する（これらの元に対応する頂点は、全2分木となるように葉として追加する）。&lt;/p&gt;
&lt;ul&gt;
&lt;li&gt;対応する括弧の添字は偶奇が異なることを示せ。&lt;/li&gt;
&lt;li&gt;N 箇所を白、N 箇所を黒で塗った長さ2Nの配列について、白と黒がペアになる括弧列が存在することを示せ。（ARC120D）&lt;/li&gt;
&lt;li&gt;添字の集合 \\(\\&#123;1,2,\\ldots,N\\&#125;\\) を2つの集合 A, B に分ける。A の偶数と奇数の個数は等しく、B の偶数と奇数の個数も等しい。A に含まれる添字の位置では &#123; か &#125;, B に含まれる添字の位置では ( か ) となるように平衡括弧列が構成できることを示せ（AGC048B, CF1593G）&lt;/li&gt;
&lt;/ul&gt;
&lt;h3&gt;経路による定義&lt;/h3&gt;
&lt;p&gt;(, ) を格子点 \\((x, y)\\) から \\((x, y+1), (x+1, y)\\) の移動と対応させる。括弧列を戦闘から読み込んだとき \\(x \\leq y \\) の下、\\((0, 0)\\) から \\((n, n)\\) への移動経路になっているならば平衡括弧列と定義する。&lt;/p&gt;
&lt;p&gt;45度回転させて、\\((x, y)\\) から \\((x+1, y+1), (x-1, y-1)\\) に \\(y \\geq 0\\) の下、移動できるときの \\((0, 0)\\) から \\((n, 0)\\) への経路とすることもできる。以下の問題は経路によって視覚的にイメージした方が分かりやすいと思う。&lt;/p&gt;
&lt;ul&gt;
&lt;li&gt;巡回シフトで平衡括弧列にできるか線形で判定せよ (ARC138C)&lt;/li&gt;
&lt;li&gt;巡回シフトで平衡括弧列にできるなら、そのうち、辞書順最小のものを求めよ（VK Cup 2015 Round 1 : A）&lt;/li&gt;
&lt;li&gt;平衡括弧列となるような置換のうち、並び替え後の添字が辞書順最小のものを求めよ（ARC141C）&lt;/li&gt;
&lt;li&gt;平衡括弧列となる部分文字列の個数を求めよ（2018 codeFlyer 本選 C）&lt;/li&gt;
&lt;/ul&gt;
&lt;p&gt;\\(y \\geq 0\\) を \\(y \\leq 0\\) にすると負の平衡括弧列になる。任意の非空な括弧列は非空な正の平衡括弧列と非空な負の括弧列を交互に連結した文字列として一意に表せる。&lt;/p&gt;
&lt;h3&gt;ゲームによる定義&lt;/h3&gt;
&lt;p&gt;長さ \\(2N\\) の配列 \\(\\delta a\\) について、先手と後手は交互に次の操作をする。&lt;/p&gt;
&lt;ul&gt;
&lt;li&gt;先手はまだ選ばれていない要素のうち、最も先頭に近いものを ( に置換する。&lt;/li&gt;
&lt;li&gt;後手はまだ選ばれていない要素から好きなものを ) に置換する。&lt;/li&gt;
&lt;/ul&gt;
&lt;p&gt;それ以上操作できなくなったときに生成される文字列を平衡括弧列と定義する（ARC138C）&lt;/p&gt;
&lt;h2&gt;平衡括弧列の個数&lt;/h2&gt;
&lt;p&gt;長さ \\(2n\\) の平衡括弧列は $$\\frac&#123;1&#125;&#123;n+1&#125;&#123;2n \\choose n&#125;$$個ある。この数を \\(n\\) 項目のカタラン数と呼ぶ。(, ) がそれぞれ \\(n\\) 個ある長さ \\(2n\\) の括弧列は \\(&#123;2n \\choose n&#125;\\) 個ある。これら全体を \\(\\mathcal&#123;A_n&#125;\\)、長さ \\(2n\\) の平衡括弧列全体を \\(\\mathcal&#123;B_n&#125;\\) とすると、ちょうど \\(|\\mathcal&#123;A_n&#125;| = (n + 1)|\\mathcal&#123;B_n&#125;|\\) であるから、何らかの \\(\\mathcal&#123;A_n&#125;\\) 上の同値関係 \\(\\sim\\) を取ると&lt;/p&gt;
&lt;ul&gt;
&lt;li&gt;同値類のサイズがそれぞれ \\(n + 1\\) となり、\\(\\mathcal&#123;A_n&#125;/\\sim\\) と \\(\\mathcal&#123;B_n&#125;\\) の間の全単射がある。&lt;/li&gt;
&lt;li&gt;同値類のサイズがそれぞれ \\(\\frac&#123;1&#125;&#123;2n+1&#125;&#123;2n + 1\\choose n&#125;\\) となり、ある同値類と \\(\\mathcal&#123;B_n&#125;\\) の間の全単射がある。&lt;/li&gt;
&lt;/ul&gt;
&lt;p&gt;のようなことが成り立つはずである。導出 3, 4 ではそのような同値関係を構成している。&lt;/p&gt;
&lt;h3&gt;カタラン数の導出1（鏡像法）&lt;/h3&gt;
&lt;p&gt;長さ \\(2n\\) の平衡括弧列は、\\(y = x + 1\\) を通らずに \\((0, 0)\\) から \\((n, n)\\) に移動する経路に対応付けられた。その経路数は鏡像法によって、\\(&#123;2n \\choose n&#125;-&#123;2n \\choose n-1&#125;\\) だと分かる。\\(y = x + A\\) を通らずに移動する経路数は同様に鏡像法により \\(&#123;2n \\choose n&#125;-&#123;2n \\choose n-A&#125;\\) である。先頭 \\(A-1\\) 文字が ( である長さ \\(2n+A-1\\) 文字の平衡括弧列の個数に等しい。&lt;/p&gt;
&lt;h3&gt;カタラン数の導出2（組合せ）&lt;/h3&gt;
&lt;p&gt;(, ) がそれぞれ \\(n\\) 個ある長さ \\(2n\\) の括弧列全体を \\(\\mathcal&#123;A_n&#125;\\)、長さ \\(2n\\) の平衡括弧列全体を \\(\\mathcal&#123;B_n&#125;\\) とする。また、\\(1, -1\\) がそれぞれ \\(n-1, n+1\\) 個ある括弧列全体を \\(\\mathcal&#123;C&#125;_n\\) とする。非平衡括弧列 \\(\\mathcal&#123;A&#125;_n \\setminus \\mathcal&#123;B&#125;_n \\) と \\(\\mathcal&#123;C&#125;_n\\) の間の全単射を作る。&lt;/p&gt;
&lt;p&gt;全単射（対合） : 累積和が初めて \\(-1\\) になった箇所を \\(k\\) 文字目として、\\(k + 1\\) 文字目以降の正負を反転させる。&lt;br /&gt;カタラン数は \\(|\\mathcal&#123;B&#125;_n| = |\\mathcal&#123;A&#125;_n|-|\\mathcal&#123;C&#125;_n| = &#123;2n \\choose n&#125;-&#123;2n \\choose n-1&#125;\\) となる。&lt;/p&gt;

&lt;h3&gt;カタラン数の導出3（Bertrand's ballot theorem）&lt;/h3&gt;
&lt;p&gt;\\(+1, -1\\) がそれぞれ \\(n+1, n\\) 個の列 \\(\\delta a\\) は \\(&#123;2n+1 \\choose n&#125;\\) 個ある。部分列 \\(\\delta a_2, \\delta a_3, \\ldots, \\delta a_&#123;2n+1&#125;\\) が平衡括弧列になるには、\\(\\min a_i = 1\\) でなくてはならない。\\(\\delta a\\) の cyclic shift しのうち、そのような条件を満たすのは、\\(\\min a_i\\) を達成する最後の位置を始点に持ってくる場合だけである。\\(n, n+1\\) が互いに素なことから、原始的な文字列なので cyclic shift で移る列は相異なる。従って、cyclic shift で移り合う列全体を同値類とみなすと、平衡括弧列の個数は $$\\frac&#123;1&#125;&#123;2n+1&#125;&#123; 2n+1 \\choose n&#125; = \\frac&#123;1&#125;&#123;n+1&#125;&#123;2n \\choose n&#125;$$ 個である。円環において)(を削除して最後に残った１つが始点という見方もできる。&lt;/p&gt;

&lt;h2&gt;カタラン数の畳み込み&lt;/h2&gt;
&lt;p&gt;k 個畳み込んだカタラン数を&lt;br /&gt;$$C_&#123;n, k&#125;=\\sum_&#123;n=\\sum_&#123;i=1&#125;^k n_i&#125; \\prod_&#123;i=1&#125;^k C_&#123;n_i&#125;$$&lt;br /&gt;と置く。例えば \\(C_&#123;n,4&#125;\\) は平衡括弧列 \\(A, B, C, D\\) (空文字列を許す) の組であって、長さの和が \\(2n\\) であるものの個数に等しい。&lt;/p&gt;

&lt;h2&gt;非交差分割&lt;/h2&gt;
&lt;p&gt;[n]の非交差分割の集合を\\(\\mathrm&#123;NC&#125;_n\\)と置く。\\(\\mathrm&#123;NC&#125;_n\\) と長さ 2n の平衡括弧の間に全単射がある。思いつきやすいのは、prefix が平衡括弧列となる箇所の集合を \\(1\\) を含むブロックと対応付ける方法だろう。もう一つの方法は、先頭の \\((A_1(A_2(\\cdots( A_i())\\cdots))\\) の \\((\\) の箇所を \\(1\\) を含むブロックと対応付ける方法（&lt;a href="https://arxiv.org/abs/math/0310157"&gt;Callan&lt;/a&gt;）。これは、葉がn個の全２分木の各sprigをブロックに対応付けている。&lt;/p&gt;
&lt;p&gt;\\(\\pi \\in \\mathrm&#123;NC&#125;_n\\)について、その重み\\(g(\\pi)\\)を数列\\(g\\)によって \\(\\prod_&#123;B \\in \\pi&#125; g_&#123;\\#B&#125;\\) と定義する。このとき、\\(F(x)=\\sum_&#123;n \\geq 1&#125; \\sum_&#123;\\pi \\in \\mathrm&#123;NC&#125;_n&#125;g(\\pi)x^n, G(x) = \\sum_&#123;n \\geq 1&#125;g_nx^n\\) と置くと、\\(F(x) = G(xF(x)))\\) である。証明は、\\(1\\) を含むブロックを\\(\\&#123;a_1, a_2, \\ldots, a_k\\&#125;_&#123;&lt;&#125;\\) と置くと、そのほかのブロックは \\(\\&#123;a_&#123;i&#125;+1, a_&#123;i&#125;+2, \\ldots, a_&#123;i+1&#125;-1\\&#125;\\) \\((1 \\leq i \\leq k)\\) の非交差分割で書けるからである。ただし、\\(a_&#123;k+1&#125;=n+1\\) とする。このとき、Lagrange反転により \\([x^n]F(x)=[x^&#123;-1&#125;] G(x)^&#123;n+1&#125;x^&#123;-1&#125;/(n+1)\\) である。&lt;/p&gt;
&lt;h2&gt;k重のdyck path&lt;/h2&gt;
&lt;p&gt;k個の長さ2nの平衡括弧列 \\(s_0, s_1, \\ldots, s_&#123;k-1&#125;\\) であって、任意の地点の prefix sum が \\(s_0, s_1, \\ldots, s_&#123;k-1&#125;\\) の順に広義単調増加になるようなものの個数を求めたい。\\(i=1,2\\ldots,k\\)について\\(s_i\\)を\\(\\mathtt&#123;(&#125;^is_i\\mathtt&#123;)&#125;^i\\)で置き換えると、非交差経路の数え上げになり、LGV公式により以下のように計算できる&lt;a href="https://arxiv.org/pdf/0709.3044"&gt;Krattenthaler&lt;/a&gt;。&lt;br /&gt;\\begin&#123;align&#125;&lt;br /&gt;&amp;\\det_&#123;0 \\leq i, j &lt; k&#125; C_&#123;n+i+j&#125; \\\\&lt;br /&gt;=&amp;\\det_&#123;0 \\leq i, j &lt; k&#125; 2^&#123;n+i+j&#125; \\frac&#123;1\\cdot3\\cdot5\\cdots(2(n+i+j)-1)&#125;&#123;(n+i+j)!&#125; \\\\&lt;br /&gt;=&amp;2^&#123;n^2&#125;\\det_&#123;0 \\leq i, j &lt; k&#125; \\frac&#123;(-\\frac&#123;1&#125;&#123;2&#125;+1)\\cdot(-\\frac&#123;1&#125;&#123;2&#125;+2)\\cdots(-\\frac&#123;1&#125;&#123;2&#125;+(n+i+j))&#125;&#123;(n+i+j)!&#125; \\\\&lt;br /&gt;=&amp;2^&#123;n^2&#125;\\frac&#123;\\prod_&#123;i=0&#125;^&#123;k-1&#125;\\left(-\\frac&#123;1&#125;&#123;2&#125;+1\\right)\\cdot\\left(-\\frac&#123;1&#125;&#123;2&#125;+2\\right)\\cdots\\left(-\\frac&#123;1&#125;&#123;2&#125;+(n+i)\\right)&#125;&#123;(n+k-1)!(n+k)!\\cdots(n+2(k-1))!&#125;\\det_&#123;0 \\leq i, j &lt; k&#125; \\left(-\\frac&#123;1&#125;&#123;2&#125;+n+i+1\\right)\\cdot\\left(-\\frac&#123;1&#125;&#123;2&#125;+n+i+2\\right)\\cdots\\left(-\\frac&#123;1&#125;&#123;2&#125;+(n+i+j)\\right)(n+i+j+1)(n+i+j+2) \\cdots (n+i+(k-1)) \\\\&lt;br /&gt;=&amp;2^&#123;n^2&#125;\\frac&#123;\\prod_&#123;i=0&#125;^&#123;k-1&#125;\\left(-\\frac&#123;1&#125;&#123;2&#125;+1\\right)\\cdot\\left(-\\frac&#123;1&#125;&#123;2&#125;+2\\right)\\cdots\\left(-\\frac&#123;1&#125;&#123;2&#125;+(n+i)\\right)&#125;&#123;(n+k-1)!(n+k)!\\cdots(n+2(k-1))!&#125;\\det_&#123;0 \\leq i, j &lt; k&#125; (x_i + a_1)(x_i + a_2)\\cdots(x_i + a_j)(x_i+b_&#123;j+1&#125;)(x_i+b_&#123;j+2&#125;)\\cdots(x_i+b_&#123;k-1&#125;) \\\\&lt;br /&gt;=&amp;2^&#123;n^2&#125;\\frac&#123;\\prod_&#123;i=0&#125;^&#123;k-1&#125;\\left(-\\frac&#123;1&#125;&#123;2&#125;+1\\right)\\cdot\\left(-\\frac&#123;1&#125;&#123;2&#125;+2\\right)\\cdots\\left(-\\frac&#123;1&#125;&#123;2&#125;+(n+i)\\right)&#125;&#123;(n+k-1)!(n+k)!\\cdots(n+2(k-1))!&#125;\\prod_&#123;0 \\le i \\leq j &lt; k&#125;(x_i-x_j) \\prod_&#123;1 \\leq i \\leq j \\leq k-1&#125; (a_i-b_j)\\\\&lt;br /&gt;\\end&#123;align&#125;&lt;/p&gt;
&lt;p&gt;最後は \\(x_i=n+i,a_i=i-1/2,b_i=i+1\\) と置いた。以下のような変形を用いた。&lt;/p&gt;
&lt;p&gt;\\(j\\)列目から\\(j+1\\)列目を引くことを\\(j=1,2,\\ldots,k-2\\)の順に行うと&lt;br /&gt;\\begin&#123;align&#125;&lt;br /&gt;&amp;\\det_&#123;0 \\leq i, j &lt; k&#125; (x_i + a_1)(x_i + a_2)\\cdots(x_i + a_j)(x_i+b_&#123;j+1&#125;)(x_i+b_&#123;j+2&#125;)\\cdots(x_i+b_&#123;k-1&#125;) \\\\&lt;br /&gt;=&amp;\\prod_&#123;j=1&#125;^&#123;k-1&#125;(a_j-b_j)\\det_&#123;0 \\leq i, j &lt; k&#125; (x_i + a_1)(x_i + a_2)\\cdots(x_i + a_&#123;j-1&#125;)(x_i+b_&#123;j+1&#125;)(x_i+b_&#123;j+2&#125;)\\cdots(x_i+b_&#123;k-1&#125;)&lt;br /&gt;\\end&#123;align&#125;&lt;br /&gt;となる。これを繰り返すと、\\(\\prod_&#123;1 \\leq i \\leq j \\leq k-1&#125;^&#123;k-1&#125;(a_i-b_j)\\det_&#123;0 \\leq i, j &lt; k&#125; (x_i+b_&#123;j+1&#125;)(x_i+b_&#123;j+2&#125;)\\cdots(x_i+b_&#123;k-1&#125;)\\)となり、あとはVandermonde行列の場合と同じ。&lt;/p&gt;
&lt;p&gt;括弧列をDyckパスに移し、i番目のDyckパスとi-1番目のDyckパスの間にiを書き込むと、形が\\((n-1,n-2,\\ldots,1)\\)で0, 1, .., kが書き込まれたplane partitionとの全単射ができる。このplane partitionを3次元図形に移して、横から見たときの図形から、また別種の非交差経路の数え上げに帰着出来て、\\(\\det_&#123;0 \\leq i, j &lt; k&#125; C_&#123;n+i+j&#125; = \\det_&#123;0 \\leq i, j &lt; n&#125; &#123;k+i+j \\choose 2j&#125;\\) となる（&lt;a href="https://arxiv.org/abs/2306.07733"&gt;Cigler&lt;/a&gt;, &lt;a href="https://arxiv.org/abs/2010.06586"&gt;Feng&lt;/a&gt;）。&lt;/p&gt;
&lt;h2&gt;広義単調減少列の数え上げ&lt;/h2&gt;
&lt;p&gt;長さ \\(N\\) の広義単調減少整数列 \\(M \\geq \\lambda_1 \\geq \\lambda_2 \\geq \\cdots \\geq \\lambda_N \\geq 0\\) が与えられたとき、任意の \\(i\\) について \\(\\lambda_i \\geq a_i \\geq 0\\) を満たす広義単調減少列 \\(a\\) の個数 mod \\(P\\) を \\(O((N+M)\\log(N+M)^2)\\) で求める&lt;a href="https://noshi91.hatenablog.com/entry/2023/07/21/235339"&gt;noshi91&lt;/a&gt;さんの手法があるが、LGV公式で個数を表してみる（&lt;a href="https://arxiv.org/abs/1503.05930"&gt;Theorem 10.7.1&lt;/a&gt;）。この方針で高速に計算できるかは分からなかった。&lt;/p&gt;
&lt;p&gt;まず、一般論として、平面分割と非交差経路の全単射が知られている（&lt;a href="https://zenn.dev/koboshi/articles/306304c0381c1e#3-%E6%AC%A1%E5%85%83%E3%83%A4%E3%83%B3%E3%82%B0%E5%9B%B3%E5%BD%A2"&gt;出題例&lt;/a&gt;）。平面分割とは、非負整数配列 \\(\\pi = (\\pi_&#123;i,j&#125;)_&#123;i,j\\geq 1&#125;\\) であって行・列方向に広義単調減少かつ非ゼロ要素が有限個であるもののこと。&lt;/p&gt;

&lt;h2&gt;上限・下限があるときのDyckパスの数え上げ&lt;/h2&gt;
&lt;p&gt;\\(y=k\\)に関する反転について不変なstepの集合を用いて (0, 0) から (a, b) に移動するパスのうち、\\(s \\leq y \\leq t\\) を満たすものの数え上げ。y=s-1についての反転をS, y=t+1についての反転をTと置く。\\(y=k\\)についての反転は\\((x,y)\\)を\\((x,2k-y)\\)に移す。\\(ST(x,y)=(x,y-2(t-s+2))\\)。 \\(ST = (TS)^&#123;-1&#125;, T(ST)^&#123;-1&#125;=S\\) より \\((ST)^k, T(ST)^k\\) (\\(k \\in \\mathbb&#123;Z&#125;\\)) によって S, T からなる列（空列含む）が全て表せる。\\(s \\leq y \\leq t\\) を無視したときの経路数を \\(f(a, b)\\) と置くと求める値は\\(\\sum_&#123;i \\in \\mathbb&#123;Z&#125;&#125;f(a,b-2i(t-s+2))-\\sum_&#123;i \\in \\mathbb&#123;Z&#125;&#125;f(a, -b+2t+2+2i(t-s+2))\\) となる。\\(f(a, b) = &#123;a \\choose \\frac&#123;a+b&#125;&#123;2&#125;&#125;\\) のときは、\\(m=\\frac&#123;a+b&#125;&#123;2&#125;\\)と置くと\\(\\sum_&#123;i \\in \\mathbb&#123;Z&#125;&#125; &#123;a \\choose i(t-s+2)+m&#125; - \\sum_&#123;i \\in \\mathbb&#123;Z&#125;&#125; &#123;a \\choose i(t-s+2)+m-t-1&#125; \\)となる。 &lt;/p&gt;

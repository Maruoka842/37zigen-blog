# B

> 📅 **投稿日**: 2021-04-07 17:02:26

与えられた数 \\(n\\) が素数かどうかを誤り率 \\(2^&#123;-k&#125;\\) 以下、時間 \\(O(k\\log(n))\\) で求める Solovay–Strassen 素数判定法を紹介します。ミラー・ラビン素数判定法と比べてやや単純で面白いと思います。平方剰余の相互法則がアルゴリズムに生かせるというのが熱い。
[toc]

アルゴリズムのアイディアを理解するには、平方剰余/非剰余の性質を少し知っている必要があります。
&lt;h2&gt;平方剰余/非剰余と \\(x^&#123;(p-1)/2&#125;\\) の関係&lt;/h2&gt;
奇素数 \\(p\\) に対して、\\(x^2=a \\bmod p\\) が解をもつとき \\(a\\) を平方剰余、解を持たないとき \\(a\\) を非平方剰余といいます。\\((\\mathbb&#123;Z&#125;/p\\mathbb&#123;Z&#125;)^\\times\\) は巡回群であり、任意の \\(a \\in (\\mathbb&#123;Z&#125;/p\\mathbb&#123;Z&#125;)^\\times\\) に対して \\(a=g^i\\) なる \\(i\\) が存在する \\(g\\) （原始根）が存在します。つまり、\\((\\mathbb&#123;Z&#125;/p\\mathbb&#123;Z&#125;)^\\times=\\&#123;g^0,g^1,\\ldots,g^&#123;p-2&#125;\\&#125;\\) です。原始根を用いて平方剰余は \\(g^&#123;2i&#125;\\)、非平方剰余は \\(g^&#123;2i+1&#125;\\) と書け、\\(p\\) が奇数より両者は同数存在します。

\\(x^2 = 1 \\Leftrightarrow x=\\pm1\\) と \\(x^&#123;p-1&#125;=1\\) より、\\(x^&#123;(p-1)/2&#125;=\\pm1\\) です。平方剰余は \\(g^&#123;2i&#125;\\) の形で表せたことから、 \\(x^&#123;(p-1)/2&#125; = 1\\) の解です。高々 \\((p-1)/2\\) 個しか解が存在しないことから、平方剰余で解は尽くされており、残りの平方非剰余は \\(x^&#123;(p-1)/2&#125; = -1\\) の解です。
&lt;h2&gt;ルジャンドル記号の二つの計算&lt;/h2&gt;
\\(a^&#123;(p-1)/2&#125;=\\pm1\\) と平方剰余/非剰余の関係を念頭に置いて、奇素数 \\(p\\) と整数 \\(a\\) に対して、ルジャンドル記号を$$\\left(\\frac&#123;a&#125;&#123;p&#125;\\right) = \\begin&#123;cases&#125; 1 &amp;( a \\equiv \\eta^2 \\pmod p \\text&#123; なる &#125; \\eta \
eq 0 \\pmod p\\text&#123; が存在&#125;)\\\\
-1 &amp;( a \\equiv \\eta^2 \\pmod p \\text&#123; なる &#125; \\eta \\text&#123; が存在しない&#125;)\\\\
0 &amp; (a=0 \\pmod p)
\\end&#123;cases&#125;$$で定義します。平方剰余/非剰余が \\(g\\) の冪の偶奇で決まったことを思い出すと、\\(\\left(\\frac&#123;ab&#125;&#123;p&#125;\\right) = \\left(\\frac&#123;a&#125;&#123;p&#125;\\right) \\left(\\frac&#123;b&#125;&#123;p&#125;\\right)\\) が成り立ちます。異なる奇素数 \\(p, q\\) 同士のルジャンドル記号には平方剰余の相互法則$$\\left(\\frac&#123;q&#125;&#123;p&#125;\\right) \\left(\\frac&#123;p&#125;&#123;q&#125;\\right)= (-1)^&#123;\\frac&#123;p-1&#125;&#123;2&#125;\\cdot\\frac&#123;q-1&#125;&#123;2&#125;&#125;$$が成り立つことが知られています。また \\(\\left(\\frac&#123;2&#125;&#123;p&#125;\\right) = (-1)^&#123;(p^2-1)/8&#125;\\) が成り立ちます。以上から、ルジャンドル記号の計算は \\(\\left(\\frac&#123;a&#125;&#123;p&#125;\\right)=a^&#123;(p-1)/2&#125;\\) を用いることのほかに、次のような方法があります。
&lt;ul&gt;
 	&lt;li&gt;\\(a=2b\\) ならば、\\(\\left(\\frac&#123;2b&#125;&#123;p&#125;\\right) = (-1)^&#123;(p^2-1)/8&#125;\\left(\\frac&#123;b&#125;&#123;p&#125;\\right)\\) とします。&lt;/li&gt;
 	&lt;li&gt;\\(a\\) が奇数ならば、平方剰余の相互法則 \\(\\left(\\frac&#123;a&#125;&#123;p&#125;\\right) = (-1)^&#123;\\frac&#123;p-1&#125;&#123;2&#125;\\cdot\\frac&#123;a-1&#125;&#123;2&#125;&#125;\\left(\\frac&#123;p&#125;&#123;a&#125;\\right)\\) を用いて、法を交換します。\\(\\left(\\frac&#123;p&#125;&#123;a&#125;\\right) = \\left(\\frac&#123;p \\bmod a&#125;&#123;a&#125;\\right) \\) より、法を交換すると底が必ず減らせます。法を交換したルジャンドル記号を再帰的に計算します。&lt;/li&gt;
 	&lt;li&gt;\\(a\\) が合成数ならば、素因数分解 \\(a=\\prod p_i^&#123;e_i&#125;\\) に対して、\\(\\left(\\frac&#123;a&#125;&#123;p&#125;\\right) = \\prod \\left(\\frac&#123;p_i&#125;&#123;p&#125;\\right)^&#123;e_i&#125;\\) です。各素因数のルジャンドル記号を再帰的に計算します。&lt;/li&gt;
&lt;/ul&gt;
平方剰余の相互法則により、\\(\\left(\\frac&#123;a&#125;&#123;p&#125;\\right) = a^&#123;(p-1)/2&#125;\\) とは全く異なった計算でルジャンドル記号を求められました。単にルジャンドル記号を求めるだけなら、平方剰余の相互法則を用いることは何の長所もありません（むしろ、因数分解で計算量が悪化）。しかし、\\(p\\) の素数判定となれば、話は別です。&lt;span class="marker_line20"&gt;「\\( \\left(\\frac&#123;a&#125;&#123;p&#125;\\right) \\) を \\( a^&#123;(p-1) / 2&#125; \\) と平方剰余の相互法則の二通りで求めて、一致するか確かめる」&lt;/span&gt;というのが Solovay–Strassen の素数判定のアイディアです。
&lt;h2&gt;ヤコビ記号は速い&lt;/h2&gt;
ルジャンドル記号を平方剰余の相互法則で求めるとき、素因数分解が計算量のボトルネックになりました。しかし、素因数分解は法を合成数に拡張したヤコビ記号で回避できます。ヤコビ記号は、任意の奇数 \\(n=\\prod p_i^&#123;e_i&#125;\\) と任意の整数 \\(a\\) に対して、ルジャンドル記号の積 \\(\\left(\\frac&#123;a&#125;&#123;n&#125;\\right) = \\prod \\left(\\frac&#123;a&#125;&#123;p_i&#125;\\right)^&#123;e_i&#125;\\) で定義されます。ルジャンドル記号では、法が素数でなくとも、互いに素ならば平方剰余の相互法則が成り立ち、$$\\left(\\frac&#123;m&#125;&#123;n&#125;\\right) \\left(\\frac&#123;n&#125;&#123;m&#125;\\right)= (-1)^&#123;\\frac&#123;n-1&#125;&#123;2&#125;\\cdot\\frac&#123;m-1&#125;&#123;2&#125;&#125;, \\ \\ \\ \\ (\\gcd(n,m)=1)$$です。\\(n\\) が合成数でも \\(\\left(\\frac&#123;2&#125;&#123;n&#125;\\right)=(-1)^&#123;(n^2-1)/8&#125;\\) は成り立ちます。\\(\\gcd(n,m) \
eq 1\\) ならば \\(\\left(\\frac&#123;n&#125;&#123;m&#125;\\right)=0\\) であることを併せると、平方剰余の相互法則を繰り返し適用して法を交換することで、ヤコビ記号が \\(O(\\log(n))\\) で求まります！　ルジャンドル記号だけでは素因数分解が必要でしたが、ヤコビ記号では不要になり、計算量が改善しました。
&lt;h2&gt;アルゴリズム&lt;/h2&gt;
アルゴリズムは非常にシンプルです。誤り率 \\(2^&#123;-k&#125;\\) 以下で \\(n\\) が素数か判定したいとします。
&lt;ol&gt;
 	&lt;li&gt;\\(n\\) が偶数ならば、\\(n=2\\) のとき奇数、さもなくば合成数です。以下、\\(n\\) が奇数とします。&lt;/li&gt;
 	&lt;li&gt;(i), (ii), (iii) を \\(k\\) 回繰り返します。&lt;/li&gt;
&lt;ol type="i"&gt;
 	&lt;li&gt;ランダムな整数 \\(a \
eq 0\\) を取ってきます。&lt;/li&gt;
 	&lt;li&gt;\\(\\gcd(a,n) &gt; 1\\) ならば \\(n\\) は合成数で確定です。&lt;/li&gt;
 	&lt;li&gt;\\(\\left(\\frac&#123;a&#125;&#123;p&#125;\\right)\\) を平方剰余の相互法則、\\(a^&#123;(n-1)/2&#125;\\) を繰り返し二乗法で求めます。\\(\\left(\\frac&#123;a&#125;&#123;p&#125;\\right) \
eq a^&#123;(n-1)/2&#125;\\) ならば \\(n\\) は合成数で確定です。&lt;/li&gt;
&lt;/ol&gt;
 	&lt;li&gt;\\(n\\) が合成数と確定していなければ、素数と判定します。&lt;/li&gt;
&lt;/ol&gt;
なかなか、シンプルです。合成数 \\(n\\) を誤って素数と判定する確率が \\(2^&#123;-k&#125;\\) 以下であることは次の節で証明します。
&lt;h2&gt;正当性の証明&lt;/h2&gt;
\\(\\left(\\frac&#123;a&#125;&#123;n&#125;\\right) \
eq a^&#123;(n-1)/2&#125;\\) ならば \\(n\\) は合成数です。そこで、\\(a\\) を合成数 \\(n\\) に対するオイラー証人（Euler Witness）と呼びます。また、合成数 \\(n\\) に対して \\(\\left(\\frac&#123;a&#125;&#123;n&#125;\\right) = a^&#123;(n-1)/2&#125;\\) となる \\(a\\) をオイラー嘘つき（Euler Liar）と呼びます。Solovay–Strassen 素数判定法の誤り率が \\(2^&#123;-k&#125;\\) 以下であることをこの節で示します。つまり、\\(\\&#123;1,2,\\ldots,n-1\\&#125;\\) のうち、オイラー嘘つきが半分以上を占めることを示します。
&lt;div class="statement"&gt;定理：任意の合成数 \\(n\\) に対して、オイラー証人は１つ以上存在します。&lt;/div&gt;
&lt;div class="proof"&gt;証明：
(i) \\(n\\) が平方因子 \\(p^2\\) (\\(p\\) : 素数) を持つ場合：
\\(n\\) と互いに素な数 \\(a\\) に対して、定義より \\(\\left(\\frac&#123;a&#125;&#123;n&#125;\\right)=\\pm1\\) です。従って、オイラー証人が存在しなければ任意の \\(a \\in (\\mathbb&#123;Z&#125;/p^2\\mathbb&#123;Z&#125;)^\\times\\) に対して \\(\\left(\\frac&#123;a&#125;&#123;n&#125;\\right)^2=a^&#123;n-1&#125;=1\\) です。\\((\\mathbb&#123;Z&#125;/p^2\\mathbb&#123;Z&#125;)^\\times\\) は要素数 \\(p(p-1)\\) の巡回群なので、\\(n-1\\) は \\(p(p-1)\\) の倍数である必要があります。しかし、\\(n-1 \
eq 0 \\pmod p\\) より矛盾しているので、オイラー証人が存在します。

(ii) ２つ以上の相異なる素数の積 \\(n=\\prod p_i\\) の場合：
中国剰余定理より、\\(i=1\\) のとき \\(\\left(\\frac&#123;a&#125;&#123;p_i&#125;\\right)=-1\\)、\\(i\
eq 1\\) のとき \\(\\left(\\frac&#123;a&#125;&#123;p_i&#125;\\right)=1\\) となる \\(a\\) を取れます。このとき、\\(\\left(\\frac&#123;a&#125;&#123;n&#125;\\right)=\\prod \\left(\\frac&#123;a&#125;&#123;p_i&#125;\\right)=-1\\) です。同様に全ての \\(i\\) で \\(\\left(\\frac&#123;b&#125;&#123;p_i&#125;\\right)=1\\) かつ \\(i \
eq 1\\) で \\(a = b \\pmod p_i\\) となる \\(b\\) を取れます。このとき、\\(\\left(\\frac&#123;b&#125;&#123;n&#125;\\right)=\\prod \\left(\\frac&#123;b&#125;&#123;p_i&#125;\\right)=-1\\) です。オイラー証人が存在しないと仮定します。\\(a^&#123;n-1&#125;=-1,b^&#123;n-1&#125;=1 \\pmod n\\) ですが、\\(a,b\\) は \\(i \
eq 1\\) のとき \\(a^&#123;n-1&#125; = b^&#123;n-1&#125; \\pmod p_i\\) です。矛盾しているのでオイラー証人が存在します。

&lt;/div&gt;
先の定理より、オイラー証人が一つは存在するので、次の定理より、オイラー証人が半分以上を占めます。
&lt;div class="statement"&gt;定理：任意の合成数 \\(n\\) に対して、オイラー証人が一つでもあれば、\\(\\&#123;1,2,\\ldots,n-1\\&#125;\\) の半分以上がオイラー証人です。&lt;/div&gt;
&lt;div class="proof"&gt;
証明：\\(x \
eq 0\\) が \\(\\gcd(x,n) &gt; 1\\) ならば、\\(n\\) は合成数と確定するので、\\(x\\) はオイラー証人です。そこで、\\((\\mathbb&#123;Z&#125;/n\\mathbb&#123;Z&#125;)^\\times\\) の要素のうち、オイラー証人である者の個数を数えます。

\\(a\\) をオイラー証人とし, \\(b\\) をオイラー嘘つきとします。つまり、$$\\begin&#123;eqnarray&#125;
\\left\\&#123;
\\begin&#123;array&#125;&#123;l&#125;
\\left(\\frac&#123;a&#125;&#123;n&#125;\\right) \
eq a^&#123;(n-1)/2&#125; \\bmod n \\\\
\\left(\\frac&#123;b&#125;&#123;n&#125;\\right) = b^&#123;(n-1)/2&#125; \\bmod n
\\end&#123;array&#125;
\\right.
\\end&#123;eqnarray&#125;$$ とします。
\\( \\left(\\frac&#123;ab&#125;&#123;n&#125;\\right) = \\left(\\frac&#123;a&#125;&#123;n&#125;\\right) \\left(\\frac&#123;b&#125;&#123;n&#125;\\right) \
eq (ab)^&#123;(n-1)/2&#125;\\) より、\\(ab\\) もまたオイラー証人です。オイラー証人の集合は部分集合をなします。よって、ラグランジュの定理よりオイラー証人が存在すれば、オイラー証人は \\((\\mathbb&#123;Z&#125;/n\\mathbb&#123;Z&#125;)^\\times\\) の半分以上を占めます。（証明終了）

using namespace std;

long long pow(long long a, long long n, long long p) &#123;
  return n != 0 ? pow(a*a%p, n/2, p) * (n%2 == 1 ? a : 1) % p : 1;
&#125;

long long gcd(long long a, long long b) &#123;
  return a == 0 ? b : gcd(b % a, a);
&#125;

// return (n / m)
long long jacobi(long long n, long long m) &#123;
  if (n == 1)
    return 1;
  if (n % 2 == 0)
    return ((m*m-1)/8 % 2 == 0 ? 1 : -1) * jacobi(n/2, m);
  return ((n-1)/2*(m-1)/2 % 2 == 0 ? 1 : -1) * jacobi(m % n, n);
&#125;

// n が素数か判定
bool solovay_strassen(long long n) &#123;
  if (n % 2 == 0) return n == 2;  
  random_device seed_gen;
  default_random_engine engine(seed_gen());
  uniform_int_distribution&lt;&gt; dist(1, n - 1);
  for (int i = 0; i &lt; 20; ++i) &#123;
    long long a = dist(engine);
    if (gcd(a , n) &gt; 1) return false;
    if ((jacobi(a, n) + n)% n != pow(a, (n - 1) / 2, n))
      return false;
  &#125;
  return true;

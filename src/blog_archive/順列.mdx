降下数:\\(\\mathrm&#123;des&#125;(w)=\\#D(w)\\)
逆降下集合：\\(\\mathrm&#123;ID&#125;=\\mathrm&#123;D&#125;(w^&#123;-1&#125;)\\)
IDはwを要素の昇順に見ていったとき、右から左に戻る直前までで読んだ要素数の集合と等しい。
major index:\\(\\mathrm&#123;maj&#125;(w)=\\sum_&#123;i \\in D(w)&#125;i\\)

\\(\\sum_&#123;w \\in \\mathcal&#123;S&#125;_n&#125; q^&#123;\\mathrm&#123;inv&#125;(w)&#125; = \\sum_&#123;w \\in \\mathcal&#123;S&#125;_n&#125; q^&#123;\\mathrm&#123;maj&#125;(w)&#125; =\\boldsymbol n!\\)
inv, majの母関数がこのようになることは挿入dpで分かる（&lt;a href="https://twitter.com/kaichou243/status/1610550581311188992?t=AxKwv7T5q4OBzGLv12_1Ng&amp;s=19"&gt;会長さん&lt;/a&gt;）。相異なる整数からなる長さ n の列 p に対して、p に含まれない整数 x を挿入したとき、maj が \\(0, 1, \\ldots, n\\) だけ増加する箇所がちょうど一つずつ存在する。 証明は次のとおり。p をいくつかの極大な増加列に分解したときの各長さを並べた数列を a, 減少列に分解したときのそれを b と置く。a の各要素を 1 だけ増加する挿入箇所が一つだけ存在し、それぞれ先頭から順に \\(\\mathrm&#123;des&#125;(p), \\ldots, 2, 1, 0\\) だけ maj が増加する。また、b の各要素を 1 だけ増加する挿入箇所が一つだけ存在し、それぞれ先頭から順に \\(\\mathrm&#123;des&#125;(p)+1, \\ldots, 2, n-1, n\\) だけ maj が増加する。また\\(\\mathrm&#123;inv&#125;(\\phi(w))=\\mathrm&#123;maj&#125;(w)\\)となるような全単射\\(\\phi:\\mathfrak&#123;S&#125;_n \\to \\mathfrak&#123;S&#125;_n\\)が構成できる。\\(\\gamma = \\phi(w_1 \\cdots w_&#123;n-1&#125;)\\)と置く。
\\(\\gamma_&#123;n-1&#125; &lt; w_n\\) のとき、\\(\\gamma_&#123;i&#125; &lt; w_&#123;n&#125;\\) となる \\(i\\) が末尾となるように順列を分割して各成分を右に巡回シフト。\\(\\gamma_&#123;n-1&#125; &gt; w_n\\) のとき、\\(\\gamma_&#123;i&#125; &gt; w_&#123;n&#125;\\) となる \\(i\\) が末尾となるように順列を分割して各成分を右に巡回シフト。これは、\\(\\phi(\\gamma w_n) \\) の先頭と末尾の大小関係によってどちらか区別できるので全単射になっている。要は \\(w_n\\) と \\(\\gamma\\) の各要素との大小比較によって、\\(\\gamma w_n \\mapsto \\phi(\\gamma w_n)\\) を以下の形で場合分けしている。
$$\\begin&#123;align&#125;&amp;(\\prod(0^&#123;e_i&#125;2))1 \\mapsto (\\prod(20^&#123;e_i&#125;))1  \\\\&amp;(\\prod(2^&#123;e_i&#125;0))1 \\mapsto (\\prod(02^&#123;e_i&#125;))1 \\end&#123;align&#125;$$
\\(\\phi\\) は inverse descent set を保つ。multiset \\(M\\) 上の順列を、standardization した順列を inverse descent set で特徴づけると、\\(\\sum_&#123;w \\in S_M&#125;q^&#123;\\mathrm&#123;inv&#125;(w)&#125; = \\sum_&#123;w \\in S_M&#125;q^&#123;\\mathrm&#123;maj&#125;(w)&#125;\\) が得られる。
\\(\\sum_&#123;w \\in \\mathcal&#123;S&#125;_n&#125; q^&#123;\\mathrm&#123;maj&#125;(w)&#125; =\\boldsymbol n! \\iff \\sum_&#123;w \\in \\mathcal&#123;S&#125;_n&#125; \\frac&#123;q^&#123;\\mathrm&#123;maj&#125;(w)&#125;&#125;&#123;(1-q)\\cdots(1-q^&#123;n-1&#125;)&#125; =  \\frac&#123;1&#125;&#123;(1-q)^n&#125;\\) とすると、(P,ω)分割の式になる。\\(M=\\&#123;1^&#123;m_1&#125;, \\cdots, k^&#123;m_k&#125;\\&#125;\\)とすると、\\(\\sum_&#123;w \\in \\mathcal&#123;S&#125;_M&#125; \\frac&#123;q^&#123;\\mathrm&#123;maj&#125;(w)&#125;&#125;&#123;(1-q)\\cdots(1-q^&#123;n-1&#125;)&#125; =  \\prod_i\\sum_&#123;w \\in \\mathcal&#123;S&#125;_&#123;m_i&#125;&#125; q^&#123;\\mathrm&#123;maj&#125;(w)&#125;\\) となり、 同様に(P, ω)分割の式(&lt;a href="https://www.sciencedirect.com/science/article/pii/000187087990046X"&gt;論文&lt;/a&gt;)。

\\((\\mathrm&#123;inv&#125; w^&#123;-1&#125;, \\mathrm&#123;maj&#125; w^&#123;-1&#125;) = (\\mathrm&#123;inv&#125; w, \\mathrm&#123;imaj&#125; w)\\) と \\((\\mathrm&#123;inv&#125; \\phi(w), \\mathrm&#123;imaj&#125; \\phi(w)) = (\\mathrm&#123;maj&#125;w, \\mathrm&#123;imaj&#125;w)\\) より (inv,maj), (inv, imaj), (maj, imaj) は対称結合分布。

\\(\\boldsymbol&#123;a_1!a_2!\\cdots a_m!&#125;\\sum_&#123;w \\in \\mathfrak S_M&#125; q^&#123;inv(w)&#125; = \\boldsymbol&#123;n!&#125;\\)
の形を示す。これは、全単射 \\(\\phi : \\mathfrak S_&#123;a_1&#125;\\times \\mathfrak S_&#123;a_2&#125;\\times \\cdots \\mathfrak S_&#123;a_m&#125;\\times \\mathfrak S_M \\to \\mathfrak&#123;S&#125;_n \\)であって、左辺の各成分の転倒数の和が右辺の転倒数になるものを構成すれば良い。小さい数から順に割り当てていけば良い。invをmajに変えても同様の式が成り立つ。\\(\\mathfrak&#123;S&#125;_n\\)のときと同様に全単射を作れば示せる。

となる。\\(|f| = \\sum_i f(i)\\) と置く。\\(\\sum_&#123;f \\in &#123;\\mathbb&#123;N&#125;^0&#125;^&#123;[n]&#125;&#125; q^&#123;|f|&#125; = \\sum_&#123;w \\in \\mathfrak&#123;S&#125;_n&#125;\\sum_&#123;f \\in \\mathcal&#123;A&#125;_w&#125; q^&#123;|f|&#125;\\) を計算すると、\\(\\sum_&#123;w \\in \\mathfrak&#123;S&#125;_n&#125; q^&#123;maj(w)&#125; = \\boldsymbol&#123; n!&#125;\\) が得られる。

&lt;h3&gt;増加二分木&lt;/h3&gt;
順列pが最小値aを用いて、語として \\(p_Lap_R\\) と書けるとき、p の増加木 \\(T(p)\\) を、aを根、左子を\\(T(p_L)\\)、右子を\\(T(p_R)\\)とした木として定義する。増加木と順列は一対一対応する。
\\(a_i\\) より右/左にある\\(a_i\\)より小さい要素のうち、右/左それぞれ最も i の近くにあるものを取り、大きい方が \\(a_i\\) の親になる。このようなものはスタックにより線形時間で列挙できるのでデカルト木は線形時間で構築できる。また、O(1)-RMQで線形時間で構築できる。また、オンラインで構築する方法もある。\\(a_&#123;n+1&#125;\\) を追加したいとする。\\(a_n\\) に対応する頂点の親を順に辿り、最初に見つけた \\(a_n\\) より小さいものの子を \\(a_&#123;n+1&#125;\\) とすればよい。親を辿る回数の合計は順列の長さで抑えられる。\\(p_&#123;i-1&#125; &gt; p_i &lt; p_&#123;i+1&#125;\\) ならば \\(p_i\\) は子を二つ持つ。
\\(p_&#123;i-1&#125; &lt; p_i &lt; p_&#123;i+1&#125;\\) ならば \\(p_i\\) は右子だけ持つ。
\\(p_&#123;i-1&#125; &gt; p_i &gt; p_&#123;i+1&#125;\\) ならば \\(p_i\\) は左子だけ持つ。
\\(p_&#123;i-1&#125; &lt; p_i &gt; p_&#123;i+1&#125;\\) ならば \\(p_i\\) は葉である。
&lt;h3&gt;ケーリー増加木&lt;/h3&gt;
子の順序を区別しない多分木に、\\([n]\\) のラベルを子のラベルが親以上になるように割り当てた木を、ケーリー増加木と呼ぶ。根の子がサイクル分解の標準形の left-to-right minima に対応しているので、\\(n + 1\\) 頂点のケーリー増加木と \\([n]\\) 上の順列は全単射の関係にある。 p[i] の右にある p[i] 未満の値のうち、p[i] に最も近い値を p[i] の親にするといってもよい。この木は \\(\\phi(i) &lt; i\\) を満たす写像 \\(\\phi : [2, n] \\to [n-1]\\) と同一視できる。このような写像を後退写像と呼ぶことにする。順列 \\(p\\) に対して \\(a_i = \\#\\&#123;j : j &lt; i, p_i &gt; p_j\\&#125;\\) を並べた列 \\(I(p) = (a_1, a_2, \\ldots, a_n) \\) を転倒表と呼ぶ。転倒表は後退写像である。転倒列も後退写像なので、順列と全単射の関係にある。

要素数 n+1 の increasing tree は長さ n の順列 P との全単射がある。各 i に対して P 上で i の左側にある i より小さい最右の数 j を取りi の親を j とする（なければj=0）。i( &lt; u,v)がu,vの祖先になる確率が2/i(i+1)であることを示せ(&lt;a href="https://atcoder.jp/contests/arc195/tasks/arc195_e"&gt;AtC&lt;/a&gt;)

n!-1回しか隣接swapしないSteinhaus–Johnson–Trotter algorithmもある。全ての要素に対して左向きのラベルを貼る。ラベルの向きに動かせる最大の要素をその向きに一つ動かし、それより大きい要素のラベルの向きを反転させることを繰り返す。

順列\\(\\pi\\)に対して、転倒している添字同士を結んだ無向グラフを\\(G_\\pi\\)と書き、転倒グラフ（inversion graph）と呼ぶ。転倒グラフは比較可能グラフである。逆に\\(G\\)と補グラフ\\(\\bar G\\)の両方が比較可能グラフであることと、Gが転倒グラフであることが同値。\\(G\\)と\\(\\bar G\\)が比較可能グラフとする。向き付けた辺集合\\(F,F'\\)について、\\((V,F+F')\\)はDAG。\\((V,F^R+F')\\)もDAG。DAGでないなら最小のサイクルが取れて、サイクルの長さが３以上。\\(F\\)の辺が連続することはない。\\(F'\\)も同様。\\(ab \\in F,bc \\in F'\\) がサイクルの辺とする。\\(ca \\in F \\cup F'\\) ならばabcがサイクルをなし、同じタイプの辺が連続するので矛盾。従って、\\(ac \\in F \\cup F'\\)だがこの場合のサイクルを小さくできて矛盾。\\((V,F+F')\\)と\\((V,F^R+F')\\)がそれぞれpos,valに対応していて、転倒グラフが作れる。

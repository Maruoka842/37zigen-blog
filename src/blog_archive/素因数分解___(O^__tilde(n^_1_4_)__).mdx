# 素因数分解 \\(O^\\tilde(n^{1/4})\\)

> 📅 **投稿日**: 2021-04-12 11:44:25

正整数 \\(n\\) の素因数分解を deterministic に \\(O^\\tilde(n^&#123;1/4&#125;)\\) で求めるアルゴリズムを紹介します。
\\(M=\\lfloor \\sqrt&#123;n&#125; \\rfloor\\) と置きます。
\\(f(x) := x(x+1)(x+2) \\cdots (x+M)\\)

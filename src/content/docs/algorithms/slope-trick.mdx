# Slope Trick（スロープ・トリック）

**Slope Trick** は、**「凸な折れ線関数（Convex Piecewise Linear Function）」** の最小値や関数の移動（シフト）、絶対値関数の加算などの操作を、優先度付きキュー（Priority Queue / Heap）を用いて高速に行うデータ構造・テクニックです。

動的計画法（DP）の遷移において、DPテーブル全体が凸関数になるようなケース（EDPC の問題や各種最適化問題）で絶大な効果を発揮します。

---

## 💡 コアアイデアと関数表現

連続な凸関数 $f(x)$ であって、傾きの変化（折れ曲がり点）がすべて整数であるようなものを考えます。
このような関数は、**最小値 $f_{\min}$** と **折れ曲がり点の多重集合（左側 $L$ と右側 $R$）** を用いて次のように一義的に表現できます。

$$
f(x) = f_{\min} + \sum_{l \in L} \max(0, l - x) + \sum_{r \in R} \max(0, x - r)
$$

- **$f_{\min}$**: 関数の最小値
- **$L$**: 傾きが $1$ ずつ減少する折れ曲がり点（最大ヒープで管理）
- **$R$**: 傾きが $1$ ずつ増加する折れ曲がり点（最小ヒープで管理）

傾きが $0$ となる区間 $[L_{\max}, R_{\min}]$ において関数の値は最小値 $f_{\min}$ をとります。

---

## ⚡ 主な操作と計算量

両端の傾き変化点をヒープで保持することにより、以下の操作がすべて `O(log N)` または `O(1)` で実行可能です。

- **左側の傾き加算**: `f(x) += max(0, a - x)` ➔ `O(log N)`
- **右側の傾き加算**: `f(x) += max(0, x - a)` ➔ `O(log N)`
- **絶対値関数の加算**: `f(x) += |x - a|` ➔ `O(log N)`
- **左右への平行シフト**: `f(x - a)` などの区間移動 ➔ `O(1)`
- **累積 min 操作**: `min_{y <= x} f(y)` (右側の傾き消去) ➔ `O(1)`

---

## 🎯 競技プログラミングでの適用パターン

1. **連続値または離散値の最適位置決定問題**
   - 「いくつかの点との距離の和を最小化する」問題で、各ステップで $|x - a_i|$ を加えていく場合。

2. **DPテーブルの凸性を用いたインライン化 (DPの高速化)**
   - $dp[i][x] = \min_y (dp[i-1][y] + \text{cost}(y, x))$ のような遷移において、$dp[i]$ が $x$ について常に凸関数となる場合。
   - 遷移が「累積 min + シフト + 絶対値関数の足し込み」に分解できる場合、Slope Trick を適用することで全体計算量を $O(N \log N)$ に落とすことができます。

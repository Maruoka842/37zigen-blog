# 行列・線形代数の各種ユーティリティ

当ライブラリ（`library/`）には、競技プログラミングにおいて強力な武器となる線形代数・行列演算アルゴリズムが網羅的に実装されています。

代数構造を抽象化した一般の行列演算クラスから始まり、素体 $\mathbb{F}_p$、整数環 $\mathbb{Z}$、剰余環 $\mathbb{Z}/n\mathbb{Z}$、二元体 $\mathbb{F}_2$、そして Min-Max半環に至るまで、それぞれの代数的特徴を最大に活かした高速・高機能なユーティリティを提供しています。

---

## 1. 抽象代数上の一般行列演算: Matrix

`Matrix<T>` は、Java の型システムと Strategy パターンを用いて、任意の代数構造上で動作するように設計された抽象行列演算クラスです。

### 💡 設計とコアアイデア
実数（`Double`）や素体 $\mathbb{F}_p$（`Fp`）だけでなく、有理数（`Fraction`）、多項式環（`FPS`）などの上で共通のアルゴリズム（行列式、逆行列、階段化など）を動かすため、以下のインターフェースを戦略（Strategy）として外部から注入します：
- `SemiRingStrategy<T>`（半環）: 加算・乗算・零元・単位元
- `RingStrategy<T>`（環）: 半環に加え、減算（加法逆元）
- `FieldStrategy<T>`（体）: 環に加え、除算（乗法逆元）
- `EuclideanDomainStrategy<T>`（ユークリッド整域）: 剰余付き除算（GCD演算）

これにより、同じソースコードを流用したまま、対象の代数的性質に応じた最適・厳密なアルゴリズムが自動的に選択されます。

### ⚡ 主なメソッドと計算量

- **`identity(n)`**: サイズ $n$ の単位行列を生成します。
- **`add(a, b)` / `mul(a, b)`**: 行列の加算・乗算を計算します。積の計算量は $O(N^3)$ です。
- **`pow(a, exp)`**: 繰り返し二乗法により行列の累乗 $A^k$ を計算します。計算量は $O(N^3 \log k)$ です。
- **`det(data)`**: 行列式 $\det(A)$ を計算します。渡された代数構造の戦略に応じて自動的に最適なアルゴリズムへ分岐します：
  - **体（Field）**: Gaussian Elimination（掃き出し法）による $O(N^3)$。
  - **可換環（Commutative Ring）**: Division-free な **Mahajan-Vinay法** $O(N^3)$ や **Leibniz公式** $O(N! \cdot N)$。
  - **ユークリッド整域（Euclidean Domain）**: 逆元を使わずに剰余を用いて消去を行うユークリッド消去法 $O(N^3 \log (\text{value}))$。
  - **非可換環/整域**: **Bareissの無除算消去法**（Bareiss Algorithm）による $O(N^3)$。
- **`smithNormalForm(a)`**: 整数環などのユークリッド整域上で定義された行列 $A$ に対し、**スミス標準形**（Smith Normal Form）を求めます。
  $UAV = S$ を満たすユニモジュラ行列 $U, V$ と、対角要素が $s_i \mid s_{i+1}$ を満たす対角行列 $S$ を返します。
- **`reducedRowEchelonForm(a)`**: 行列 $A$ の既約行階段形（Reduced Row Echelon Form, RREF）を掃き出し法によって求めます。
- **`linearEquation(a, b)` / `nullSpace(a)` / `solve(a, b)`**:
  連立一次方程式 $Ax = b$ の特殊解 $x$、および同次方程式 $Ax = 0$ の解空間（核; Null Space）の基底を求めます（解が存在しない場合は `null` を返します）。
- **`inv(data)`**: 逆行列 $A^{-1}$ を計算します。
- **`invUpdateRank1` / `invUpdatePoint` / `invUpdateRow` / `invUpdateCol`**:
  **Sherman-Morrison の公式**を利用し、行列 $A$ に対する「階数 1 の加算（外積 $uv^T$ の加算）」や「1成分の書き換え」「1行/1列の書き換え」が行われた際の、新しい逆行列 $(A + uv^T)^{-1}$ を $O(N^2)$ で動的に更新します。

## 2. 素体 Fp 上の高速・高度な線形代数: MatrixUtilsFp

`MatrixUtilsFp` は、法 $p$（素数）の剰余環（素体）$\mathbb{F}_p$ 上に特化したユーティリティです。競プロで頻出する $\text{mod } 998244353$ や $\text{mod } 1000000007$ などの演算を高速に処理するだけでなく、非常に高度な線形代数アルゴリズムを内蔵しています。

### ⚡ 主なメソッドと計算量

#### 1. グラフ・数え上げのための高度な行列式・固有演算
- **`pfaffian(a, mod)`**:
  偶数サイズ $N$ の歪対称行列（Skew-symmetric matrix: $A^T = -A$ 且つ対角成分が 0）に対し、その **Pfaffian（プファフィアン）** を $O(N^3)$ で計算します。
  数学的に $\det(A) = (\text{Pf}(A))^2$ が成り立ち、無向一般グラフの完全マッチング数をカウントする FKT アルゴリズムなどで決定的な役割を果たします。
- **`hessenbergReductionOnFp(A, mod)`**:
  相似変換 $B = P^{-1}AP$ により、行列 $A$ をヘッセンバーグ形式（下対角の 2 本目以下がすべて 0 である行列）に $O(N^3)$ で変換します。
- **`characteristicPolynomialOnFp(A, mod)`**:
  行列 $A$ の特性多項式 $P(x) = \det(xI - A)$ を $O(N^3)$ で計算します。
  ヘッセンバーグ形式に変換後、動的計画法に類似した漸化式を用いて $O(N^2)$ で多項式を復元します。
- **`determinantAxPlusBOnFp(A, B, mod)`**:
  1変数多項式行列 $M(x) = Ax + B$ の行列式 $\det(Ax + B)$（$N$ 次多項式）の全係数を $O(N^3)$ で求めます。
- **`hafnian(mat, mod)`**:
  無向グラフの隣接行列 `mat` に対し、完全マッチングの重み和を表す **Hafnian（ハフニアン）** を Björklund のアルゴリズムに基づき $O(N^2 2^{N/2})$ で計算します。

#### 2. Wiedemann アルゴリズムによるスパース行列演算
行列 $A$ の非零要素の数 $Z$ が十分に少ない（スパースな）場合、通常の $O(N^3)$ の掃き出し法は非効率です。
- **`minimalPolynomialOnFp(n, entries)`**:
  Wiedemann のランダム射影法を用いて、スパース行列 $A$ に対する最小多項式を $O(N \cdot Z + N \log^2 N)$ で計算します。
  ランダムな行ベクトル $x$ と列ベクトル $y$ に対し、スカラー列 $s_i = x A^i y \pmod p$ を生成し、これを Berlekamp-Massey アルゴリズムで解くことで、高確率で行列の最小多項式（および特性多項式）と一致する多項式を得ます。
- **`sparseDeterminantOnFp(n, entries)`**:
  Wiedemann 法を応用し、スパース行列の行列式を $O(N \cdot Z + N \log^2 N)$ で求めます。

#### 3. 1変数多項式行列の随伴・有理関数・動的更新
- **`bilinearFormAdjugateAxPlusBOnFp(A, B, u, v, mod)`**:
  1変数多項式行列 $M(x) = Ax + B$ に対し、双線形形式 $u^T \text{adj}(Ax + B) v$ の多項式係数を $O(N^3)$ で計算します（ここで $\text{adj}(M)$ は余因子行列）。行列式補題 $\det(M + vu^T) = \det(M) + u^T \text{adj}(M) v$ を応用しています。
- **`leftVectorAdjugateAxPlusBOnFp(A, B, u, mod)`**:
  多項式ベクトル $u^T \text{adj}(Ax + B)$ の各成分の係数を $O(N^3)$ で計算します。
- **`inverseIminusAxOnFp(A, u, mod)` / `inverseAxPlusBOnFp(A, B, u, mod)`**:
  1変数有理関数ベクトル $v(x) = (Ax + B)^{-1} u$ を、共通分母多項式 $Q(x) = \det(Ax + B)$ と、分子多項式ベクトル $P(x) = \text{adj}(Ax + B) u$ に分解し、それぞれの多項式係数を $O(N^3)$ で求めます。

## 3. 整数環 Z 上の厳密線形代数: MatrixUtilsZ

実数（浮動小数点数）による線形代数には「丸め誤差」があり、$\mathbb{F}_p$ 上の線形代数には「法 $p$ で潰れてしまう」性質があります。
整数行列 $A$ について、実数に拡張せず、かつ剰余も取らずに、**整数環 $\mathbb{Z}$ の中だけで厳密に計算を完結させたい**（例えば格子の基底やディオファントス方程式の解空間を求めたい）場合に `MatrixUtilsZ` を使用します。

### 💡 数学的背景とコアアイデア
整数環 $\mathbb{Z}$ は体（Field）ではないため、ある行をピボット要素で「割る」という操作ができません（ピボットの倍数以外の要素を直接 0 に消去できません）。
代わりに、2つの行の間で**ユークリッドの互除法（Euclidean algorithm）**を回すことで、要素を割り切るように行/列基本変形を進めます。
また、基本変形に用いる行列は、行列式が $\pm 1$ である整数行列（ユニモジュラ行列）に限定されます。これによって、変形前後で「張る格子（Lattice）」が完全に保存されます。

### ⚡ 主なメソッドと計算量

- **`smithNormalForm(a)`**:
  整数行列 $A$ の**スミス標準形** UAV = S を計算します。
  計算量は $O(NM \min(N, M) \log(\max |A_{ij}|))$ です。
- **`rowHermiteNormalForm(a)` / `columnHermiteNormalForm(a)`**:
  整数行列 $A$ に対し、行/列基本変形のみを施して、**エルミート標準形**（Hermite Normal Form, HNF）へ変換します。
  HNF は、整数行列において掃き出し法の階段行列（RREF）に相当する唯一の正規形（各ピボットは正で、ピボットより上の要素はピボット未満に正規化されている）であり、整数ベクトル空間（格子）の等価性判定や、ディオファントス方程式の解法において基礎となります。
- **`linearEquationOnZ(a, b)`**:
  整数上の連立一次方程式 $Ax = b$ を厳密に解き、整数特殊解 $x$ と、整数解空間の核（零空間）の整数基底を返します。解が存在しない場合は `null` を返します。

## 4. 合成数 n を法とする剰余環 Z/nZ 上の演算: MatrixUtilsZn

法 `mod` が素数ではなく**合成数**（例: $10^9$ や $2^k$）の場合、剰余環 $\mathbb{Z}/n\mathbb{Z}$ には逆元を持たない非ゼロ元（零因子など）が存在するため、通常の体（Field）を前提とした掃き出し法が使えません。

### ⚡ 主なメソッド
- **`determinantByEuclid(a, mod)`**:
  逆元を用いずに、隣接する行の間でユークリッドの互除法を実行しながら下三角成分を消去していくことで、任意の合成数 `mod` の上で正方行列の行列式を厳密に計算します。
  計算量は $O(N^3 \log(\text{mod}))$ です。
- **`add` / `mul` / `pow`**:
  合成数を法とする基本的な行列加算、乗算、累乗をサポートします。

## 5. 二元体 F2 上のビットパラレル高速演算: MatrixUtilsF2

二元体 $\mathbb{F}_2$ （$\text{mod } 2$）上の演算は、コンピューティングにおける**ビット演算**（XOR と AND）と完全に一致します。
`MatrixUtilsF2` は、1つの `long`（64ビット）に 64 次元分の要素を詰め込む（パックする）ことで、あらゆる行列演算を定数倍 $1/64$ に高速化（ビットパラレル化）します。

### ⚡ 主なメソッドと計算量

- **`bitBasisMSB(a)`**:
  与えられたベクトル集合から、MSB（最上位ビット）から順に掃き出した XOR 線形基底を抽出します。
- **`bitVectorSpaceIntersectionBasis(u, v)`**:
  $\mathbb{F}_2$ 上の $2$ つの部分空間 $\langle U \rangle$ と $\langle V \rangle$ の**共通部分（交空間; Intersection Space）**の基底を高速に計算します。
  関係式 $Ux = Vy \iff Ux \oplus Vy = 0$ に基づき、連合行列 $[U \mid V]$ の核（零空間）をビット掃き出し法で求めることで、交空間の基底を抽出します。計算量は $O((|U| + |V|) \times 64)$ です。
- **`addToBitBasis(val, basis)`**:
  線形独立性を判定しながら、新しい要素 `val` を既存の XOR 線形基底へ挿入し、基底を動的に拡張します（破壊的更新）。
- **`packToBitMatrix(a)` / `unpackBitMatrix(a, n, m)` / `transposeBitMatrix(a, n, m)`**:
  直感的な `boolean[][]` 表現と、ビットパラレル用の高速な `long[][]` 表現を相互に変換・転置します。
- **`determinantMod2(a, n)` / `rankMod2(a, n, m)` / `invMod2(a, n)` / `linearEquationMod2(a, b, n, m)`**:
  ビット並列処理を極限まで最適化した、$\mathbb{F}_2$ 上の行列式・ランク・逆行列・連立一次方程式ソルバです。
  すべての掃き出し操作が `long` のビット演算で行われるため、サイズ $N = 1000$ 程度の行列であっても一瞬で計算が完了します（消去計算量は $O(N^3 / 64)$）。
- **`geometricSum(A, N)`**:
  $\mathbb{F}_2$ 上の等比級数の和 $\sum_{i=0}^{N-1} A^i$ をダブリングにより高速に計算します。

## 6. Min-Max 半環上の最短路・ボトルネック演算: MinMax

`MinMax` クラスは、通常の「加算・乗算」の代わりに「$\min$・$\max$」を基本演算とする **Min-Max 半環**（Min-Max Semiring）上の行列演算を扱います。

### 💡 代数的背景：Min-Max 半環上の行列積
実数に無限大を加えた集合上において、和（加算）演算を $\oplus = \min$、積（乗算）演算を $\otimes = \max$ と定義すると、これは代数的な**半環（Semiring）**を構成します。
この半環における、２つの正方行列 $A, B$ の積 $C = A \otimes B$ は、定義より次のように書き表されます：
$$
C_{ij} = \bigoplus_{k=1}^n (A_{ik} \otimes B_{kj}) = \min_{1 \le k \le n} \left( \max(A_{ik}, B_{kj}) \right)
$$
これは、グラフにおいて「頂点 $i$ から $j$ へ遷移する際、経由地 $k$ を通るルートの（最大辺重み）を最小化する」という**ボトルネック最短路（Minimum-Max Path）**の遷移そのものです。

### ⚡ 主なメソッドと計算量

- **`asps(cost)`** (All-Pairs Shortest Path):
  Min-Max 半環における全点対最短路（APSP）を計算します。
  - **Floyd-Warshall（頂点数 $N < 50$ の場合）**:
    $O(N^3)$ の単純な動的計画法（`warshalFloyd`）を実行します。
  - **ビットパラレル・スイープ（頂点数 $N \ge 50$ の場合）**:
    辺をコストの昇順にソートし、到達可能性（Reachability）を `long[]` によるビットベクトルで表現して伝播させます。これによって、全体の計算量を **$O(N^3 / 64 + M \log M)$**（ここで $M$ は辺数）に落とし、大規模グラフでのボトルネック全点対最短路を劇的に高速化します。

## 🎯 競技プログラミングでの典型的な適用場面

### 1. 期待値・確率 DP のリピート遷移
「ある状態から別の状態へ遷移する確率や期待値」の遷移関係は連立一次方程式 $Ax = b$ となり、これを $\mathbb{F}_p$ 上や実数上で解くことで、自己参照的な期待値・確率が求まります（`solveLinearEquation`）。

### 2. スパニングツリーの数え上げ (行列木定理)
グラフのラプラシアン行列（次数行列 - 隣接行列）の余因子（または一部の行と列を削除した行列の行列式）を計算することで、グラフの全域木の個数をカウントできます。
有向グラフや、重み付きの全域木にも拡張可能です。

### 3. XOR 空間の独立性と最大化 (XOR線形基底)
$\mathbb{F}_2$ 上の線形代数は、XORに関連する競プロ問題のほぼすべてに適用できます。
「選んだ要素の総 XOR を最大化する」問題は、`bitBasisMSB` によって基底を取り出し、大きい方のビットから貪欲に XOR していくことで解くことができます。また、部分空間の共通部分を求める `bitVectorSpaceIntersectionBasis` は、「2つの条件を同時に満たす XOR の基底」を得るための強力な道具です。

### 4. グラフのボトルネックパス
「グラフ上で移動するとき、通過する辺の最大重みの最小値（または最小重みの最大値）」をすべてのペアについて求める問題において、`MinMax.asps` は非常に高速な解法を提供します。

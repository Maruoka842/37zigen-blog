# 37zigen Algorithm Note

このサイトは、競技プログラミング（AtCoder / Codeforces 等）で用いられる高精度なアルゴリズムや数学的背景を解説する技術ノートです。

実装コードそのものではなく、**背景にある数学的構造・直感的イメージ・計算量・典型的な適用パターン** を中心にまとめています。

---

## 📚 ディレクトリ・カテゴリ構成

当ライブラリ（`library/`）の構造に対応したカテゴリ分類になっています。

| カテゴリ | 説明・主なトピック |
|---|---|
| **データ構造** (`segtree`, `unionfind`, `collections`) | セグメント木、Dynamic Segment Tree、LiChaoTree、Persistent UnionFind |
| **グラフ・木** (`graph`, `tree`) | 最大流/最小カット、HL分解、Centroid Decomposition、Top Tree |
| **代数・線形代数** (`algebra`, `linalg`, `monoid`) | 抽象代数構造、基底追跡、行列累乗 |
| **多項式・FFT** (`polynomial`) | 形式的冪級数 (FPS)、NTT、高速畳み込み・除算 |
| **列・文字列** (`seq`, `mo`) | Suffix Array / LCP、Aho-Corasick、Mo's Algorithm |
| **順序集合** (`poset`) | 束論、メビウス反転 |
| **ゲーム理論・幾何** (`game`, `geometry`) | Nim / Nimber、凸包、直線アレンジメント |
| **アルゴリズムテクニック** (`algorithms`) | Slope Trick、挿入DP、桁DP、二分探索、数論 |

Slope Trick（凸折れ線関数の高速管理）

Slope Trick（スロープ・トリック）

Section titled “Slope Trick（スロープ・トリック）”

Slope Trick は、「凸な折れ線関数（Convex Piecewise Linear Function）」 の最小値や関数の移動（シフト）、絶対値関数の加算などの操作を、優先度付きキュー（Priority Queue / Heap）を用いて高速に行うデータ構造・テクニックです。

動的計画法（DP）の遷移において、DPテーブル全体が凸関数になるようなケース（EDPC の問題や各種最適化問題）で絶大な効果を発揮します。

💡 コアアイデアと関数表現

Section titled “💡 コアアイデアと関数表現”

連続な凸関数 f(x)f(x)f(x) であって、傾きの変化（折れ曲がり点）がすべて整数であるようなものを考えます。 このような関数は、最小値 fmin⁡f_{\min}fmin​ と 折れ曲がり点の多重集合（左側 LLL と右側 RRR） を用いて次のように一義的に表現できます。

f(x)=fmin⁡+∑l∈Lmax⁡(0,l−x)+∑r∈Rmax⁡(0,x−r)f(x) = f_{\min} + \sum_{l \in L} \max(0, l - x) + \sum_{r \in R} \max(0, x - r)f(x)=fmin​+l∈L∑​max(0,l−x)+r∈R∑​max(0,x−r)
  • fmin⁡f_{\min}fmin​: 関数の最小値
  • LLL: 傾きが 111 ずつ減少する折れ曲がり点（最大ヒープで管理）
  • RRR: 傾きが 111 ずつ増加する折れ曲がり点（最小ヒープで管理）

傾きが 000 となる区間 [Lmax⁡,Rmin⁡][L_{\max}, R_{\min}][Lmax​,Rmin​] において関数の値は最小値 fmin⁡f_{\min}fmin​ をとります。

⚡ 主な操作と計算量

Section titled “⚡ 主な操作と計算量”

両端の傾き変化点をヒープで保持することにより、以下の操作がすべて O(log N) または O(1) で実行可能です。

  • 左側の傾き加算: f(x) += max(0, a - x) ➔ O(log N)
  • 右側の傾き加算: f(x) += max(0, x - a) ➔ O(log N)
  • 絶対値関数の加算: f(x) += |x - a| ➔ O(log N)
  • 左右への平行シフト: f(x - a) などの区間移動 ➔ O(1)
  • 累積 min 操作: min_{y <= x} f(y) (右側の傾き消去) ➔ O(1)

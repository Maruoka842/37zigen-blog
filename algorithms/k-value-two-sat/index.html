多値 2-SAT (K-Value 2-SAT)

多値 2-SAT（K-Value 2-SAT） は、各変数が二値（0 または 1）ではなく、000 以上 KKK 未満の整数値をとるような充足可能性問題を、通常の 2-SAT に帰着して解くテクニックです。

各変数のとりうる選択肢が KKK 個存在し、変数間の関係性が「2変数間の制約（または単一変数への制約）」のみで記述される場合、適切な Boolean 変数の割り当てと含意関係の構築を行うことで、多項式時間で解くことができます。

1. 変数の Boolean 表現

Section titled “1. 変数の Boolean 表現”

各多値変数 xix_ixi​ （0≤xi<K0 \le x_i < K0≤xi​<K）を、通常の 2-SAT で扱えるようにするために、以下の KKK 個の Boolean 変数 P(xi≥t)P(x_i \ge t)P(xi​≥t) （0≤t<K0 \le t < K0≤t<K）を導入します。

P(xi≥t)  ⟺  xi≥tP(x_i \ge t) \iff x_i \ge tP(xi​≥t)⟺xi​≥t

これらの Boolean 変数に対して、多値変数の定義および整合性を保つための以下の制約を課します。

  • 境界条件: xi≥0x_i \ge 0xi​≥0 は常に真であるため、以下を固定します。 P(xi≥0)=trueP(x_i \ge 0) = \text{true}P(xi​≥0)=true
  • 単調性制約（Monotonicity）: xi≥t+1x_i \ge t+1xi​≥t+1 が真ならば、xi≥tx_i \ge txi​≥t も必ず真でなければなりません。この関係を含意（Implication）として 2-SAT に追加します。 P(xi≥t+1)  ⟹  P(xi≥t)(0≤t<K−1)P(x_i \ge t+1) \implies P(x_i \ge t) \quad (0 \le t < K - 1)P(xi​≥t+1)⟹P(xi​≥t)(0≤t<K−1)

これにより、Boolean 割り当てが確定した際、真となる ttt の最大値を vvv とすれば、多値変数の値 xi=vx_i = vxi​=v を一意に復元できます。

2. 各種制約の 2-SAT へのマッピング

Section titled “2. 各種制約の 2-SAT へのマッピング”

2つの多値変数 x,yx, yx,y の関係式は、Boolean 変数 P(x≥a)P(x \ge a)P(x≥a) や P(y≥b)P(y \ge b)P(y≥b) に対する論理和（∨\lor∨）や含意（  ⟹  \implies⟹）の形にマッピングされます。

2.1 条件付きインプリケーション

Section titled “2.1 条件付きインプリケーション”

閾値条件に基づく含意関係は、以下のように直接マッピングできます。

  • [x≥a]  ⟹  [y≥b][x \ge a] \implies [y \ge b][x≥a]⟹[y≥b] P(x≥a)  ⟹  P(y≥b)P(x \ge a) \implies P(y \ge b)P(x≥a)⟹P(y≥b)
  • [x≥a]  ⟹  [y<b][x \ge a] \implies [y < b][x≥a]⟹[y<b] P(y<b)P(y < b)P(y<b) は ¬P(y≥b)\neg P(y \ge b)¬P(y≥b) と等価であるため、以下のように表されます。 P(x≥a)  ⟹  ¬P(y≥b)(  ⟺  ¬P(x≥a)∨¬P(y≥b))P(x \ge a) \implies \neg P(y \ge b) \quad (\iff \neg P(x \ge a) \lor \neg P(y \ge b))P(x≥a)⟹¬P(y≥b)(⟺¬P(x≥a)∨¬P(y≥b))
  • [x<a]  ⟹  [y≥b][x < a] \implies [y \ge b][x<a]⟹[y≥b] P(x<a)  ⟹  P(y≥b)(  ⟺  P(x≥a)∨P(y≥b))P(x < a) \implies P(y \ge b) \quad (\iff P(x \ge a) \lor P(y \ge b))P(x<a)⟹P(y≥b)(⟺P(x≥a)∨P(y≥b))
  • [x<a]  ⟹  [y<b][x < a] \implies [y < b][x<a]⟹[y<b] 対偶をとることで [y≥b]  ⟹  [x≥a][y \ge b] \implies [x \ge a][y≥b]⟹[x≥a] と等価になり、以下のように表されます。 P(y≥b)  ⟹  P(x≥a)P(y \ge b) \implies P(x \ge a)P(y≥b)⟹P(x≥a)

2.2 値の固定

Section titled “2.2 値の固定”

変数 xxx の値を vvv （0≤v<K0 \le v < K0≤v<K）に固定する場合、以下を同時に満たすように固定します。 P(x≥v)=trueP(x \ge v) = \text{true}P(x≥v)=true P(x≥v+1)=false(if v+1<K)P(x \ge v + 1) = \text{false} \quad (\text{if } v + 1 < K)P(x≥v+1)=false(if v+1<K)

2.3 特定区間の禁止

Section titled “2.3 特定区間の禁止”

変数 xxx が特定の閉区間 [l,r][l, r][l,r] に属することを禁止します。これは x<lx < lx<l または x≥r+1x \ge r + 1x≥r+1 が成立することと同値です。 ¬P(x≥l)∨P(x≥r+1)(  ⟺  P(x≥l)  ⟹  P(x≥r+1))\neg P(x \ge l) \lor P(x \ge r + 1) \quad (\iff P(x \ge l) \implies P(x \ge r + 1))¬P(x≥l)∨P(x≥r+1)(⟺P(x≥l)⟹P(x≥r+1))

2.4 差の制約

Section titled “2.4 差の制約”

2変数の差に関する制約 x−y≤dx - y \le dx−y≤d は、任意の閾値 aaa に対して x≥a  ⟹  y≥a−dx \ge a \implies y \ge a - dx≥a⟹y≥a−d が成り立つことと同値です。 したがって、すべての aaa について以下の含意を追加します。 P(x≥a)  ⟹  P(y≥a−d)P(x \ge a) \implies P(y \ge a - d)P(x≥a)⟹P(y≥a−d)

2.5 和の制約

Section titled “2.5 和の制約”
  • 和の上限: x+y≤cx + y \le cx+y≤c expand: x≥a  ⟹  y<c−a+1x \ge a \implies y < c - a + 1x≥a⟹y<c−a+1 と同値。よって、以下を追加： ¬P(x≥a)∨¬P(y≥c−a+1)\neg P(x \ge a) \lor \neg P(y \ge c - a + 1)¬P(x≥a)∨¬P(y≥c−a+1)
  • 和の下限: x+y≥cx + y \ge cx+y≥c expand: x<a  ⟹  y≥c−a+1x < a \implies y \ge c - a + 1x<a⟹y≥c−a+1 と同値。よって、以下を追加： P(x≥a)∨P(y≥c−a+1)P(x \ge a) \lor P(y \ge c - a + 1)P(x≥a)∨P(y≥c−a+1)

2.6 等号制約

Section titled “2.6 等号制約”

2つの変数 x,yx, yx,y が等しい（x=yx = yx=y）という制約は、すべての閾値 t≥1t \ge 1t≥1 において x≥t  ⟺  y≥tx \ge t \iff y \ge tx≥t⟺y≥t であることと同値です。 P(x≥t)  ⟹  P(y≥t)andP(y≥t)  ⟹  P(x≥t)(1≤t<K)P(x \ge t) \implies P(y \ge t) \quad \text{and} \quad P(y \ge t) \implies P(x \ge t) \quad (1 \le t < K)P(x≥t)⟹P(y≥t)andP(y≥t)⟹P(x≥t)(1≤t<K)

⚡ 計算量と制約

Section titled “⚡ 計算量と制約”

変数の総数を NNN、とりうる状態数を KKK、追加された2変数関係の制約数を MMM とします。

  • 時間計算量:
    • 変数・単調性制約の構築: O(NK)O(N K)O(NK) 各変数に対して KKK 個のノードを作成し、隣接する閾値間を辺で結びます。
    • 制約（辺）の追加:
      • 条件付き含意・区間禁止・値固定: O(1)O(1)O(1)
      • 差・和・等号制約: O(K)O(K)O(K)
    • 2-SAT ソルバによる求解: O(NK+Medge)O(N K + M_{\text{edge}})O(NK+Medge​) 強連結成分分解（SCC）を用いた通常の 2-SAT 求解に帰着されるため、頂点数と辺数に対して線形時間で動作します。
  • 空間計算量: O(NK+Medge)O(N K + M_{\text{edge}})O(NK+Medge​) 2-SAT を構築するための含意グラフを保持するメモリが必要です。

🎯 競技プログラミングでの典型的な適用場面

Section titled “🎯 競技プログラミングでの典型的な適用場面”

  1. 整数値をとる要素の二者択一関係

    • 「要素 iii を位置 xix_ixi​ に配置したい。ただし、要素 iii と要素 jjj の距離は一定以上離さなければならない、または特定の組み合わせは禁止される」といったグリッド・数軸上の配置問題。

  2. 条件分岐を伴うグリッド・ネットワーク最適化

    • 「もし xix_ixi​ を aaa 以上にするならば、xjx_jxj​ を bbb 以上にする必要がある」というような、複雑に依存したしきい値の決定。

  3. 差や和に上限・下限がある系の判定・構築

    • 差分制約（xi−xj≤dx_i - x_j \le dxi​−xj​≤d）や和の制約がある問題において、変数がとる値の範囲 KKK が十分に小さい場合（例: N×K≤106N \times K \le 10^6N×K≤106 程度）、2-SAT による確実な解の判定と逆算・復元が威力を発揮します。

考察のステップ

Section titled “考察のステップ”
  1. 各変数の定義域の確認: 各変数が連続値ではなく、離散的な KKK 通りの状態をとるか確認します。
  2. 制約の分解: 問題に現れる制約が、すべて「2つの変数以下の関係式」に分解できるかを検証します（3変数以上が同時に関与する制約は 2-SAT で扱えません）。
  3. 閾値に基づく定式化: 各制約を [xi≥a]  ⟹  [xj≥b][x_i \ge a] \implies [x_j \ge b][xi​≥a]⟹[xj​≥b] のような「しきい値形式」に翻訳し、多値 2-SAT の各種インターフェースに落とし込みます。

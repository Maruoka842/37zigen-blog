行列・線形代数ユーティリティ (linalg / MinMax)

行列・線形代数の各種ユーティリティ

Section titled “行列・線形代数の各種ユーティリティ”

当ライブラリ（library/）には、競技プログラミングにおいて強力な武器となる線形代数・行列演算アルゴリズムが網羅的に実装されています。

代数構造を抽象化した一般の行列演算クラスから始まり、素体 Fp\mathbb{F}_pFp​、整数環 Z\mathbb{Z}Z、剰余環 Z/nZ\mathbb{Z}/n\mathbb{Z}Z/nZ、二元体 F2\mathbb{F}_2F2​、そして Min-Max半環に至るまで、それぞれの代数的特徴を最大に活かした高速・高機能なユーティリティを提供しています。

1. 抽象代数上の一般行列演算: Matrix

Section titled “1. 抽象代数上の一般行列演算: Matrix”

Matrix<T> は、Java の型システムと Strategy パターンを用いて、任意の代数構造上で動作するように設計された抽象行列演算クラスです。

💡 設計とコアアイデア

Section titled “💡 設計とコアアイデア”

実数（Double）や素体 Fp\mathbb{F}_pFp​（Fp）だけでなく、有理数（Fraction）、多項式環（FPS）などの上で共通のアルゴリズム（行列式、逆行列、階段化など）を動かすため、以下のインターフェースを戦略（Strategy）として外部から注入します：

  • SemiRingStrategy<T>（半環）: 加算・乗算・零元・単位元
  • RingStrategy<T>（環）: 半環に加え、減算（加法逆元）
  • FieldStrategy<T>（体）: 環に加え、除算（乗法逆元）
  • EuclideanDomainStrategy<T>（ユークリッド整域）: 剰余付き除算（GCD演算）

これにより、同じソースコードを流用したまま、対象の代数的性質に応じた最適・厳密なアルゴリズムが自動的に選択されます。

⚡ 主なメソッドと計算量

Section titled “⚡ 主なメソッドと計算量”
  • identity(n): サイズ nnn の単位行列を生成します。
  • add(a, b) / mul(a, b): 行列の加算・乗算を計算します。積の計算量は O(N3)O(N^3)O(N3) です。
  • pow(a, exp): 繰り返し二乗法により行列の累乗 AkA^kAk を計算します。計算量は O(N3log⁡k)O(N^3 \log k)O(N3logk) です。
  • det(data): 行列式 det⁡(A)\det(A)det(A) を計算します。渡された代数構造の戦略に応じて自動的に最適なアルゴリズムへ分岐します：
    • 体（Field）: Gaussian Elimination（掃き出し法）による O(N3)O(N^3)O(N3)。
    • 可換環（Commutative Ring）: Division-free な Mahajan-Vinay法 O(N3)O(N^3)O(N3) や Leibniz公式 O(N!⋅N)O(N! \cdot N)O(N!⋅N)。
    • ユークリッド整域（Euclidean Domain）: 逆元を使わずに剰余を用いて消去を行うユークリッド消去法 O(N3log⁡(value))O(N^3 \log (\text{value}))O(N3log(value))。
    • 非可換環/整域: Bareissの無除算消去法（Bareiss Algorithm）による O(N3)O(N^3)O(N3)。
  • smithNormalForm(a): 整数環などのユークリッド整域上で定義された行列 AAA に対し、スミス標準形（Smith Normal Form）を求めます。 UAV=SUAV = SUAV=S を満たすユニモジュラ行列 U,VU, VU,V と、対角要素が si∣si+1s_i \mid s_{i+1}si​∣si+1​ を満たす対角行列 SSS を返します。
  • reducedRowEchelonForm(a): 行列 AAA の既約行階段形（Reduced Row Echelon Form, RREF）を掃き出し法によって求めます。
  • linearEquation(a, b) / nullSpace(a) / solve(a, b): 連立一次方程式 Ax=bAx = bAx=b の特殊解 xxx、および同次方程式 Ax=0Ax = 0Ax=0 の解空間（核; Null Space）の基底を求めます（解が存在しない場合は null を返します）。
  • inv(data): 逆行列 A−1A^{-1}A−1 を計算します。
  • invUpdateRank1 / invUpdatePoint / invUpdateRow / invUpdateCol: Sherman-Morrison の公式を利用し、行列 AAA に対する「階数 1 の加算（外積 uvTuv^TuvT の加算）」や「1成分の書き換え」「1行/1列の書き換え」が行われた際の、新しい逆行列 (A+uvT)−1(A + uv^T)^{-1}(A+uvT)−1 を O(N2)O(N^2)O(N2) で動的に更新します。

2. 素体 Fp 上の高速・高度な線形代数: MatrixUtilsFp

Section titled “2. 素体 Fp 上の高速・高度な線形代数: MatrixUtilsFp”

MatrixUtilsFp は、法 ppp（素数）の剰余環（素体）Fp\mathbb{F}_pFp​ 上に特化したユーティリティです。競プロで頻出する mod 998244353\text{mod } 998244353mod 998244353 や mod 1000000007\text{mod } 1000000007mod 1000000007 などの演算を高速に処理するだけでなく、非常に高度な線形代数アルゴリズムを内蔵しています。

⚡ 主なメソッドと計算量

Section titled “⚡ 主なメソッドと計算量”

1. グラフ・数え上げのための高度な行列式・固有演算

Section titled “1. グラフ・数え上げのための高度な行列式・固有演算”
  • pfaffian(a, mod): 偶数サイズ NNN の歪対称行列（Skew-symmetric matrix: AT=−AA^T = -AAT=−A 且つ対角成分が 0）に対し、その Pfaffian（プファフィアン） を O(N3)O(N^3)O(N3) で計算します。 数学的に det⁡(A)=(Pf(A))2\det(A) = (\text{Pf}(A))^2det(A)=(Pf(A))2 が成り立ち、無向一般グラフの完全マッチング数をカウントする FKT アルゴリズムなどで決定的な役割を果たします。
  • hessenbergReductionOnFp(A, mod): 相似変換 B=P−1APB = P^{-1}APB=P−1AP により、行列 AAA をヘッセンバーグ形式（下対角の 2 本目以下がすべて 0 である行列）に O(N3)O(N^3)O(N3) で変換します。
  • characteristicPolynomialOnFp(A, mod): 行列 AAA の特性多項式 P(x)=det⁡(xI−A)P(x) = \det(xI - A)P(x)=det(xI−A) を O(N3)O(N^3)O(N3) で計算します。 ヘッセンバーグ形式に変換後、動的計画法に類似した漸化式を用いて O(N2)O(N^2)O(N2) で多項式を復元します。
  • determinantAxPlusBOnFp(A, B, mod): 1変数多項式行列 M(x)=Ax+BM(x) = Ax + BM(x)=Ax+B の行列式 det⁡(Ax+B)\det(Ax + B)det(Ax+B)（NNN 次多項式）の全係数を O(N3)O(N^3)O(N3) で求めます。
  • hafnian(mat, mod): 無向グラフの隣接行列 mat に対し、完全マッチングの重み和を表す Hafnian（ハフニアン） を Björklund のアルゴリズムに基づき O(N22N/2)O(N^2 2^{N/2})O(N22N/2) で計算します。

2. Wiedemann アルゴリズムによるスパース行列演算

Section titled “2. Wiedemann アルゴリズムによるスパース行列演算”

行列 AAA の非零要素の数 ZZZ が十分に少ない（スパースな）場合、通常の O(N3)O(N^3)O(N3) の掃き出し法は非効率です。

  • minimalPolynomialOnFp(n, entries): Wiedemann のランダム射影法を用いて、スパース行列 AAA に対する最小多項式を O(N⋅Z+Nlog⁡2N)O(N \cdot Z + N \log^2 N)O(N⋅Z+Nlog2N) で計算します。 ランダムな行ベクトル xxx と列ベクトル yyy に対し、スカラー列 si=xAiy(modp)s_i = x A^i y \pmod psi​=xAiy(modp) を生成し、これを Berlekamp-Massey アルゴリズムで解くことで、高確率で行列の最小多項式（および特性多項式）と一致する多項式を得ます。
  • sparseDeterminantOnFp(n, entries): Wiedemann 法を応用し、スパース行列の行列式を O(N⋅Z+Nlog⁡2N)O(N \cdot Z + N \log^2 N)O(N⋅Z+Nlog2N) で求めます。

3. 1変数多項式行列の随伴・有理関数・動的更新

Section titled “3. 1変数多項式行列の随伴・有理関数・動的更新”
  • bilinearFormAdjugateAxPlusBOnFp(A, B, u, v, mod): 1変数多項式行列 M(x)=Ax+BM(x) = Ax + BM(x)=Ax+B に対し、双線形形式 uTadj(Ax+B)vu^T \text{adj}(Ax + B) vuTadj(Ax+B)v の多項式係数を O(N3)O(N^3)O(N3) で計算します（ここで adj(M)\text{adj}(M)adj(M) は余因子行列）。行列式補題 det⁡(M+vuT)=det⁡(M)+uTadj(M)v\det(M + vu^T) = \det(M) + u^T \text{adj}(M) vdet(M+vuT)=det(M)+uTadj(M)v を応用しています。
  • leftVectorAdjugateAxPlusBOnFp(A, B, u, mod): 多項式ベクトル uTadj(Ax+B)u^T \text{adj}(Ax + B)uTadj(Ax+B) の各成分の係数を O(N3)O(N^3)O(N3) で計算します。
  • inverseIminusAxOnFp(A, u, mod) / inverseAxPlusBOnFp(A, B, u, mod): 1変数有理関数ベクトル v(x)=(Ax+B)−1uv(x) = (Ax + B)^{-1} uv(x)=(Ax+B)−1u を、共通分母多項式 Q(x)=det⁡(Ax+B)Q(x) = \det(Ax + B)Q(x)=det(Ax+B) と、分子多項式ベクトル P(x)=adj(Ax+B)uP(x) = \text{adj}(Ax + B) uP(x)=adj(Ax+B)u に分解し、それぞれの多項式係数を O(N3)O(N^3)O(N3) で求めます。

3. 整数環 Z 上の厳密線形代数: MatrixUtilsZ

Section titled “3. 整数環 Z 上の厳密線形代数: MatrixUtilsZ”

実数（浮動小数点数）による線形代数には「丸め誤差」があり、Fp\mathbb{F}_pFp​ 上の線形代数には「法 ppp で潰れてしまう」性質があります。 整数行列 AAA について、実数に拡張せず、かつ剰余も取らずに、整数環 Z\mathbb{Z}Z の中だけで厳密に計算を完結させたい（例えば格子の基底やディオファントス方程式の解空間を求めたい）場合に MatrixUtilsZ を使用します。

💡 数学的背景とコアアイデア

Section titled “💡 数学的背景とコアアイデア”

整数環 Z\mathbb{Z}Z は体（Field）ではないため、ある行をピボット要素で「割る」という操作ができません（ピボットの倍数以外の要素を直接 0 に消去できません）。 代わりに、2つの行の間で**ユークリッドの互除法（Euclidean algorithm）**を回すことで、要素を割り切るように行/列基本変形を進めます。 また、基本変形に用いる行列は、行列式が ±1\pm 1±1 である整数行列（ユニモジュラ行列）に限定されます。これによって、変形前後で「張る格子（Lattice）」が完全に保存されます。

⚡ 主なメソッドと計算量

Section titled “⚡ 主なメソッドと計算量”
  • smithNormalForm(a): 整数行列 AAA のスミス標準形 UAV = S を計算します。 計算量は O(NMmin⁡(N,M)log⁡(max⁡∣Aij∣))O(NM \min(N, M) \log(\max |A_{ij}|))O(NMmin(N,M)log(max∣Aij​∣)) です。
  • rowHermiteNormalForm(a) / columnHermiteNormalForm(a): 整数行列 AAA に対し、行/列基本変形のみを施して、エルミート標準形（Hermite Normal Form, HNF）へ変換します。 HNF は、整数行列において掃き出し法の階段行列（RREF）に相当する唯一の正規形（各ピボットは正で、ピボットより上の要素はピボット未満に正規化されている）であり、整数ベクトル空間（格子）の等価性判定や、ディオファントス方程式の解法において基礎となります。
  • linearEquationOnZ(a, b): 整数上の連立一次方程式 Ax=bAx = bAx=b を厳密に解き、整数特殊解 xxx と、整数解空間の核（零空間）の整数基底を返します。解が存在しない場合は null を返します。

4. 合成数 n を法とする剰余環 Z/nZ 上の演算: MatrixUtilsZn

Section titled “4. 合成数 n を法とする剰余環 Z/nZ 上の演算: MatrixUtilsZn”

法 mod が素数ではなく合成数（例: 10910^9109 や 2k2^k2k）の場合、剰余環 Z/nZ\mathbb{Z}/n\mathbb{Z}Z/nZ には逆元を持たない非ゼロ元（零因子など）が存在するため、通常の体（Field）を前提とした掃き出し法が使えません。

⚡ 主なメソッド

Section titled “⚡ 主なメソッド”
  • determinantByEuclid(a, mod): 逆元を用いずに、隣接する行の間でユークリッドの互除法を実行しながら下三角成分を消去していくことで、任意の合成数 mod の上で正方行列の行列式を厳密に計算します。 計算量は O(N3log⁡(mod))O(N^3 \log(\text{mod}))O(N3log(mod)) です。
  • add / mul / pow: 合成数を法とする基本的な行列加算、乗算、累乗をサポートします。

5. 二元体 F2 上のビットパラレル高速演算: MatrixUtilsF2

Section titled “5. 二元体 F2 上のビットパラレル高速演算: MatrixUtilsF2”

二元体 F2\mathbb{F}_2F2​ （mod 2\text{mod } 2mod 2）上の演算は、コンピューティングにおけるビット演算（XOR と AND）と完全に一致します。 MatrixUtilsF2 は、1つの long（64ビット）に 64 次元分の要素を詰め込む（パックする）ことで、あらゆる行列演算を定数倍 1/641/641/64 に高速化（ビットパラレル化）します。

⚡ 主なメソッドと計算量

Section titled “⚡ 主なメソッドと計算量”
  • bitBasisMSB(a): 与えられたベクトル集合から、MSB（最上位ビット）から順に掃き出した XOR 線形基底を抽出します。
  • bitVectorSpaceIntersectionBasis(u, v): F2\mathbb{F}_2F2​ 上の 222 つの部分空間 ⟨U⟩\langle U \rangle⟨U⟩ と ⟨V⟩\langle V \rangle⟨V⟩ の**共通部分（交空間; Intersection Space）**の基底を高速に計算します。 関係式 Ux=Vy  ⟺  Ux⊕Vy=0Ux = Vy \iff Ux \oplus Vy = 0Ux=Vy⟺Ux⊕Vy=0 に基づき、連合行列 [U∣V][U \mid V][U∣V] の核（零空間）をビット掃き出し法で求めることで、交空間の基底を抽出します。計算量は O((∣U∣+∣V∣)×64)O((|U| + |V|) \times 64)O((∣U∣+∣V∣)×64) です。
  • addToBitBasis(val, basis): 線形独立性を判定しながら、新しい要素 val を既存の XOR 線形基底へ挿入し、基底を動的に拡張します（破壊的更新）。
  • packToBitMatrix(a) / unpackBitMatrix(a, n, m) / transposeBitMatrix(a, n, m): 直感的な boolean[][] 表現と、ビットパラレル用の高速な long[][] 表現を相互に変換・転置します。
  • determinantMod2(a, n) / rankMod2(a, n, m) / invMod2(a, n) / linearEquationMod2(a, b, n, m): ビット並列処理を極限まで最適化した、F2\mathbb{F}_2F2​ 上の行列式・ランク・逆行列・連立一次方程式ソルバです。 すべての掃き出し操作が long のビット演算で行われるため、サイズ N=1000N = 1000N=1000 程度の行列であっても一瞬で計算が完了します（消去計算量は O(N3/64)O(N^3 / 64)O(N3/64)）。
  • geometricSum(A, N): F2\mathbb{F}_2F2​ 上の等比級数の和 ∑i=0N−1Ai\sum_{i=0}^{N-1} A^i∑i=0N−1​Ai をダブリングにより高速に計算します。

6. Min-Max 半環上の最短路・ボトルネック演算: MinMax

Section titled “6. Min-Max 半環上の最短路・ボトルネック演算: MinMax”

MinMax クラスは、通常の「加算・乗算」の代わりに「min⁡\minmin・max⁡\maxmax」を基本演算とする Min-Max 半環（Min-Max Semiring）上の行列演算を扱います。

💡 代数的背景：Min-Max 半環上の行列積

Section titled “💡 代数的背景：Min-Max 半環上の行列積”

実数に無限大を加えた集合上において、和（加算）演算を ⊕=min⁡\oplus = \min⊕=min、積（乗算）演算を ⊗=max⁡\otimes = \max⊗=max と定義すると、これは代数的な**半環（Semiring）**を構成します。 この半環における、２つの正方行列 A,BA, BA,B の積 C=A⊗BC = A \otimes BC=A⊗B は、定義より次のように書き表されます：

Cij=⨁k=1n(Aik⊗Bkj)=min⁡1≤k≤n(max⁡(Aik,Bkj))C_{ij} = \bigoplus_{k=1}^n (A_{ik} \otimes B_{kj}) = \min_{1 \le k \le n} \left( \max(A_{ik}, B_{kj}) \right)Cij​=k=1⨁n​(Aik​⊗Bkj​)=1≤k≤nmin​(max(Aik​,Bkj​))

これは、グラフにおいて「頂点 iii から jjj へ遷移する際、経由地 kkk を通るルートの（最大辺重み）を最小化する」という**ボトルネック最短路（Minimum-Max Path）**の遷移そのものです。

⚡ 主なメソッドと計算量

Section titled “⚡ 主なメソッドと計算量”
  • asps(cost) (All-Pairs Shortest Path): Min-Max 半環における全点対最短路（APSP）を計算します。
    • Floyd-Warshall（頂点数 N<50N < 50N<50 の場合）: O(N3)O(N^3)O(N3) の単純な動的計画法（warshalFloyd）を実行します。
    • ビットパラレル・スイープ（頂点数 N≥50N \ge 50N≥50 の場合）: 辺をコストの昇順にソートし、到達可能性（Reachability）を long[] によるビットベクトルで表現して伝播させます。これによって、全体の計算量を O(N3/64+Mlog⁡M)O(N^3 / 64 + M \log M)O(N3/64+MlogM)（ここで MMM は辺数）に落とし、大規模グラフでのボトルネック全点対最短路を劇的に高速化します。

🎯 競技プログラミングでの典型的な適用場面

1. 期待値・確率 DP のリピート遷移

Section titled “1. 期待値・確率 DP のリピート遷移”

「ある状態から別の状態へ遷移する確率や期待値」の遷移関係は連立一次方程式 Ax=bAx = bAx=b となり、これを Fp\mathbb{F}_pFp​ 上や実数上で解くことで、自己参照的な期待値・確率が求まります（solveLinearEquation）。

2. スパニングツリーの数え上げ (行列木定理)

Section titled “2. スパニングツリーの数え上げ (行列木定理)”

グラフのラプラシアン行列（次数行列 - 隣接行列）の余因子（または一部の行と列を削除した行列の行列式）を計算することで、グラフの全域木の個数をカウントできます。 有向グラフや、重み付きの全域木にも拡張可能です。

3. XOR 空間の独立性と最大化 (XOR線形基底)

Section titled “3. XOR 空間の独立性と最大化 (XOR線形基底)”

F2\mathbb{F}_2F2​ 上の線形代数は、XORに関連する競プロ問題のほぼすべてに適用できます。 「選んだ要素の総 XOR を最大化する」問題は、bitBasisMSB によって基底を取り出し、大きい方のビットから貪欲に XOR していくことで解くことができます。また、部分空間の共通部分を求める bitVectorSpaceIntersectionBasis は、「2つの条件を同時に満たす XOR の基底」を得るための強力な道具です。

4. グラフのボトルネックパス

Section titled “4. グラフのボトルネックパス”

「グラフ上で移動するとき、通過する辺の最大重みの最小値（または最小重みの最大値）」をすべてのペアについて求める問題において、MinMax.asps は非常に高速な解法を提供します。
